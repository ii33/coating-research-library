# 有限厚板局部修正的物理目标与边界

## 结论和阅读路径

本轮证明和实现一个很窄但可复算的事实：对于T02第三轮已冻结的有限厚矩形板仿射运动截面，只改变板横移b和半宽a时，可在活动面切换、事件碰到过程端点及事件次序改变前限制一步。若只求光滑核的导数，这两个板变量的梯度为零，不能得到有用局部步。包含遮挡事件项后，一次小步改善同一沉积目标，且本轮有理区间互不重叠。

这不是任意CAD优化器、加工方案或连续源收敛证明。工件横移的反号反例只复现T02结论，不扩展本轮设计自由度。T02旧点12仍partial；点2条件包络仍非严格。合成仿射族的严格编码算术不能追溯提升旧数据的资格。

先读本章和第2章的步长条件，再读第3章数值资格、第4章完整算法；第5章给结果和反例，第6章说明设备与发布边界。具体实现与对应单元测试随reader提供。

## 冻结输入和坐标

全部长度用m、时间用s、角度用rad。源节点S=(s,0,0)，法向+z；靶点X(t)=(x0+u+v(t+c),0,H)，法向−z。有限厚板为闭长方体，b−a≤x≤b+a，|y|≤0.15，0.4≤z≤0.6。板和源坐标架无旋转，源/靶y固定为零，故y侧面不会参与本轮遮挡切换。H=1，v=0.4，x0=−0.4，u=0.03，c=0，b=0，a=0.08，过程窗口[0,2]。

板厚0.2m来自原合成合同，不是用户机器的尺寸。源率q(t)=1+0.3t按参考时钟t计算；位姿时钟c只移动靶点，不平移源率。这些字段都进入缓存合同。

原始计算合同为单节点s=0、权重w=1；本轮结果仍使用该合同。代码支持不超过65个明确给定的有限节点，但不把有限节点求和自动当成连续源积分。零输入不确定性是假设，不是测量结论。

## 唯一的比较目标

余弦发射、余弦凝结和反平方距离给出：

```
y(t,s) = x0 + u + v(t+c) - s
f(t,s) = A q(t) H² / [H²+y(t,s)²]²
D(b,a) = Σj wj ∫[t0,t1] Vj(t;b,a) f(t,sj) dt
J(b,a) = 1/2 [(D(b,a)-D*)/D*]², D*=1 s/m²
```

D是归一化传递积分，单位s/m²，J无量纲。未使用密度、分子质量、实际源率标定或材料粘附系数，不能把D直接称作nm膜厚。选择D*=1是本轮明确的合成目标。包含事件与漏事件方法始终使用同一D、D*、源、窗口与完整forward；只有提议步的Jacobian不同。

此目标不是厚度CV，也不是多点面形最优、通量最大化或多目标Pareto问题。一点标量残差对两个板参数仅提供秩至多1的局部信息。可证实一次下降，不可据此唯一辨识板形或宣布达到局部/全局最优。

## 材料边界

Zhang与Cai的镀膜研究明确区分发射、凝结角特性；本轮保留cosine/cosine只是已冻结参考的条件，不把材料指数视为普遍常数。后续材料研究需要独立数据来决定是否应替换该核。参见[开放原文式1](https://pmc.ncbi.nlm.nih.gov/articles/PMC3817662/)。
