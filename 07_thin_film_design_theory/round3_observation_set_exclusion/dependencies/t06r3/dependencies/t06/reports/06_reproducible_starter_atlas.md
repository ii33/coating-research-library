# 06 六组可复算、可调参数的起始膜系

## 6.1 怎么运行

从`06_optical_coating_families`目录执行：

```sh
python models/run_atlas.py
python -m unittest discover -s tests -v
```

Python≥3.10、NumPy≥2.0；不需联网、不需商业软件、不需第三方论文原件。`data/material_proxies.json`冻结所有使用的n/k及明确假设，`data/starter_stacks.json`存入射→基片的逐层物理厚度、波段、AOI、偏振、基片厚度/α和背面状态。nm与µm同时列出并测试一致性。

`build_atlas_inputs.py`是可选的来源重建入口，会重新运行E02的有界二维网格、检查T04 Al原始CC0数据的SHA256，再重采样九个n/k点；该脚本需要T04本地原件，**公开包正常复算不依赖它**。没有原件时不能宣称做了原始数据重建，但仍可运行冻结输入和所有参考测试。

所有示例均标为`synthetic_reference_calculation_not_measured`。所谓起始，是可改变λ₀、层厚、层对数、角度或材料代理再复算的对象，不是可直接生产的工艺卡。

## 6.3 参数的证据等级

| 参数集 | 实际继承的证据 | 模型额外假设 | 不可跨越的界限 |
|---|---|---|---|
| MgF₂/K9 NIR | T04指定λ处n，H-K9L牌号 | 冻结n、膜k=0、bulk α=0 | 不作低吸收或所有K9保证 |
| ZnS/YbF₃ MWIR | 原厂n表；YbF₃ k离散点；Ge295K n点 | 稀疏线性插值；ZnS k=0；体α=0 | 无法恢复水峰和工艺变化 |
| 双谷ZnS/Ge | ZnS目录n，Ge11 µm锚点 | 3–12 µm冻结Ge n/k；教学反例 | 不是Ge全谱真实数据 |
| LWIR HR | 历史Ge膜n≈4.3；ZnS目录点；ZnSe10.6µm n | Ge/基片冻结，k=0 | 不以块Ge替代膜Ge，不推生产吸收 |
| NIR腔Ta/Si | 同来源1064nm IBS膜n | 全谱冻结n、k=0 | 无法推蒸发工艺、远带吸收 |
| Al保护镜 | 有来源复n九点重采样 | 稀疏插值、盖层冻结n、无氧化/粗糙模型 | 非超薄岛状层、非耐久资格 |

`calculation_bounds_um`只控制代码允许的实验域，不是材料被实测验证的有效域。越界请求必须报错，不能用端值延伸生成漂亮光谱。已知k上限不是k=0；未知α不变成测得0；当前基线α=0是写明的对照场景。

## 6.4 光谱、图和数值指标在哪里

- `data/spectra/E01_spectrum.csv`至`E06_spectrum.csv`：λ、每角度/偏振的R/T/A、前膜R/T/A和单程体透过；无百分单位混用
- `data/finite_band_metrics.json`：全量有限带指标、最坏OD和前表面比较
- [生成简表](06a_generated_metrics.md)：0°的双面总外响应
- [谱图](../figures/01_spectral_atlas.svg)：六例总R/T/A
- [角度/偏振图](../figures/02_angle_polarization.svg)：最大评估角的s/p与0°对照
- `data/sensitivity_scenarios.json`：各层共同±2%厚度和AR不同背面、假定体α的确定性敏感度

共同±2%只是相关厚度误差情景，不是设备标准差或95%置信区间。本册没把层误差假定成独立同分布；T05已指出料位、温度与QCM密度误设可造成跨层相关误差。要算产率需真实协方差和工艺边界，交T08。

## 6.5 参考求解器究竟验证了什么

`reference_tmm.py`使用各向同性、平面、均匀、非磁性层；N=n+ik、时间exp(−iωt)。s导纳q=Ncosθ，p使用切向电场导纳q=N/cosθ，因此p振幅r符号可能与使用另一坐标约定的文献不同；R/T不受该符号选择影响。光谱比较应先对功率，不能直接拿异约定相位相减。[F01](https://arxiv.org/html/1603.02720v5)

有限层矩阵使用−i sinδ项映射后端场到前端，选择向前衰减的根。T包含入射/出射光学导纳实部比；只算|t|²会在不同n两侧出错。无吸收输入、吸收半无限输出时，T是进入输出介质的边界功率，有限层A不包含该半无限介质后续全部吸收。

验证分四层：

1. 精确极限：Fresnel、Brewster、四分之一波匹配、零厚度、相同材料分层与TIR
2. 独立接口递归：随机有吸收堆与特征矩阵功率一致；不是调用同一函数与自己比较
3. 厚基片：裸Ge无损/有损解析式、光程角度、相干相位平均与非相干和、色散反向角逐点计算
4. 数据与实例：边界拒绝、厚度单位、全例被动性、采样加密、已知失败特征、背面敏感性

能量残差小只是归一化一致性，不能证明n/k正确、模型齐全或实件合格。随机算例也不能替代目标材料的计量。

## 6.6 明确不支持，避免错误扩张

不支持各向异性、粗糙/散射、梯度层、横向结构、非线性、热机械场、层内吸收剖面、激光损伤或任意相干混合。入射介质必须无吸收；厚基片接口必须实n，体α另给，仅适用于可忽略界面吸收的情形。对大Imδ的强吸收厚层主动拒绝；不静默截断相位，也不截断负A掩盖数值问题。

不存在统一的“厚于X µm就非相干”规则。当前plate函数按指定非相干模型汇集全部镜面出射；窄线宽干涉、有限孔径漏收、明显楔角、强吸收介质反向功率需换模型。T07应接手更通用散射矩阵/混合相干求解，而不扩大这份教学参考的生产定位。
