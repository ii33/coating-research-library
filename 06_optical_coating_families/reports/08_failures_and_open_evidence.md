# 08 失败案例与仍未解决的证据

## 8.1 有结果、能重跑的反例

| 失败/误用 | 复算或来源证据 | 正确处理 |
|---|---|---|
| 两个低R谷被叫作双宽带AR | E03在3–5 µm总Tmin≈47.14%，而8–12平均T≈94.88% | 分别验每个有限带，不能用峰值或总平均 |
| 高峰值腔被叫作高阻挡滤光片 | E05指定阻带T约2%，不满足OD3 | 远带扫描、额外阻挡与多腔综合留后续 |
| 高反堆被叫作陷波片 | E04在12–13 µm仍低透射 | 两侧通带必须各自通过，不能只验阻带 |
| 单面低R被当成高总T | E02裸背面与同膜背面差异超过25个百分点的测试通过 | 显式建后膜与体吸收 |
| K9 n数据扩展到10 µm | `test_forbid_extrapolation`直接报错 | 确定牌号与数据域，MWIR/LWIR基片重新选择 |
| YbF₃ MWIR代理拉到LWIR | `test_no_ybf3_lwir_extrapolation`报错 | 获取适用LWIR n/k，不能让插值库自动延伸 |
| 厚强吸收层矩阵溢出被当成零T | Imδ>25主动拒绝 | 使用经验证的稳定散射矩阵或不透明极限 |
| 不透射金属被当作无损 | E06仍有约3.13%平均A | 保留R/T/A并做热/吸收计量 |
| 窄腔谱点太少但均值看似收敛 | 首次E05 2601点加密差3.59×10⁻⁵，未过10⁻⁵门槛 | 改10401点再验证；不放宽阈值掩盖问题 |
| 论文标题低反射数字当实测总窗 | F17单面模型0.54%与双面实测3.31%不同 | 区分模型/实测、单面/双面、加附着层前后 |
| YF₃写成YbF₃ | F12是YF₃；本库E02是YbF₃ | 保持化学身份；不以类似名称换n/k |
| 光学厚度系数直接改nm | F16给H/N/L系数，需参考λ、n和角约定 | 没有完整转换信息就只作文献结构记录 |

## 8.2 尚不能补空的材料与制造信息

没有用户本机n/k、实际膜厚、面内均匀性、密度、应力、吸收和缺陷数据。T04部分目录参数缺温度、厚度或不确定度，T06没有把它们转换为“已测精确曲线”。原厂n点之外的插值只是一种可检验假设，未解决窄带吸收、声子边缘或批间漂移。

H4身份、K9实际牌号、Ge掺杂/电阻率、ZnS具体等级与所有基片实际厚度仍需用户实件资料。本轮不因此停下公开理论研究，但它们构成生产化阻断条件。

## 8.3 文献完整性与冲突清单

- F11双带AR：公开层数/总厚度和测量，无完整每层处方；ZnSe表3样片二/三材料归属未澄清
- F12热AR：Table1与正文厚度不同；保留两个版本和定位，不平均，不凭经验修正
- F13分色：公开背面AR表，未核清编号方向；前面最终处方、偏振和基片厚度未齐
- F14保护银：早期可行性99.1%和后续批次值不能混；完整n/k/测试角未齐
- F15宽角HR：完整层厚补充S1未取得；主文性能可作案例，不能宣称处方复现
- F16 PBS：系数不能冒充nm；后AR与完整物理表未取齐；设计和实测带宽分开
- F17超薄AR：初始、加附着层重优化、TEM实测层表是不同对象；未取齐最终制造几何

这份有界首轮不以无限检索填满所有缺口。可公开实测证据已支持膜类和工程边界；尚未取得的细节也有明确下次切入点。

## 8.4 研究完成、数值验证、生产资格分开

本轮“完成”表示已建立章节、引用、来源卡、起始膜系、光谱数据、参考代码/测试、失败边界和T07接口。它不表示全部全球文献读完，也不表示实机膜系已验证。

数值测试是可复算的参考验证；指定外部模型/审查角色若未实际运行，状态保持未执行。独立来源核验与程序中的独立接口递归测试分别留记录，不能冒称为完整生产软件评审或指定模型审查。
