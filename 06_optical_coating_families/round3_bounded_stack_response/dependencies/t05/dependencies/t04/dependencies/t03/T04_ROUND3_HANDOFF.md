# T04第三轮候选 材料响应的有界传递

本交接是候选，未启动T04。T03新输入是冻结有限厚板两参数族的事件感知一步、可拒绝的目标区间比较及有限源编码模型包络；它不提供实机膜厚标定、光学常数或生产可用板形。

建议只解决一个新增问题：怎样在不改变已冻结几何/运动/源时钟的前提下，把传递积分D与材料/基片响应分开，并说明材料未知如何阻止原有优化排名向“材料性能更好”外推。

可交付边界：

1. 从已有材料研究和可信原始来源定义最小响应参数（沉积质量到厚度的系数、角度依赖凝结、密度/基片温度影响），明确量纲与来源，不臆测机器或材料实测值
2. 区分可识别的比例转换与会改几何核形状的响应。全候选共用正常数比例，且目标一致换算时相对目标可能保持；参数依赖角度/能量/温度时须重新评价，不直接沿用J排名
3. 对材料参数区间传播后的目标重叠返回无法分辨；不能将unknown粘附率、负净沉积或分母近零作透明/零误差处理
4. 保留T03事件项和完整forward接口，不以材料小例子覆盖或补齐T02旧point2/12；point12仍partial，point2仍条件非严格，源/时间缺口仍在
5. 只使用有边界的小解析/数值核查。高算量设备授权和hostquota/权限未恢复前不运行、不改远控路线
6. 来源原文单独本地保存；读者包包含hash绑定依赖，可脱离兄弟目录复算。PNG要查像素，HTML浏览器限制实报
