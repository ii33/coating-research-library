## 来源与状态

- 原文定位：`00_project/工程科研.txt` 第10行
- 顺序：第6个大项目；第一轮
- 当前状态：仅规划，尚未启动研究
- 前置阶段：T05首轮验收完成
- 算法/数值验证要求：本规划侧重资料与证据；若后续加入定量模型，追加算法与数值验收

## 首轮范围

以近红外、中红外、多光谱为首轮重点，建立应用需求、膜类、基片、环境和测试条件的对应关系。具体波段范围与评价指标在研究启动时定义，不把名称当固定数值边界。

## 优先顺序

1. 近红外
2. 中红外
3. 多光谱

## 交付物

- 按应用与性能指标组织的膜类资料图谱
- 代表性设计、工艺和测试证据摘要
- 科研结果与工程应用的条件差异对照
- 复用案例、失败案例和优先资料索引

## 阶段验收标准

1. 覆盖三个首轮重点，明确波段、角度、偏振、温度与测试条件
2. 每个代表案例说明目标、构成、来源、结果及适用边界
3. 光谱、环境和制造指标分别追踪，不只收集峰值性能
4. 引文和合法原文档案完整，未核验案例明确标识

共同门槛：关键结论能回溯来源与条件；有可复用结果、未决问题、失效/适用边界及下一阶段接口；审查结论有记录。资料完成、仿真验证、实测验证分开标注。研究范围有限，文献不要求无限穷尽；关键缺口不得隐藏。

## 目录约定

- `reports/`：分章节报告与有版本号的阶段成果
- `sources/summaries/`：逐来源摘要、原文定位、限制与证据等级
- `sources/originals/`：仅保存已核对合法存档权利的原文
- `data/`：可复用参数、数据表与来源/单位/不确定度
- `reviews/`：阶段验收、纠错与未决问题处理
- 需要模型、实验、benchmark时，在本专题下新增对应目录，并更新共享索引
