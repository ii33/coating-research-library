# 工程选型 拓扑误判与维护后的复标

本章补齐首轮工程决策接口。下述比较为公开结构证据结合运动学的工程综合，不是厂家优劣排名，不给未经测试的精度、寿命或产能承诺。

## 1 先写任务边界再选结构

选型输入按以下顺序确定：有效镀膜口径与工件形状；一炉数量及混装方式；可接受温度与热接触；所需厚度/光谱的空间误差；最短和最长单层时间；允许维护停机和可保存的数据。若先决定“必须某齿数”“一定四行星”，容易把目标适配成已有机构。

几何装得下不等于有效装载：必须检查整个运动周期内的碰撞包络、可达沉积视线、离子照射、修正板间隙、监控光路和装卸通道。遮住的工件面积与为机械间隙留出的空白都不能计为有效镀膜口径。

## 2 运动架构的有限比较

| 结构选择 | 优先考虑的任务 | 直接优势或可控量 | 必须付出的确认工作 |
|---|---|---|---|
| 平行轴直接外啮合行星 | 平面工件，需简明且可复现传动链 | 齿比与相位关系容易核算，几何可由少量刚体变量描述 | 轴距与齿数耦合；装夹倾斜、有限层时间、遮挡仍需测量 |
| 带中间轮组的行星 | 工件轴位置或方向不适合直接啮合 | 可调节布局、相对方向或输出传动 | 必须逐级追踪方向；复合轮不能当惰轮消去；更多接口需登记 |
| 倾斜或可变角度行星 | 曲面/特定入射角分布任务 | 可改变工件法向与源的关系 | 需要三维姿态；角度标定、摆动机构和遮挡不得用平面公式替代 |
| 单轴盘作为对照 | 简单工件、空间限制或源分布基线试验 | 少一级传动，较易隔离某些变量 | 不具有双轴采样；不能默认达到同样大口径均匀性 |

结构存在性来源：Bühler装夹选项[S01](https://dam.buhlergroup.com/asset/5a2a255493ef47d49158daae54c1f037/Brochure_LO_Optics_Precision%20Optics.pdf)、中间轮/倾角输出专利[S16](https://patents.google.com/patent/DE4025659A1/en)。表中选择逻辑是本研究建议。

冷却、夹具形状和监控方式是另一些选择轴，不能与“直接/间接传动”放成互斥机型。水冷行星可与平面或倾斜夹具组合，但需要旋转供回水、接头、热接触、流量监测及装卸接口；是否采用由温度和节拍需求决定。[S05](https://patents.google.com/patent/US11608882B2/en)

## 3 驱动和真空穿轴应怎样比较

不要只比电机额定转矩或最大转速。应核对装载惯量、加速度、启动力矩、运行阻力、输出轴承载、轴径/空心通道、真空边界、温度和工艺气体相容性。Ferrotec选型目录分别讨论尺寸、实心/空心轴、转速与转矩，并区分气体负载与泄漏率；这些项目是设计输入，不能用某个零件的最高转速代替整套行星机构允许转速。[S24，印刷页x–xi](https://seals.ferrotec.com/wp-content/uploads/sites/2/ferrotecVFcat_020812_web.pdf)

工程建议保留三套速度量：命令值、测得的主轴值、测得的工件轴值。只记录命令值，会把齿轮连接、减速器配置或机械迟滞问题隐藏在“已按配方运行”之下。

## 4 常见拓扑误判速查

| 容易说错的句子 | 更准确的表述 | 最小识别证据 |
|---|---|---|
| 外啮合，所以工件一定与大盘反转 | 外啮合符号先在载架参考系内写；绝对速度再加载架项 | 固定件与参考系、两轴标记 |
| 自转就是120/36×15 | 该值是本示例相对载架自转；绝对自转还需加15 | 控制器量的定义与录像 |
| 太阳轮固定就能只看两枚齿轮 | 可能还有中间轮、复合轮、摆动输出或离合 | 端到端机械连接图 |
| 齿轮半径就是工件盘半径 | 分度圆、夹具、基片及有效口径是不同几何量 | 四个尺寸分列 |
| 37齿互素，所以不会重复 | 理想有理齿比仍会周期重复；这里是37圈位姿闭合 | 精确齿比与重复条件 |
| 转完一次闭合周期就完全均匀 | 完整闭合不等于所有独立相位组合都被均匀采样 | 有限时间与真实通量积分 |
| 换齿只改变速度 | 同模数直接啮合还改变中心距，安装也可能改变 | 改动前后几何测量 |
| 有离子枪就是IBS | IAD中膜料可来自蒸发源；IBS材料来自受轰击靶面 | 沉积物料路径 |
| 图上的每条线都是固定遮挡 | 挡板可能固定于腔体、载架或工件 | 所属运动系与开闭时序 |
| 一个圈均值正常，就不存在角向问题 | 径向平均会消去同半径方位信息 | 保留二维原始测量 |

前七项由章节03的条件化约束与反例支持；后面三项由章节01、02、04的路径和采样定义支持。

## 5 维护不是脱离工艺标定的附录

维护后的任务是判断哪些模型输入发生了变化，而不是只写“清洁完成”。以下是检查框架；具体拆装、润滑、冷却、带电操作和联锁测试必须按该机型规程由合格人员执行。

| 检查对象 | 可观察的异常或变化 | 建议保留的证据 | 可能触发的复标 |
|---|---|---|---|
| 齿轮/轴连接与支承 | 新出现相位跳变、回差、松动、端面摆动 | 运行角度曲线、停机照片、配置号 | 运动比与安装姿态 |
| 夹具/压圈 | 开口变化、积膜、装夹变形、重复定位变化 | 清洁前后轮廓与装夹基准 | 有效口径、遮挡、二维见证片 |
| 固定修正板/源挡板 | 轮廓改变、弯曲、位置/行程变化、开闭时间改变 | 版本图、位置记录、开关日志 | 可见性与时序 |
| 蒸发源 | 更换穴位、装料/预熔形态变化、源面高度变化 | 源编号、装料照片、速率曲线 | 源分布与tooling |
| QCM头及前遮罩 | 材料积累、晶片更换、接触/热状态或定位变化 | 传感器编号、位置、原始频率/温度/流量记录 | 传感器稳定性及工件厚度标定 |
| 离子源/中和器 | 清洁或更换电极、栅网、中和部件，腔壁覆层变化 | 型号/配置、实际电流电压、异常日志 | 束流空间分布与充电状态 |
| 冷却与真空穿轴 | 流量/温度、压力趋势、启动力矩变化 | 支路记录与维护单 | 热稳定、运动稳定与真空基线 |
| 光学监控通道 | 窗片、试片、光路或探测位置变化 | 光路基准、背景/参考谱 | 监控基线与层终止关联 |

INFICON的Type A传感器明确设置可拆前遮罩以减少沉积物累积并便于维护，说明“监控硬件本身也会被镀膜”是设备设计必须处理的现实，而不只是软件校正问题。[S23](https://www.inficon.com/en/products/thin-film-technology/sensors-and-feedthroughs/type-a-sensor)

不在缺少设备手册时规定“每多少炉换润滑脂”“统一流量多少”“固定几小时必须清洁”。维护周期应结合实际材料、沉积累积、制造商要求、趋势数据和过程风险确定。通用观察项目可以先建立，数值阈值保持未定。

## 6 一个可执行的改动闭环

1. 变更前保存配置号、原因与可比较基线
2. 标明改动涉及几何、运动、源、测量、热/离子中的哪些输入
3. 安全检查和空载/允许条件下的功能检查按设备规程进行
4. 只对受影响链路先做最小复标，再视结果决定扩大检查
5. 保存验证结果和新配置号；如果验证不足，明确旧标定不再保证适用

这条流程是本研究提出的质量控制建议，不取代工厂质量体系、客户验收规范或设备制造商指令。

## 7 首轮选型结论

对于尚未取得用户传动图的场景，最合理的默认工作不是推荐换齿或换机构，而是以“平行轴直接外啮合”建立可反驳的基准模型，同时保留可替换的传动/姿态接口。选型最终输出应是需求符合性、可调范围、数据可得性、维护与复标成本的比较，不是单一齿数或厂家名称。
