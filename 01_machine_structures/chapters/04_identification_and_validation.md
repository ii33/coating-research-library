# 实机识别 参数字典与验证计划

## 1 本批要解决的实际问题

历史线索包括：固定中心太阳轮120齿，行星轮36/37齿，大盘15 rpm，约30 cm基片，源高约1 m，源相对行星中心约10 cm偏心，以及同一圆周上的角向不均匀。以上均为待核对案例输入。它们不具备统一坐标、不确定度、日期和运行日志，不能直接用于高精度标定。

尤其“源相对行星中心偏心10 cm”存在结构歧义：若源固定在腔体，而行星中心公转，两者水平相对向量一般随时间变化；这个10 cm可能指某一瞬时位置、源与主轴距离之差、轨道最近间距或源投影偏离某指定工位。未解开歧义前不赋值给`source_x=0.1 m`。

## 2 首批参数字典

| 参数组 | 最小字段 | 单位/表达 | 采集与核对方式 |
|---|---|---|---|
| 腔体 | 内部有效边界、固定基准、泵口与视线构件 | m，坐标与轮廓 | 图纸与带标尺照片 |
| 传动拓扑 | 固定/输入/输出件，每级外或内啮合，同轴约束 | 有向结构图 | 设备手册、停机观察 |
| 齿轮几何 | 每级齿数、模数、中心距、变位、轴向位置 | 整数、m、无量纲 | 图纸/型号与测量相互核对 |
| 运动 | `θc(t),ψw(t)`、方向、速度实际量、相位零点 | rad，rad/s，s | 编码器或可追踪标记录像 |
| 工件 | 基片形状、尺寸、有效口径、曲率、安装偏心、法向 | m，单位向量 | 夹具测量与装夹照片 |
| 源 | 每种材料/穴位中心、表面高度、法向、蒸发区尺寸 | m，单位向量 | 图纸、装料/预熔后记录 |
| 遮挡 | 类型、边界、厚度、高度、所属运动系、开闭时间 | m，s | CAD/轮廓测量，时间日志 |
| 离子 | 型号、束轴、束流分布、中和器、各电源实际量 | m、A、V、时间 | 官方手册及设备日志 |
| 监控 | QCM/光控位置、tooling、材料参数、采样/滤波 | 各设备原单位 | 原始日志与离线厚度 |
| 环境 | 基底与工艺压力、气流、温度测点与曲线 | Pa，sccm，K或°C | 原始过程记录 |
| 层时序 | 源稳定时刻、挡板开闭、层起止、公转起止 | 同一时钟的s | 同步记录，标出时钟偏差 |
| 结果 | 坐标化膜厚/光谱、重复测量、拟合约束 | m或nm，误差 | 固定方向二维采样 |

每个值另带`value_status`：`measured`、`drawing`、`manufacturer_spec`、`historical_unverified`、`assumed_for_test`。不允许把最后两类悄然改成实测。

## 3 从低成本检查开始

### V1 先确认机械关系

在设备规定的安全检查状态下，标记载架和工件，各记录至少足够识别齿比的连续转动。优先读取真实编码器；录像须给帧率、视角和时间基准。对公转与工件角度解缠绕后拟合`ψw=aθc+b`，检查斜率与方向，而不只用两个截图数半圈。

**输出：**传动图、角度原始记录、拟合斜率/残差、正反向差异。若不满足理想公式，先检查拓扑、显示轴和打滑，而不是修改数学符号迁就现象。

### V2 建立一次几何基线

在共同坐标中记录源、行星轴、基片表面与修正板。标尺读数需考虑照片透视；不能用未经标定的图片像素代替毫米。面向高精度阶段，输出尺寸不确定度及重复装夹误差；本阶段不擅设微米级验收门槛。

**输出：**带坐标的俯视/侧视图、几何表、测量方法、照片证据。确认10 cm与1 m各自所指的两端和方向。

### V3 固定方位的二维膜厚采样

为识别同半径角向变化，可采用中心点加多个径向环，每环等角采样。起步方案可用3个非零半径、每环12个点，加中心共37点；这是建议的低成本筛查设计，不是检测标准。若已有窄条纹或明显高阶角向结构，应加密并按仪器光斑与空间变化尺度设计。

在每个半径上分别报告均值、最大最小值、标准差以及角向分布；不要先把同一半径平均掉。保留基片上的0°方向与在机位置。光谱拟合得到的是模型依赖厚度，需要检查折射率/厚度耦合；有条件用另一种量测方式交叉核对代表点。

**输出：**带单位和误差的原始二维数据，采样坐标，拟合设置，缺测点。建议模板见`data/measurement_template.json`。

### V4 重复性与重新装夹

先保持同一配置做重复批次，再分开研究重新装夹。至少两个批次只能初步观察可重复性，不能充分估计所有过程分布。单一异常图不宜用作修正板设计的唯一目标。

观察纹理是否随基片方位、夹具方位或腔体方位重复。这个实验是区分测量偏差、装夹固定误差与腔体固定误差的办法，不保证一种纹理只对应一个原因。

### V5 只在前四步通过后比较36/37齿

更换必须属于设备允许的配置，并确认中心距与啮合要求。保持或记录材料批次、源穴位、装料/预熔、几何、遮罩、离子条件、温度、速率和层终止方式。按AB/BA等顺序安排交叉比较可降低单调漂移混淆，但实际生产样片、成本与停机安排需由用户决定。

每个配置应包含至少一个短层窗口和一个较长窗口，并记录起始相位。窗口不应仅按“是否超过148秒”划分：需要考虑有效开挡板时间、通量稳定段和目标工艺。相关文献提供了非整圈和速率振荡的误差路径。[S14](https://opg.optica.org/ao/abstract.cfm?uri=ao-56-5-1460)；[S12](https://opg.optica.org/ol/abstract.cfm?uri=ol-41-22-5182)

**输出：**条件匹配表、二维膜厚对比、残差与不确定度；结论只对测试窗口有效。

## 4 不均匀性指标统一

建议明确同时保存以下量，而非只写“均匀性99%”：

- `U_PV=(dmax−dmin)/dmean ×100%`
- `U_half_range=(dmax−dmin)/(dmax+dmin) ×100%`
- `CV=std(d)/dmean ×100%`，注明样本还是总体标准差以及加权方式
- 同半径的`U_PV(r)`和角向曲线，另列全口径指标

离散采样均值不自动等于面平均。若需要面平均，应定义面积权重；径向环等点数采样不能在未加权时冒充均匀面积采样。这些是本研究的报告约定，不声称来自ISO某一条款。

ISO 9211-1:2024的官方范围是光学镀膜术语与规范表达，且明确不规定工艺方法。本批仅据官方页面登记版本与范围；没有取得全文，不引用未读条款。[S20](https://www.iso.org/standard/82935.html?browse=tc)

## 5 一张排查矩阵

| 观察 | 优先核查 | 不能直接推出 |
|---|---|---|
| 同半径角向差异稳定 | 初相位、传动比、盘面摆动、固定或随动遮挡、测量方位 | 必然是齿数不合适 |
| QCM厚度相同但样片不同 | 源分布变化、tooling失效、传感器/工件遮挡、材料光学常数 | QCM必然坏了 |
| 不同行星差异稳定 | 轨道半径/高度、装夹角、相位、局部遮挡、热/离子分布 | 共用一张修正板一定能消除 |
| 短层明显差、长层改善 | 起止相位、速率瞬态、滤波、有效圈数 | 任意增加转速均有效 |
| 清洁后结果改变 | 遮罩轮廓、接地/介质积累、热接触、装夹重定位 | 源材料性质必然变化 |
| 换齿轮后改善 | 运动采样、中心距、齿隙、安装姿态和同期工艺变化 | 改善只来自互素齿数 |

## 6 下一阶段的输入门槛

进入高精度模型前至少满足：传动拓扑已确认；坐标定义无歧义；基本几何与误差可追溯；有有限时间层日志；有二维膜厚数据与测量不确定度；源/遮挡/材料标定状态已分开。若暂缺实机数据，可继续做“假设模型与反例测试”，但输出必须标为合成案例，不能称用户设备预测精度。
