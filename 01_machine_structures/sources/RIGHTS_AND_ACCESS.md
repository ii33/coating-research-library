# 原文存档和权利边界

本批成功存档4份PDF：S01厂家手册、S02厂家说明书、S05公开专利及S12由OSTI公开提供的作者稿。每份文件均由公开下载入口取得，保留原始字节并计算SHA-256。用户可在本研究工作区查阅；未经进一步核对再分发许可，不将这些PDF放进可公开分享的研究包。读者版交付包只包含本研究原创文字、表格、推导、必要简要摘要与官方链接。

S06在PMC明确为Creative Commons Attribution开放文章，但本批PDF请求返回非PDF，不冒称已存档。其余失败请求见download_log.json；403、502或非PDF结果均没有绕过。除S06开放全文和S12作者稿之外，多篇期刊文章只核读公开摘要，S20标准与S21教材只核读官方元数据；没有取得全文的资料不用于未读细节断言。

S01元数据创建时间为2018-05-08，不能按搜索引擎抓取日期误记为2026版。KRI说明正文版权年代为2003/2006或2005/2006，URL中2024只是上传路径。
