# 行星盘首轮术语与符号索引

以下是本研究统一约定，并非声称逐条引用标准全文。

| 中文 | 英文 | 符号/定义 | 不要混同 |
|---|---|---|---|
| 腔体固定系 | laboratory/chamber frame | L，固定于腔体 | 载架坐标系 |
| 行星架 | carrier | c，携带行星轴公转 | 工件盘 |
| 公转 | revolution/orbit | θc，行星轴绕主轴的位置角 | 工件自身姿态 |
| 太阳轮 | sun gear | s，与主轴同轴的中心轮 | 必然固定件 |
| 行星轮 | planet gear | p，中心随载架移动的轮 | 行星夹具或基片 |
| 内齿圈 | ring/internal gear | r，内齿啮合构件 | 外太阳轮 |
| 惰轮 | idler gear | 传递运动的中间轮 | 有两个不同齿圈的复合轮 |
| 绝对自转 | absolute spin | ωp或ωw，相对腔体 | 相对载架自转 |
| 相对自转 | carrier-relative spin | ωp−ωc | 控制器未注明的“转速” |
| 工件姿态 | workpiece attitude | ψw或三维矩阵Q | 工件轴中心的位置 |
| 分度圆 | pitch circle | rs、rp等 | 齿顶圆和夹具外径 |
| 轨道半径 | orbital radius | R，主轴到行星轴 | 工件半径 |
| 模数 | gear module | m_g，几何齿尺寸参数 | 薄膜凝结指数m |
| 源挡板 | source shutter | 时间开关 | 空间均匀性修正板 |
| 修正板 | uniformity/shadow mask | 部分阻挡沉积通量 | 仅保护机构的罩板 |
| 几何可见性 | visibility | V，是否遮挡/半影传递 | 单一常数挡膜率 |
| 石英晶体监控 | quartz crystal monitoring | QCM，传感器响应 | 全口径工件实测厚度 |
| 工装系数 | tooling factor | 传感器到工件的标定 | 不随配置变更的材料常数 |
| 光学监控 | optical monitoring | OMS/OTM，依具体设备 | 离线二维厚度测量 |
| 离子辅助沉积 | ion-assisted deposition | IAD，辅助束作用于生长膜 | 离子束作为蒸发膜料源 |
| 离子束溅射 | ion-beam sputtering | IBS，束轰击靶产生膜料 | 所有带离子源设备 |
| 位姿闭合周期 | pose closure period | 位置与带标记姿态同回初值 | 所有观测量最短周期 |
| 源距 | source-to-substrate distance | 必须说明轴向高度差或斜距 | 未指明两端的“高度” |
| 均匀性 | uniformity | 必须写公式、口径和采样 | 厂家不同定义的同名百分比 |
