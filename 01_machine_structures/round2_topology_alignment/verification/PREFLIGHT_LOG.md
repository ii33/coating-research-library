# 数值主试算之前的接口修正

2026-10-02 04:20 UTC，尚未运行主对照或比较厚度均匀性：

- C同模数由0.004改为0.008m，使输出轮位于内齿圈之内且同时满足三个中心距；不是只满足速度方程就声称能装配。用户未给实际模数，此值仍为合成
- 初始蒸气板投影完全位于工件运动环带内侧，遮挡单元测试正确失败。把蒸气板中心x从0.145改为0.21m、半宽x从0.045改为0.035m，使它实际截断一部分蒸气路径；只按几何相交修正，未按均匀性结果寻优

- 比值输出的整型输入先转浮点，零/负净沉积返回NaN待写出null，不把不可定义归一化写成0

以上是建立可运行、几何自洽算例的预检，不改变预登记容差/停止预算。以后不根据均匀性结果更改几何或速比。
