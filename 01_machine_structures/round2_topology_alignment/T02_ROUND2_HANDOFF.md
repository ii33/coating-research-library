# 向T02第二轮移交：同一时钟的两通量参考

## 可立即复用

本增量已把工件位置/法向、蒸气点源、离子束、两个实际空间薄板及两个诊断点放入统一右手系与秒时钟。输出净厚度/净原子面数、正离子注量、入射动能面密度、局部积分R/ε、全盘总量及离子独曝时长。D是冻结基线的条件实现；C/I只在一手文字连接条件下成立，源图门槛仍unsupported。参考代码独立于首轮文件，不改变其验收。

高价值结论：同一个固定几何和源场中，厚度CV改进与离子注量CV改进可反向；单看厚度目标会漏掉真实辅助暴露差异。固定板没有出现预想的厚度优化效果，原样保留负例；不用无限调参把它包装成成功。

## 建议下一项，限定一个任务

T02第二轮建议只做“扩展蒸气源+有限厚板的双覆盖接口接入与误差预算”，不同时开发新板形优化器或材料响应模型：

1. 只读使用本轮pose/clock/output契约，以D为已知条件基线；C/I不必等图补齐才可作明确条件测试，但不得提升结构等级
2. 复用T02已有扩展源与厚板射线核，分别应用于蒸气和离子；禁止直接复用同一遮挡矩阵、把杯面读数重复乘cos或将净增长当全部入射原子
3. 固定不超过三个预设几何：点源/薄板回归、扩展蒸气/薄板半影、扩展蒸气/厚板侧壁；每个仍比较两通量及局部R/ε
4. 先固定算量和容差，区分时间、源面、空间、模型四种误差。至少保留本轮源图缺口和浮点切线负例，避免“加密差小=严格界”
5. 完成有限回归和一个独立留出数值检查就交接T03第二轮；若预算耗尽明确未收敛，不继续加候选或调参

真实机台输入不阻止上述公开方法研究。实机移入仍需传动/工件输出轴、尺寸/法向/相位、源和束图、板厚/归属、同步诊断、净留存与材料响应；缺这些就不能声称本机精度或生产窗口。
