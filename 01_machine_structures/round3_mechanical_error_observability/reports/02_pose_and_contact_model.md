# 误差如何进入位置 法向与有限时间沉积

## 1 不以一个“修正转速”代替三维运动

本轮采用主动旋转、列向量。Rz(θ)为右手绕z轴旋转；Exp([a]×)为旋转向量a的SO(3)指数映射。每个时刻定义：

- θc：实际载架角；φ：理想输出相对载架角，rad
- bC：[R cosβ,R sinβ,z]，名义行星轴参考点在C中的位置，m
- dL：载架原点在L中的平移误差，m
- acL：载架绕L的x、y方向倾斜误差，rad
- dpC：行星轴中心相对C的平移误差，m
- apC：行星轴绕C的x、y方向倾斜误差，rad
- δψ：条件理想输出之外的自转误差，rad
- Qmount：静态工件装夹旋转；eW：工件系中装夹偏心，m

精确组合定义为：

Rc = Exp([acL]×) Rz(θc)

c = dL + Rc (bC + dpC)

Q = Rc Exp([apC]×) Rz(φ + δψ) Qmount

x(t,u) = c + Q(u + eW)，n(t,u) = Q nW(u)

acL与apC只使用两个倾斜分量；绕z的误差并入θc或δψ，避免同一物理自由度重复设参。bC包含名义高度，dL不能再无说明地包含另一份相同高度。相机、探头和源也需要自己的外参；误差绕哪个轴点发生决定杠杆臂，不能把同一三维小角直接套在不同转轴上。

该组合不是唯一参数化，必须随实际机械链改变。载架或工件柔性挠曲需要空间变形场，不能靠一个刚体倾角全部解释。模型使用精确旋转，线性Jacobian仅用于局部敏感性与条件可辨识诊断。

## 2 位姿微扰的明确符号

对一个已算得的刚体姿态(c,Q)，令r=x−c。在L中、关于c的左乘小旋转δα下：

δx = δc + δα × r

δn = δα × n

Jx = [I, −[r]×]，Jn = [0, −[n]×]

因此一个转角对离轴位置的灵敏度量纲为m/rad，对法向灵敏度为1/rad。轴向平移改变高度但不直接改变法向；倾斜必须同时改变两者。`models/reference.py`给出精确姿态与该Jacobian，测试用中心有限差分独立检查六列，不以厚度图“看起来对称”替代符号核验。

对名义水平表面u=(ux,uy,0)，小角位移的z分量为δz=δcz+αx uy−αy ux。在半径ρ的某一点，倾斜与轴向平移可能给出相同读数；跨非共线位置的测量才有机会拆开。这直接导出第四章的三探头设计矩阵。

一阶近似的余项随角度平方和杠杆臂增长。若要把线性传播当精度证据，须用实际允许扰动域与精确旋转比较；本轮的小数学测试仅验证代码，不选择实际误差范围。

## 3 回差是有记忆的接触问题

齿隙不是每次采样独立加一份均匀随机角误差。载荷持续保持同一齿侧接触时，可以存在几乎恒定的相位滞后而没有完整自由游隙运动；换向、转矩翻转或振动脱离接触时，响应可能完全不同。

为演示这一点，本轮给出输出角坐标的标量play算子：输入xk为理想无隙输出角，半宽b≥0（rad），初始接触状态y0已知且|y0−x0|≤b，

yk = clip(yk−1, xk−b, xk+b)，δψk=yk−xk

总反向空程为2b。输入先上升再下降，在进入另一边界前输出保持原值，因此同一x可对应不同y。它只是一种准静态无惯性条件模型；不描述齿刚度、冲击、摩擦、控制闭环和独立载荷运动。初态未知不允许默认y0=x0，不能用一次单向记录估计完整b，更不能把拟合b直接换算成实际齿侧长度而没有分度半径和拓扑。

实际TE可按给定齿侧、载荷和温度写为δψTE(χ,load,T)，与play支路明确分开，避免重复解释同一滞后。NASA-CR-176163 §2.5指出TE是齿轮副的工况相关量；仅靠一条曲线不能无条件归因到其中一枚齿轮。[M04](https://ntrs.nasa.gov/citations/19850026091)

## 4 周期误差应该按什么角度展开

一般写e(χ)=e0+Σh[ah cos(hχ)+bh sin(hχ)]，但χ必须明确是载架角θc、输出绝对角ψ、输出相对载架角φ、太阳轮相对载架角或某中间轴角。把所有谐波都按时间拟合，在变速时会掩盖来源；把不同χ的同频项都自由加入，则可能产生严格别名。

对确认的固定太阳轮直接外啮合，啮合相位可写χmesh=Zs(θc−θs)，其频率绝对值为Zs|ωc−ωs|/(2π)=Zp|ωp−ωc|/(2π)。这只给运动学索引，不保证TE只含啮合频率；偏心、齿距误差、调制边带和载荷变化都可能存在。太阳轮120齿不意味着“每圈120个厚度条纹”。有限曝光、积分时间、姿态映射与遮挡都会改变响应。

选择有限谐波阶数需用传感器带宽、抗混叠、采样覆盖和留出残差；不能按拟合残差越小越好无限加阶。合成参考不预设实机误差幅度，也不选择制造公差。

## 5 从轨迹到沉积的接口及导数边界

保留前两轮的有限时间接口：H(u)=∫Σs As(t) Ks(x,n,state) Vs(x,t)dt。As为源强，Ks含源空间/角度核，Vs为可见性；单位由T02实际通量模型定义，不能把任意归一化K直接当nm/s。

在固定光滑支集、无事件切换时，δH=∫Σs[(δAs)KsVs+AsVs(∇xKs·δx+∇nKs·δn)+AsKsδVs]dt。此处法向梯度沿单位球切空间理解；模型可用未归一化坐标延拓计算，但δn应满足n·δn=0的一阶条件。

硬遮挡的V是跳变函数，不能在所有时刻写δV=0就算完。若单事件根g(t*,p)=0且gt≠0，dt*/dp=−gp/gt；积分导数还包含(F左−F右)dt*/dp。切线事件gt≈0、事件合并、漏采样或几何unknown时，该表达可能病态或失效，应保持事件状态与不确定区间，调用T02专门事件积分/求交核验证。此接口没有修复T02源求积和时间参考的既有partial状态。

机械误差与源形状共享同一几何光路，因此灵敏度可相关；不能把机械CV和源CV平方相加就得到总厚度CV。全盘连续极值、实际膜厚及离子响应本轮均未执行。
