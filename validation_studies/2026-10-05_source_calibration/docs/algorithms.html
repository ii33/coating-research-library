固定几何 QCM → A/cosⁿ 标定

日期：2026-10-05。独立云端研究，未改变生产内核。

证据边界：全部数值均是合成实现核查。真实 QCM、有限晶体面积、有限源行星双掩模物理验证及完整指定模型审查未完成。

1. 合同、坐标及单位

固定腔体右手坐标，源节点 s、QCM 中心 x 均为 m，法向为单位向量。源节点权重 w≥0、Σw=1。输出 j 为 kg m⁻² s⁻¹；源总半球质量率 A 为 kg s⁻¹。QCM 接收法向朝源，因此入射投影为 μᵢ=max(0,−u·nᵢ)，其中 u=(x−s)/r。输入晶体面积为 m²，仅在总质量率→面质量通量时使用；点接收器核未执行有限面积积分。

图 1：原创合同示意图。同一轴对称源的六个同环、同高度接收器具有相同源角，即使方位不同也无法分离 A,n。

2. 前向核及归一化

pₙ(μₛ)=(n+1) μₛⁿ/(2π)，仅 μₛ>0；否则 pₙ=0
jᵢ=A ηᵢ Σₖ wₖ pₙ(μₛ,ᵢₖ) μᵢ,ᵢₖ/rᵢₖ²
∫前半球pₙ dΩ=1

η 是已知净捕集率。本研究自由分子、无遮挡、固定源几何。n=0 的背面仍不得发射；实现使用 front mask，避免 0⁰。实际计算直接复用既有 T05 Source/flux_kg_m2_s。点源的闭式式子另由测试独立核查，n=0/1/4 的归一化由 Gauss-Legendre 积分核查。

生产 source_samples 的 mm 节点可转为 m 输入上述接口。生产 simulator 的相对厚度场没有该 A 的量纲信息。研究没有把生产 nm/s 参数改名为 kg/s，也没有对生产全场求解宣称校准通过。

3. 加权有界非线性拟合

χ²(A,n)=Σᵢ[(A Kᵢ(n)−jᵢ)/σᵢ]²；A≥0，0≤n≤20
σᵢ=max(输入绝对标准差,严格正的绝对噪声底)
Â(n)=max[0, Σᵢ Kᵢ jᵢ/σᵢ² ÷ Σᵢ Kᵢ²/σᵢ²]
∂Kᵢ/∂n=ηᵢΣₖ wₖ pₙ μᵢ/r² [1/(n+1)+ln μₛ]

实现：calibration.py:fit_source。SciPy TRF 以缩放幅度 A/A_scale 和 n 求解，解析 Jacobian，固定初值 n∈{0,1,4,10,20}（按 cap 调整），最多 500 次函数评估/起点；ftol、xtol、gtol=1e-12。每个候选 n 用闭式 A 精修，补上精确端点。多起点不能证明全局最优。20 是声明的计算 cap，不是物理测量上界。使用给定绝对 σ，不按 reduced χ² 重新缩放协方差。

4. SVD、相关性与 n profile

J 对 [ln A,n] 白化：Jᵢ=[ĵᵢ, A ∂Kᵢ/∂n]/σᵢ
点源：∂ln j/∂ln A=1；∂ln j/∂n=1/(n+1)+ln μₛ
同一源角时第二列是第一列的常数倍 → rank≤1

相对奇异值阈值 1e-8、condition>100 和最大 SNR<3 均为本项目描述性约定。rank<2 或低信号时阻止片上预测；窄角 rank=2 仍会给病态告警。仅非边界满秩时提供 (JᵀJ)⁻¹ 与 ln A/n 相关系数，条件化于当前模型/噪声/几何。predict_fitted 的配置 ID 由调用方维护；其返回值只通过局部秩/信号/配置合同，不是工程批准的图，仍可能 cap-hit、病态或优化器未收敛。未来生产接口需另作严格收敛、不确定度及独立源身份门控。

在 401 个均匀 n 网格加最佳拟合点，对每个 n 剖面掉 A。Δχ²≤3.84146 区域是常规内点一参数渐近 95% 参照，不是边界、小样本、离散网格或模型失配下保证覆盖的置信区间。任何到达 n cap 的区域记上端未闭合，完整数组保留在 representative_profiles.json。

5. 工况 GP 与训练/留出

实现：condition_surrogate.py:QCMConditionGP。输入为功率[W]、压力[mTorr]；本示范 20 个整条件训练，5 个整条件留出。训练归一化范围、均值、幅度尺度与凸包只取训练集。RBF k=exp(−‖z−z′‖²/(2ℓ²))，固定 ℓ=0.65，无留出调参。每枚 QCM 独立输出；K 加已知噪声方差对角项及严格正的相对噪声底 1e-6²。Cholesky 解 α=(K+Σ)⁻¹(y−mean)，预测 mean+k*α，潜在方差 k**−k*(K+Σ)⁻¹k*ᵀ。

预测需配置标识相同且位于训练二维凸包。只在矩形包围盒内但凸包外的请求也被拒绝。对负预测明确拒绝，不悄悄裁正。输出方差不含未来测量噪声，也不含跨 QCM 相关漂移、超参数未知、物理失配或批间变化；因此不能作为总物理不确定度传递。

6. 反例及未运行项

合成恢复：A=2e-6 kg/s，n=0/1/4；测量噪声 0/1/5%，每格 20 seed，共 180 次。三个训练源角 8°/30°/55°；空间留出 0°/18°/40°/65°。另一构造有限源半径 .18 m、高度 .4 m；仅 1°/5°/10° 近轴训练并错用点源。这是特意构造的模型失配反例。完整绝对与相对误差、低信号诊断见 results。

如果输入是厚度，整体只能约束 A×η/ρ。没有独立 η 与膜密度 ρ，不得声称已识别总发射率。未知几何、历史同环半径、真实质量通量及噪声保持 null 并拒绝真实标定入口。未运行实机实验、几何校准、有限 QCM 面积收敛、有限源行星双掩模物理验证、主动学习及指定模型审查链。
