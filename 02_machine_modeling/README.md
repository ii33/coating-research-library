## 阶段验收标准

1. 精度指标、容差和测量基准已明确，未定值显式标记
2. 有独立参考或实验对照并报告误差与不确定度
3. 完成单位、守恒或极限情形检查以及网格/步长收敛检查
4. 模型版本、数据、计算配置、随机种子（适用时）可复现

共同门槛：关键结论能回溯来源与条件；有可复用结果、未决问题、失效/适用边界及下一阶段接口；审查结论有记录。资料完成、仿真验证、实测验证分开标注。研究范围有限，文献不要求无限穷尽；关键缺口不得隐藏。
