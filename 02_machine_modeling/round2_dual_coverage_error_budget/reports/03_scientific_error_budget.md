# 科学误差预算和适用边界

## 五类误差不能合成一个漂亮百分数

下表中的数值都是本轮合成比较，未作置信度解释。完整数值和单位在data/error_budget.csv。

| 类别 | 本轮证据 | 能说什么 | 不能说什么 |
|---|---|---|---|
| 时间离散 | 固定S1时T1→T2，主要积分最坏差0.085296%，τ差10.032 ms | 这13点上此离散变化较小，τ仍未达 | 所有时刻事件被捕获或全片时间误差有界 |
| 源求积 | 固定T1时S1→S2差0.535438%；最高源与第二求积族差0.202989% | 半影需独立源求积检查 | 后一差一定包住真误差，或τ已收敛 |
| 基片空间 | 固定S1T1时P1→P2均值差0.016290%，采样PV差0.000592374 | 给定核的面积统计加密通过 | 连续最大/最小已找到，或源/时间误差也通过 |
| 求交与几何表示 | slab对独立六面、解析侧壁；薄板化对照最坏差15.084% | 一般尺度内已列射线相符，板厚影响不可忽略 | 任意CAD、支架、自遮挡、极近切线或尺度变换可靠 |
| 几何输入与运动 | 两板各x±1 mm，最坏变化约1.02916% | 指定扰动包络的局部敏感性 | 真实板定位误差就是±1 mm，或95%置信度 |
| 校准与模型形式 | 没有真实源率、密度、留存、杯响应和坐标校准 | unknown，列数据需求和传播公式 | 数值通过等于生产精度、总误差或材料性能通过 |

空间离散、时间离散和源求积都是数值问题，但不独立，交叉项会改变半影事件。几何测量误差则是输入不确定性；把真实有限厚板简化成薄板属于模型形式差异。把这些统一称“网格误差”会使后续优化错误分配算力。

## 校准传播要用测量依据

若有输入θ的协方差Σθ，可在局部可微、近似线性的条件下用Σz≈JΣθJᵀ。未知系统偏差不能自动视为独立均值零噪声；源率与厚度标尺、材料密度与留存、两个通道共享时钟/法向的误差通常相关。硬遮挡与近零分母可使线性化失效，应采用有来源的联合分布传播或明确的区间情景。

本轮重新核对[BIPM官方JCGM目录](https://www.bipm.org/en/committees/jc/jcgm/publications)及[100:2008/Amd.1:2026](https://www.bipm.org/documents/20126/2071204/JCGM_100_Amd1_2026.pdf/18b8a72a-6caf-69e8-8bbd-dd13056a4a84?download=true&t=1785763281319&version=1.6)。该修订在非线性明显时要求考虑高阶项或JCGM101的分布传播；它不会提供本机未知输入分布。本次没有随意设置高斯先验或发布实验置信区间。

在这里N=Q_vK_v、D=Q_iK_i、h=N/n_atom。对总率和密度的对数灵敏度为∂ln h/∂ln Q_v=1、∂ln h/∂ln n_atom=-1，∂ln D/∂ln Q_i=1；R=D/N则对ln Q_i为1、对ln Q_v为-1。这些是条件解析灵敏度，可以告诉人需要测什么，不能变成没有校准证据的“误差只有若干百分比”。离子能谱未知时，单能100 eV也不能用标称加速电压自动证明。

## 保留的具体缺口

1. 主例源求积和τ未完全通过。预算完成后按partial状态冻结，不以空间均值平稳替代
2. 只有13个固定诊断点做S2/T2与留出求积；P2全部236点没有同时在S2/T2重算。主CSV为S1/T1，其状态必须随图和后续目标函数传播
3. 面积均值/CV与采样PV分开；没有连续全域极值保证。额外边界点不增加面积
4. 绝对1e-14 m平行阈值导致极近边界反例。独立复核保留真穿入而被当平行的病态射线，不能删掉此例后声称稳健求交
5. 零厚共面不挡与有限厚切线挡是不同数学约定。无限薄极限须排除该零测度集合，或重新规定共面接触语义
6. 比值统计只在有效区域成立。当前主例全有效，不意味着未来局部零沉积可被忽略
7. 合成有限离子盘是弹道代理，未解栅极束光学、空间电荷、中和、能谱、快中性、碰撞、再溅射或温度
8. C/I原图门槛、真实D结构、真实源和诊断坐标、真实产品容差均未解决；本轮没有实机验证声明

## 有界冻结含义

本轮停止并不表示已经耗尽所有允许射线，也不表示必须把每个目标做成全绿。四组预定检查、固定加密清单、一次窄独立核查与真实实现错误修复已足以定位下一步。继续无限加密会掩盖“该观测定义对半影支集敏感”这一需要工程决策的问题。后续T03可以用这套带状态的正向接口做误差感知优化研究，不能把当前数字直接用作加工或设备运行输入。
