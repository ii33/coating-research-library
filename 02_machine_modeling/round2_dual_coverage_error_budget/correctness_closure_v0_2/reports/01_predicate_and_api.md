# 求交判据、数值语义与公共 API

## 结论先行

固定绝对平行阈值会改变几何问题本身。新版完全去除该阈值：只有在**输入所表示的数学模型中方向分量等于零**才是平行。Python 标准库 `Fraction` 对给定 binary64 位模式进行有理运算，避免除法、局部坐标变换和接触比较中的继续舍入。

这是一条受限参考求交路径，不是已标定物理几何的“精确答案”，也不是原 NumPy 向量化核的性能替代。原 v0.1 文件未改；使用它的旧积分器仍保留旧行为。新旧模块不可通过相同布尔方法名静默替换。

## 1. 原反例为何发生

实体半宽 0.1 m、半高 0.2 m、厚度 0.04 m；局部坐标与实验室坐标相同。源点为 `(0.1+4e-15, 0, -0.1)`，目标为 `(0.1-4e-15, 0, 0.1)`。

实际存储的 x 位移约 `−7.993605777301127e−15 m`。旧实现把它与 1e−14 m 比较，归入平行；起点位于侧壁外，于是返回不挡。实际上射线进入盒体。增加常规随机样本、空间/源/时间网格，均不能修复这个确定性分支错误。

新版名义模型返回 blocked。它不是通过扩大板边界或把所有近平行射线当挡板修复，而是正确处理非零方向的两侧平面参数。

## 2. 有限厚实体与开线段

名义局部坐标为 `a_j = Σ_i (s_i−c_i) Q_ij`，`b_j = Σ_i (t_i−c_i) Q_ij`，所有输入首先按已存储数值转为有理数。

每轴要求 `−h_j ≤ a_j + λ(b_j−a_j) ≤ h_j`。非零方向给出闭参数区间，两端次序由数值大小决定；零方向且坐标在 slab 外则必不相交。三个轴区间与 `[0,1]` 求交，最后明确要求交集包含 `0<λ<1` 的点。

- 实体表面、边和角在开线段内部的接触均阻挡
- 仅在源或目标端点接触不阻挡
- 源或目标在体内、完全包含、面/边共面段均可正确判定
- 两端相同按参数化映射解释：若该点属于闭实体，则开参数域仍映到该点，因此实体分支 blocked；这不是有非零物理路径长度的声明
- slab 判据使用解析不等式；测试用独立逐面枚举/内部见证，避免只比较两份相同 slab 代码

## 3. 理想零厚板是另一种约定

`thickness_m=0` 时仅与中平面求交；要求 `0<λ<1` 且落在闭矩形内。严格共面射线不挡，端点-only 接触不挡，与旧模型的明示约定相同。非零但小于 1e−14 m 的法向位移仍正常判定。

这意味着零厚共面“不挡”与任意正厚度的共面“挡”不连续。不能通过取厚度趋于零，跨过该例外集合宣称语义连续或物理正确。

## 4. 编码几何与测量/表示不确定性

有理运算只消除本求交器内部继续舍入，不能恢复进入 Python float 之前丢掉的有效数字，也不能让由 sin/cos 得到的 Q 变成理想正交矩阵。

代码检查 Q 的有理 Gram 残差不超过 1e−12、行列式正，但不会正交化。名义几何严格定义为 `|(x−c)·Q[:,j]|≤h_j`；一个近正交而非精确正交 Q 给出的形体是该组半空间的交。称它为精确理想旋转矩形是不当的。真实旋转、测量、单位转换、上游 pose 计算误差须作为单独输入不确定性处理。

### 提供 `local_margin_m=m>0`

调用方应保证：对于线段上所有参数，名义局部坐标与实际局部坐标之差的逐轴绝对界，加上该轴边界位置误差绝对界，不超过 m。若只知道端点坐标误差，仿射插值的逐轴误差由两个端点最大界控制；若旋转、中心、几何边界也不确定，必须把它们造成的最坏局部误差一起包含。m 不是代码自动估计的机器精度或实机置信区间。

有限厚体：

1. 名义线段不触及各轴扩张 m 的盒体 → clear。任何满足假设的扰动都不可能阻挡
2. 名义线段触及各轴侵蚀 m 的盒体，且侵蚀半宽均非负 → blocked。此处存在一个共同开参数见证，在所有允许扰动下仍在实体内
3. 其余 → unknown

这是充分条件，不是全部可能不确定几何的最紧分类。侵蚀可空，unknown 可能较宽。对于正 m 的理想零厚板，新版仅证明远离膨胀体时 clear；其余都 unknown。它没有实现更强的区间平面穿越证明，因此普通明确穿板也可能 unknown，故意保守。

边界上的名义精确接触在 m=0 可按约定分类；一旦输入不确定性足以改变接触，就不会静默变透明。若调用方不给 m，返回的是**条件于输入已确定**的名义状态，不能解释为数值/测量精度证书。

## 5. 数值范围和失败方式

详见先写下的 `verification/PRE_REGISTERED_PROTOCOL.md`。点/中心/一般非零标量绝对值须在 `[2^-200,2^80]`；宽高/正厚度须在 `[2^-80,2^80] m`。Q 系数绝对值≤2，且符合前述检查。允许精确零。过小的非零量、非有限值、错误形状、反射/非正交框架、负 margin 或尺寸，以及大于4096条的单批，明确报错。

单位仍是 SI。量纲转换应同时改变点、中心、尺寸及 m，不能只缩放方向。有限 admitted domain 控制有理数位长与算量；没有覆盖任意十进制、任意精度输入、任意单位系统、任意CAD或超出范围的极端数据。输入只接受 Python int/float；NumPy 调用方须显式 `.tolist()`，不得依赖旧广播行为。

## 6. 三态与区间如何向上层传播

公共入口：

```python
from models.robust_mask import RectangleMask, Verdict
mask = RectangleMask(center, Q, half_width, half_height, thickness)
result = mask.classify(source, target, local_margin_m=margin)
result.verdict                 # blocked / clear / unknown
result.transmission_interval   # (0,0) / (1,1) / (0,1)
```

- `bool(result)` 总是抛 TypeError，不能把 unknown 当 False
- `combine_masks(results)`：任何一定阻挡板使总状态 blocked；全 clear 才 clear；其余 unknown
- `blocks_conservatively()` 明确将 unknown 作为挡板，只得到非负透过量的下界，不是所有派生指标的“保守值”
- `transmitted_sum_interval(nonnegative_contributions, results)` 要求每项已包括源权重、时间权重及名义无板核，返回各透过区间乘这些非负项的和；内部按有理数求和，再朝外舍入到 float
- 此函数只包住有限给定节点上的可见性不确定性；不包住核函数计算误差、源/时间求积遗漏、材料/校准误差。不能把它写成总模型误差区间

后续若 N∈[N_lo,N_hi]、I∈[I_lo,I_hi] 且 N_lo>0，可得比值外包 `[I_lo/N_hi, I_hi/N_lo]`，实际浮点实现也须朝外舍入。若 N_lo≤0，不得给有限的相对精度，须标为无定义/无界或待定。这个比值传播是接口说明，本版未实现通用区间积分器。

离子独曝时长中的 `I>0且N=0` 是非连续存在性事件：任一相关节点/时间有 unknown 就须传播待定状态或0/1事件区间，不能把离散上界的零、微小正数或 unknown 自动变成精确时长。边界保守blocked可低估两个通道，但比值和独曝时长都不保证同向保守。
