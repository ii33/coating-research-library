## 当前结果

- 旧极近侧壁例已重现：旧阈值版返回 clear；新名义判据、独立有理六面 oracle 均返回 blocked
- 8,265 组名义几何比较零差异：23确定性、240尺度/符号/反向、2平移、6,000固定种子普通、2,000固定种子近边界/近平行/近零厚板射线
- 名义结果：1,452 blocked、6,813 clear。该路径条件于存储输入确定，因此没有 unknown
- 正 margin 的4个实体样例为1 blocked、1 clear、2 unknown；256个端点扰动见证均被输出可见性区间包含。另检查正 margin 薄板的远离 clear / 可能接触 unknown
- 18项非法输入/尺寸/框架/批量/权重拒绝测试通过；三态不能强制转 bool，多板并集与朝外舍入的非负离散求和通过
- 主套件每次求交/oracle调用共16,798次；第一次约2.3秒，修复API后的第二次约3.0秒，仅为此解释器和本固定小例的记录，不是生产性能基准

完整字段、输入位模式、固定种子、代码哈希和每次执行预算在 `data/check_results.json` 与 `verification/execution_ledger.json`。主套件默认只读，不写证据；作者显式 `--record` 才写结果。最终又在只含17项允许文件的隔离临时目录中运行一遍只读主套件和--reader哈希校验，无ZIP、父目录或第三方原件，全部通过。三次主运行累计50,394 / 160,000次，独立复核另计11,422次。临时副本已清理。

## 一次独立窄复核

独立初次复核发现2类API缺陷：公开构造的字符串verdict经并集可误判clear，空批量未拒绝负margin。已增加严格Verdict类型检查和空批量margin校验，补入5项主回归；最初失败证据保留，仅对受影响API做最终局部复看。

最终独立复看185条断言通过，只新增24次predicate、0次oracle。初次加最终独立累计11,422次，未第二遍完整随机套件。

最终结论和独立资源计数见 `reviews/INDEPENDENT_REVIEW.md`、`reviews/independent_results.json`。独立复核只针对本新增求交与三态 API，不针对整个研究库或源/时间积分。若独立检查发现缺陷，修复和最终哈希必须随这些文件一并记录，不以先前通过替代最终实现复核。

## 比较的强弱

随机零差异不是完备证明。这里还具有名义实体的线性 slab 解析判据和有理数计算语义，测试的作用是找实现/约定错误，并非估算“漏挡概率”。六面 oracle 与 slab 独立组织算法，但都使用 Python Fraction 和相同输入模型；它不是独立硬件、定理证明器或真实设备真值。

尺度试验只使用预登记的2的幂，方向/符号由24个proper signed permutations覆盖，以避免在测试变换中悄悄加入未记录的舍入差异。旋转普通测试另外使用存储的sin/cos系数。平移只有两组仍可表示原扰动的平移，不宣称任意大平移保持原理想输入。

margin扰动样本只是实现检查；其包络理由来自膨胀/侵蚀的充分条件，而非因为256个采样全通过就把采样极值当严格误差界。实际用户提供的 margin 是否有效，本版无法替其证明。

## 未改变的失败和缺口

v0.1冻结数据未重算、未改写：最高两种源求积族主要积分差约0.203%，离子独曝时长差约14.3 ms，超过10 ms阈值。源/时间partial_numerical_acceptance继续保留，空间均值平稳不等于完整模型收敛，经验网格差不构成总误差界。

本闭环没有量化该极近边界反例对原厚度图的影响，没有更改源/时间/基片网格，没有确定连续最坏点，没有真实几何/源率/离子束/材料校准。D仍只是条件合成基线，C/I仍unsupported。

## 后续T03能否用作oracle

可以：在已给定存储坐标、矩形半空间约定、数值域及可承受小批量内，用本模块作为**求交子问题**的名义参考；对明确给定局部不确定界的几何，用它提供保守可见性区间与unknown见证。更快求交实现若声称等价，必须对照同样端点/接触/薄板约定。

不可以：把旧 `dual_finite` 整个前向模型或本小模块直接称为经认证的优化oracle；不能因为求交闭环通过就让源/时间误差、未知校准、连续极值或非连续独曝事件自动通过。若未来优化依赖该谓词，应先显式接线三态/区间，禁止unknown→透明；比较目标区间相互重叠时应标不可判序。本次没有进入T03、未运行候选优化或改产品。

停止条件已固定：完成列出的有限测试与一次窄复核即停，不通过增加随机种子或源/时间大网格追求全绿。
