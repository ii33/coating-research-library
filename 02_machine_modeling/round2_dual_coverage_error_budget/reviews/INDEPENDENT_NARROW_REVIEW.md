## 1. 独立几何检查

独立算法不计算 slab 进入/离开区间，而在实验室坐标系逐个求六个面的平面交点，检查交点是否位于该面闭矩形以及参数 `0 < λ < 1`；加上线段中点的实体内见证，以覆盖完全包含及共面段。平行判定使用精确零，与原实现固定长度阈值不同。

随机组：6 个随机旋转和平移的有限厚矩形实体，每组 10,000 段；既有普通均匀段，也显式覆盖端点在内和穿透族。全部布尔一致。确定性组覆盖前后穿透、只击侧壁、平行外部、完全包含、内外端点、只在开线段端点接触、共面面接触、边/角切触，以及边界内外 ±10⁻¹² m。15 项均与预期一致。零厚理想板另核对横穿、首末端点排除、共面排除约定，共 4 项通过。

极近边界例采用半宽 0.1 m、半高 0.2 m、厚 0.04 m，源点 `(0.1+4e-15, 0, -0.1)`，靶点 `(0.1-4e-15, 0, 0.1)`。中点位于侧壁和实体内部高度；后半段存在真实实体内部分。slab 将 x 分量作平行且起点在外，故未阻挡；六面法阻挡。该例说明固定绝对阈值存在几何尺度局限，记录为 caveat，不作浮点严格证书，也不外推到实际设备误差大小。

## 2. 总粒子率归一化与投影一次

令均匀圆盘半径 a，总发射粒子率 Q，半球角分布

`f_p(θ) = (p+1)/(2π) cos^p θ`，仅 `cos θ > 0` 有发射。

因为 `∫半球 f_p dΩ = (p+1) ∫₀¹ μ^p dμ = 1`，Q 是全部上半球的总粒子率，而非轴上强度或单位源面积率。盘面积元分配 `dQ = Q dA/(πa²)`；离散节点的 fractions 必须总和为 1。不能再把盘面积乘入已经归一化的源权重。

接收通量为 `dQ f_p(θ_s) max(cos θ_i,0)/R²`。此处源发射角余弦包含在 f_p 内，接收面投影因子仅出现一次；p=1 时出现源角和接收角两个不同物理余弦是正确的。

轴上高度 h>0、接收法线向源时，R²=h²+r²，两个角的余弦均为 h/R。直接积分得

`K_p = Φ/Q = [1 − (h/√(h²+a²))^(p+1)]/(πa²)`

特别是 cosine 源 p=1：

`Φ = Q/[π(h²+a²)]`

零半径极限 `K_p → (p+1)/(2πh²)`，符合归一化点源。脚本采用 expm1/log1p 稳定表达式作解析参照。

数值检查 p=0、1、12：半球归一化最大偏差 7.11×10⁻¹⁵；轴上核在本次浮点精度下与公式一致，满足预登记 10⁻⁸ 相对阈值。p=1 对称盘轴上，将接收面法线倾斜 0°/35°/70°，且全部入射保持正面，通量比分别应为 cos β；实测最大绝对差 2.22×10⁻¹⁶，排除了该检查中额外一次接收投影的实现。

## 3. 三点独立源求积

选择半径 0.15 m 的合成 cosine 盘与三个固定接收点（含两个离轴倾斜法线点），不加遮挡板。原方法采用 Gauss 于 r² 加均匀方位；独立法采用

`x=a sin χ, y=a cos χ v`，`χ∈[−π/2,π/2], v∈[−1,1]`

雅可比 `a² cos²χ`，归一化面积权重 `cos²χ/π`，在 χ、v 上分别 Gauss；独立编写核与权重，不调用 Source 或 transfer_kernel。31² 和 61² 节点对照，原实现使用 32×67 节点。

- 独立法两级最大相对变化：6.003×10⁻¹⁵
- 原方法与独立法最大相对差：2.711×10⁻¹⁵
- 权重总和偏离 1 不超过 2.7×10⁻¹⁵

这是有限三个平滑、静止、无板点的经验一致，另有轴上解析锚点。没有做 D 运动/遮挡时间非共振检查，没有读取主例配置；它不证明遮挡不连续、主例时间、基片连续最坏点或全域源收敛。两套结果接近本身不是普适误差界。

## 4. 近零分母与误差预算措辞

选读输出函数确实在 N≤0 时将 R 和 ε 置 NaN，在 N>0 时才计算。合成 `N=[−1,0,10⁻¹⁶,1]`、离子通量均为 1、单离子能量 100 eV 时，R 为 `[NaN,NaN,10¹⁶,1]`，ε 为 `[NaN,NaN,10¹⁸,100]`。微小正 N 产生巨大但有限的值，不能仅靠有限性筛选认为可信。

原 statistics 会删除非有限值并将剩余正权重重归一，因此给出的均值是有效子域条件均值。主实现现已在 metrics 中提供 `finite_area_fraction=0.5` 和 `nonfinite_witness_count=2`，本次复核值正确。仍应在报告保留这些字段，不把条件均值写成全基片均值；有限但病态的点还需要单独 conditioning 标注。

零尺度修复复核：全部为零的积分比较返回 0 且显式 `zero_channels_exact`；零参考通道有非零差异时返回 inf 且 `undefined_zero_reference`；其他通道的真实差异不会被 0/0 吞掉。统计均值为零且 CV/PV 为 None 时，stats_compare 返回 inf 和 `undefined_or_nonpositive_reference`，不再异常或表面通过。

对 `R=I/N`，若有可信绝对误差估计且 `η_I=ΔI/|I|`、`η_N=ΔN/N<1`，可用 `(η_I+η_N)/(1−η_N)` 作为相应有界扰动的相对变化上界；一阶近似为 η_I+η_N。固定单离子能量时 ε 与 R 具有相同分母条件数。这里的“有界误差”是附加前提，经验网格差不能自动满足它。若未来把 N 写成沉积与移除的差，须先传播绝对误差再除以净 N；本次模型明确排除再溅射，不据此引入新物理。
