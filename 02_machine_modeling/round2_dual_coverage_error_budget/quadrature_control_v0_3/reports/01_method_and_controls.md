# 方法：把阴影不连续从采样函数移入积分边界

## 1. 有限适用域

只接受冻结D合成配置：平行水平基片，局部点z=0、半径≤0.06m，轨道0.312m/0.25rps，绝对自转13/12rps；均匀有限盘蒸气与离子源、静止水平有限厚矩形板。蒸气指数p=1、离子p=12；源总率、gate和100eV合成能量沿用冻结值。不是任意CAD或任意源分布API。输入含非有限数、越域点、未知rate形式或无效控制应拒绝。

新参考没有将Fraction求交用于所有求积。v0.2只作少量近边界名义/unknown检查；投影法是另行推导的低维积分，不把v0.2正确性自动传到整个前向模型。独立核查会用原字节v0.2模块比对少量射线。

## 2. 厚板的中心投影

目标X、源面中心C、单位法向n，板顶点V。dX=n·(X−C)，dV=n·(V−C)。当所有顶点0<dV<dX时，投影到源面为

P = X + dX/(dX−dV) (V−X)。

投影分母保持同号，凸实体投影恰为八个顶点投影的凸包。光线被实体挡住，当且仅当源点落在该凸多边形内（边界零测度不改变源面积积分）。因此厚板前后面与侧壁都包含，不能只投影中面。

本特例每个通道只需自己的板。另一块板可用全时刻坐标界排除：Xx∈[−0.372,0.372]m；vapor→ion板在其z层的射线x保持正值，远大于ion板最右−0.37m；ion→vapor板在其z层射线x≤约−0.20m，低于vapor板最左0.175m。独立核查给出具体保守数值。这个排除不允许复制到变化后的板位置或未知几何；若一般两板阴影共同拼合遮盘，须对区间取并集，不能以“任一单板包含盘”替代并集包含。

## 3. 源积分降为一维

源局部坐标(x,y)，盘x²+y²≤a²。固定x时，凸阴影给出一个blocked y区间；与圆的[−√(a²−x²),+√(...)]相交后，剩余至多两段visible区间。计算可见段，不用近全遮情况下的“大总量减大遮挡量”。

源面局部目标为(ξ,η,d)，A=d²+(x−ξ)²，z=y−η。两种源的basis_v均沿实验室y，因此接收面投影的分子只依赖x。含一次发射余弦与一次接收投影的核为

K(x,y) = (p+1)/(2π) · d^p · (Xz−Sz(x)) · [A+z²]^−((p+3)/2)。

均匀源面积密度另除πa²。对p=1，使用

∫(A+z²)^−2 dz = z/[2A(A+z²)] + atan(z/√A)/(2A^(3/2))。

对p=12，从I_(3/2)=z/[A√(A+z²)]递推到I_(15/2)：

I_s = z/[2A(s−1)(A+z²)^(s−1)] + (2s−3)I_(s−1)/[2A(s−1)]。

由此y不再离散采样；x在凸包顶点和圆/边交点处显式分段，交给一维自适应Gauss–Kronrod。外层时间再自适应，预拆gate、固定时间面板、已知支集窗口和rate事件。相比二维源节点直接乘bool，该方法避免部分阴影被固定源网格错过；仍需检查剩余x/time误差。

目前Q为近正交binary64系数。解析降维遵循其理想正交源面语义，与原离散浮点运算并非位级同一公式；低维结果标估计，不能声称复现有理数意义下每次浮点运算。

## 4. 独曝duration必须按连续支集处理

在本均匀盘、正rate、发射/接收核严格正的条件下，源通量>0等价于存在正面积visible源域。离散节点“至少一条射线可见”不是此条件。

设源盘中心在原点，阴影凸集P(t)，g(t)=min_|n|=1 h_P(t)(n)−a。g≥0表示整盘被遮；g<0表示正面积可见。原点在P内时min h是到最近边的距离；原点在P外时为−dist(0,P)。代码由凸包边/线段计算，不依赖源节点。

h的变化受凸集Hausdorff位移界控制。蒸气投影随X的缩放系数最大0.21/(0.6−0.21)，|X'|≤0.312π/2+0.06·13π/6<0.899m/s，故|g'|<0.484m/s，代码用0.5。离子中心投影用导数范数界 dV/(dX−dV)+dV|X−V|/(dX−dV)²，再乘|X'|，代码采用6m/s；独立核查复算该保守界。

时间区间中点m、长度h：若g(m)>Lh/2+δ，整区间遮满；若g(m)<−Lh/2−δ，整区间可见；否则二分到固定leaf_width，余下unknown区间保留。因此不会仅凭两个采样端点同号忽略窄事件。duration下界只数“ion确定可见且vapor确定不可见”，上界还计入可能满足的unknown段；gate外单独处理。

δ=1e-11m是本次显式浮点guard，不是经形式验证的libm/凸包误差上界。所以数学上的Lipschitz包络为条件结论，实际数值区间标`conditional_lipschitz_enclosure_not_validated_float`。成为严格界还需经验证三角函数/投影/凸包区间实现或可审计舍入分析。若rate为零或未知高频，在source几何支集之外还要处理rate支集；driver对非严格正rate拒绝给出duration认证。

## 5. 估计与界分开

QUADPACK的abserr是估计；相邻/异族结果差也是估计。嵌套积分的误差理论上满足“外层误差 + 对全时间域内层误差的积分”，但采样时记录的max source abserr不是连续全时间严格上界，不能塞进该式冒充认证。参考base/tight一致、无warning、异族/错相位检查只建立有限数值可信度。

积分报告N绝对误差atoms/m²、D绝对误差ions/m²及点相对误差；为追踪旧0.203%，另保留冻结13点留出均值归一化。duration报告s/ms，不拿百分比掩盖10ms门槛。能量在本单能条件下只是D×100eV，不算新的独立证据。
