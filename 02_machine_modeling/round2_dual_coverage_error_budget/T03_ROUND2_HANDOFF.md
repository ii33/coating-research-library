# T03 第二轮建议 误差感知的双覆盖板形研究

## 可复用的边界

本轮D条件基线、冻结源/实体代码、同一时钟和单位规范可复用。所有板对两通道均不透明，V_v和V_i必须由各自射线产生。主例C的数值资格是partial，不得将其主图称作高精度真值。未达项为源求积与τ；连续极值、P2全点S2/T2、极近掠射稳健性、物理校准仍未知。C/I结构源图继续unsupported。

## 建议下一项只做一个有界任务

研究“修正板优化目标如何继承双覆盖数值误差”，不同时扩展任意CAD、CFD/PIC或真实材料响应。

1. 先冻结三种候选：无板、首轮已有参数板、一个有限厚度小扰动板。使用已有T03带厚度包络检查的缓存或不剪枝流式核，不另造全局自由形状优化器
2. 目标同时看h均匀度、D或R/ε允许区间及吞吐下限。h相同但D×2的反例必须作为回归；τ若仍定义Γ>0应附未达状态，不能把阈值换掉而不告知
3. 训练核和验证核分开。验证至少改变源求积族、时间非整倍数、边缘/未见空间点；比较目标的差异是否超过各候选数值差。候选间差小于数值不确定区间时判“无法分辨”，不排伪精确名次
4. 缓存键包含源位置/尺寸/法向/指数/率历程、节点及权重、两通道的物种和能量、板完整位姿/厚度包络、工件pose、clock、面积/见证点、密度/留存模型与代码哈希。任何相关项改变即重建；禁止套用蒸气遮挡矩阵到离子
5. 预先限制候选数、评价次数和射线预算。完成有限比较与一个窄核查就停止；未达精度或优化无明显改善是可接受的研究结果

## 接口建议

F_dual(theta_plate, scene, process, observation, numerics)应返回逐点N_net、h、D、U、R、ε、τ和量纲；逐量有效面积占比/无定义点；面积统计和见证极值；源/时间/空间工作数；单轴、交叉、留出误差状态；几何浮点/模型适用域；所有依赖版本。若分母误差与分母同阶，R/ε目标必须标病态而非给优化奖励。

真正移入实机前需要可追溯结构/输出轴、位姿、源与束图、板厚及机械归属、同步门控和相位、观测面积基准、净留存和材料响应数据，以及真实产品容差。缺这些不阻止公开方法研究，但阻止生产资格或真实加工尺寸结论。本移交不修改根状态，也不自动启动下一专题。
