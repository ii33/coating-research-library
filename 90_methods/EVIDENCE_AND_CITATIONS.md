# 证据、引用与合法存档方法

## 证据层级

层级描述来源类型和核验要求，不机械保证真实性。原始实验可能不适用于另一设备，厂家资料可能只对应特定配置，标准也不替代产品测试。

- A：针对命题适用的原始研究、官方标准发布资料、正式技术文档、可追溯本项目实测数据。分别记录同行评审状态、标准版次、厂商利益关系与实验质量
- B：高质量教材、综述、权威手册或有明确方法和来源的二次综合资料；追查核心结论的原始出处
- C：有条件和设备信息的厂家应用案例、工程记录、可审查实验报告；可用于形成假设，泛化需验证
- D：社区、论坛、口述经验和缺少完整条件的案例；保留上下文与原始链接，标为经验线索，绝不能当已验证工程事实
- U：身份、版本、内容、测量条件或权利尚不清楚的来源；不能支撑确定性结论

将“来源等级”与“具体命题验证状态”分别记录。命题状态至少有：reported（来源这样报告）、cross_checked（有独立交叉证据）、derived（本项目推导）、simulated（仅模拟）、measured（实测）、validated_in_scope（在明确适用域内验证）、unverified、contradicted。

## 每条结论的证据链

`结论ID → 来源ID/数据ID → 页码/章节/图表/方程 → 条件与单位 → 推导/核验方式 → 限制 → 报告版本`。

引用格式示例：`[SRC-000001, §2.3, Fig.4]`。最终报告同时给完整作者/机构、标题、年份/版次、出版物/发布机构、DOI或稳定URL、访问日期。网络搜索摘要只作线索，重要结论须读取原始页面或文件；无法读取明确写出限制。

## 来源摘要要保存什么

研究问题、来源身份与版本、与本专题相关结果、实验/仿真假设、设备/材料/测量条件、参数与误差、适用范围、与其他来源冲突、待复核问题、原文定位、版权/许可与存档位置。摘要用自己的话，不以长篇复制替代摘要。

## 合法原文

1. 不把“网上能看到”当作允许整篇复制。记录许可证、公开存储库授权或其他明确保存依据
2. 只有确认可合法保存时才将文件放入`sources/originals/`，登记SHA-256、来源链接、访问时间和许可依据
3. 付费、访问受限或权利不明的全文不复制、不绕过限制；保留元数据、合法短引与原创摘要。用户已拥有的受限文件也不能据此扩大传播权限
4. 不在汇总ZIP或分享中自动包含受限第三方全文；每次打包重新检查`redistribution_allowed`
5. 原始网页后续变化或下线时，保留先前摘要和已合法存档版本，标明引用版本及检查日期

## 标准与供应商身份

标准必须核查完整编号、发布机构、版次、修改单、生效/失效/替代状态、适用范围与具体条款；仅凭编号或网上二手摘要不能判断适用性。用户已确认H4为常见的高折射率材料；具体来源涉及配方/牌号/批次/规格时需记录并核对，不自动假定不同来源的H4完全等同，也不把供应商答复设为资料研究前置条件。原文ybf3已由用户确认是氟化镱YbF3，保持原文映射，绝不替换YF3。

## 从资料到工程建议

建议应标注设备、材料、工况、目标、证据、风险和验证方案。没有真实校准/实验时使用“待验证建议”，不得给出“保证达标”“通用最优”等结论。人员、设备与工艺安全需由合格人员依据真实设备说明与现场条件审核。
