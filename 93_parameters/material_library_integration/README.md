# 既有材料研究接入包

2026-10-04。先复用研究，再补结构化断点。本包没有重新进行一轮同题文献研究，也没有将目录参数提升为机台标定结果。

## 覆盖

- 原始12种膜：Ta2O5、ZnS、TiO2、YbF3（氟化镱）、SiO2、MgF2、Al2O3、H4、Ge、Cu、Cr、Al
- 原始4种基片：ZnS、Ge、K9、ZnSe
- 已有专题ITO薄膜：30组成套样本观察，保留装置、样本、源料组分、电学/光学配对条件和冲突记录
- T04第二轮实际研究的熔融硅石：只标为方法示范基片，不替换原始优先基片
- 10种源容器角色：W、Mo、Ta、Pt、石墨、玻璃碳、FABMATE、铜炉床、Al2O3坩埚、TiB2–BN复合衬里。它们是相容性候选索引，不宣称具备完整热物性

总计28个“材料×角色”条目，不是28种已验证蒸发材料。H4、ITO、K9以及复合/商标材料不赋虚构唯一化学式。化学式相同的膜、基片、容器仍保留独立身份。

## 可用性与真实缺口

| 层次 | 已有并接入 | 限制 |
|---|---|---|
| 来源化显示与筛选 | 全部207条T04属性，49条旧卡片中的新增结构化数字，T05相容性，ITO样本记录 | 工艺条件和原文状态必须显示；不能用design_ready=false隐藏已有值 |
| 光学参考 | 条件化n/k、同数据集插值、bulk色散模型及单独标记的代理上下文 | 不跨样本拼n/k；k未知不填0；代理理想假设不是测量 |
| 蒸气压 | ZnS两个原厂锚点；Al2O3、Ge、Cu、Al单点 | 单点不足以定两参数曲线；工作温度不是第二锚点；氧分压不是材料蒸气压 |
| ZnS热力学/HK | 保留已核RI8301补充原始参数与公式复核路径，现有产品计算核由接入方维护 | 1180–1210 K气相式；其他温域标准态不同；传输/蒸发系数、孔面积、气相组成必须明确 |
| 热模型 | 部分源块材和基片热物性、既有源模型算法 | 未有所有材料高温粉床k、cp、接触热阻、发射率/能量吸收；不把bulk/QCM/膜密度混用 |
| ITO电光 | 30样本配套观察、过程证据与电光机制来源 | 无同批项目标定；Far2012不自洽数据隔离；不同透射定义不能统一排名 |
| 机台绝对预测 | 没有宣称完成 | 需要实际批次/几何/温度/流量/到片通量和见证片；多找论文不能代替机台标定 |

此批不因为缺少机台实验而阻止文献参考功能。反过来，目录能显示也不意味着自动生成生产设定。当前全部定量数据为display-only；不写入求解器隐式默认值。

## 文件和复现

- `build_catalog.py`：只读取既有本地研究和新增抽取清单的确定性构建器，无网络请求
- `card_extractions.json`：旧卡片报告→机器记录的49条结构化增量，带原来源ID/单位/状态
- `researched_materials.json`：接入快照，保留原始记录、样本配对、条件、来源标题/URL、访问范围、源路径
- `coverage.json`：计数与快照SHA256；数字不表示独立论文数或独立样本数
- `validate_catalog.py`：源解析、未知/隔离/身份/单位、完整继承和本地输入哈希复核

执行：`python 93_parameters/material_library_integration/build_catalog.py`，再执行同目录`validate_catalog.py`。

`input_files`的34项SHA256是本次真实读取的本地源文件字节核验，不冒充全部远端研究库的逐文件核验，也不冒充出版社原件验证。T04/T05第三轮依赖副本和合成模板不重复变成新材料证据；既有ZnS复用审计保留其远端基准和图像缺失说明。源PDF未随本包重复归档或开放权限。

接入约定：`ZnS_film`可映射现有产品`zns`条目，但不得合并`ZnS_substrate`。`response_contract.fields.*.value=null`若存在evidence_refs，含义是未选择匹配记录，不能解释成“无来源数据”。source_container条目不得绑定为膜层。由产品任务复制此JSON并验证哈希；此包本身不推送GitHub。
