# TFCalc 3.5：功能证据、独立算法设计与验证准备

研究日期：2026-10-05。本文为原创分析与改写，不包含原手册的整页复制，不执行 TFCalc，不读取其程序内部实现，也不涉及许可或授权绕过。

## 1. 结论与证据边界

1. 核心基线是用户提供的 01.pdf：TFCalc for Windows Version 3.5，版权 1985–2002，共 92 个物理页。该文件包含 Windows Basics（Section 1）、Guide to TFCalc（Section 2）及索引；总目录引用的 Section 3 Optimization Guide 没有包含在 01.pdf 中。
2. 04.pdf 是封面日期 2010 年 4 月的中文资料，共 56 个物理页。其物理第 32 页开始包含“第三部分 TFCalc 优化指南”，至第 38 页前半段结束；之后包含实例。该指南可以补足实用技巧，但其版本对应关系未充分确定，存在译文错误，不能用封面日期推断它完整对应某个 2010 版本。
3. 02.pdf 是 18 页的代理商功能/升级概要，不是另一份完整的英文手册。DLL、WDM、Reoptimize 在其中作为另行产品介绍；不能全部混作基本 TFCalc 的功能承诺。
4. 01.pdf 明确给出三类局部优化：Gradient、Variable Metric、Simplex。手册没有给出“阻尼最小二乘法”名称，也未公布 Variable Metric 是 BFGS、DFP 还是其他更新式；Simplex 未明确注明 Nelder–Mead 及具体系数。独立项目可以采用公开算法，但应标注为项目选型，不能称为复原了 TFCalc 的内部求解器。
5. 已建立 74 项双语功能证据，见 feature-evidence.csv / feature-evidence.json。每项有物理页、印刷页、输入、输出、文档行为、未知实现及独立项目建议。另有 22 项解析/行为验收夹具，见 validation-oracles.json。

页码约定：物理页始终从 PDF 第一页计数，从 1 开始。印刷页带章节，例如“01，物理 p53；S2 p43”。对 04 使用“物理 p34；印刷 p33”，不把其连续印刷页误写成英文 Section 2 页。

## 2. 容易决定项目成败的建模约定

### 2.1 层序与方向

01，物理 p13 / S2 p3：第 1 层紧邻基底，前、后表面均可有膜层，光可以先遇 Front 或 Back。数学求解器通常按光线经过的顺序存层，这与界面中“从基底向外编号”不同。数据模型必须明确层序，而不是在多个模块里凭经验倒序。

建议保存：front_layers_substrate_outward、back_layers_substrate_outward、first_surface。仅在求解适配器中生成 incident-to-exit 的实际传播序列。反向入射、层序反转、前后表面交换是不同操作，不能互相代替。

### 2.2 厚基底不是一个额外相干薄膜

01，物理 p21 / S2 p11：基底是 massive/bulk medium，不产生干涉，仅在吸收时衰减。基底/出射介质不同或存在背面膜时计入背面反射及多次往返；基底与出射介质相同且无背面膜时，计算进入基底的透过率，等同无背面反射的终端半无限介质。

更重要的是观测量不共用一个背面模型：01，物理 p68–69 / S2 pp58–59，有限基底的 R/T 假设非相干光源；phase-change、psi 和 EFI 则始终忽略背面反射，采用无限基底。手册没有在这段为 GD/GDD/TOD 单独解释有限基底政策，不能自动推断一个能代表整个非相干组件的单一复透射相位。

独立应用应让输出携带 model_assumptions。至少区分“相干前膜复振幅”“含非相干厚基底的总功率”“无背面 EFI”。更通用的相干/部分相干基底是扩展功能，需要另外定义，而不是静默改变旧行为。

### 2.3 折射率、相位、单位

01，物理 p13 / S2 p3 使用复折射率 n−ik；正 k 吸收，负 k 增益需配置允许（p42 / S2 p32）。新算法可采用 e^(−iωt)、N=n+ik、前进波 e^(+ik_z z)，但导入数据、相位符号和 GD 符号必须统一。

01，物理 p10 / S1 p6：Muller 约定在正常入射时反射 P/S 相位相差 180°；Abelès 相同。这个约定影响 P 反射复振幅符号，不应改变 R/T。平均偏振的强度是两偏振强度的平均，不能把它当成一个相干振幅平均。01，物理 p74 / S2 p64 提醒正常入射保存相位到 illuminant 要选 P 或 S，Average phase 在其定义中是 P/S 相位之差。

物理厚度通常为 nm，基底厚度为 mm，目标超快量为 ps、ps²、ps³；内部建议统一 SI，并在所有接口明确单位。普通 QWOT=4 n d / λ0。吸收材料的实数近似显示使用 n 的实部，不代表获得了完整的复相位厚度。

### 2.4 表格及色散

01，物理 p42 / S2 p32：材料表线性插值。配置 p10 / S1 p6 决定超范围时保持最近端点，或警告；手册称 endpoint holding 为“extrapolation”，并非线性外推。独立项目采用明确的 clamp / warn / error 策略：默认 ERROR，保留既有产品对材料定义域外计算的拒绝；用户显式选择 legacy 兼容模式才允许保持端点，同时给出警告并记录来源与范围越界信息。不得通过研究旧行为削弱现有计算校验。

04，物理 p35 / 印刷 p34 特别指出：在 n/k、光源或探测器的表格节点，导数目标可能不连续。线性表给出分段常数的一阶导数，二、三阶导数更不能直接当平滑数据使用。使用经验证的解析色散模型，或明确声明平滑拟合及其误差；不要为了求导而悄悄改变测量资料。

## 3. 评价函数与目标系统

### 3.1 手册给出的完整数学形式

01，物理 p53 / S2 p43，已对页面图像检查括号、绝对值和外层指数：

F_k(x) = [ (1/m) Σ_{j=1}^{m} |(I_j D_j C_j(x) − T_j)/(N_j Tol_j)|^k ]^(1/k)

F_Max(x) = max_j |(I_j D_j C_j(x) − T_j)/(N_j Tol_j)|

- m：目标数量
- I_j：光源 illuminant 在该目标波长的强度
- D_j：探测器在该目标波长的效率
- C_j：该波长、角度、偏振、环境的计算量
- T_j：期望目标值
- Tol_j：目标公差，用作相对权重；越小越重
- N_j：把不同量的单位归一到兼容尺度的因子
- k：允许 1、2、4、8、16、Max

手册列出的 N：反射/透射/吸收/亮度为 1，phase 为 1.8，density 为 0.09，color 为 0.01。此处没有列出 psi、GD/GDD/TOD 及各阶导数的 N，项目不能虚构其旧值。光源、探测器表用百分数，但数学权重应只转换为无量纲 0–1 一次；目标观测量保留其已定义的单位尺度。

所有 Tol 同比例变化会缩放 F 的数值，却不改变数学极小点；“效果相同”不意味着显示的 merit 数值完全相同。对于 k=2，Tol 减半使该目标的平方贡献放大 4 倍。

Max 不光滑，手册限制为 Simplex；k=1 在 Gradient/Variable Metric 下只建议用于目标极值，例如 R=0 或 100%。可变材料的 n/k 不由 Simplex 调整（01，物理 p38 / S2 p28）。

### 3.2 不等式、连续目标和锥角目标

不等式用来表达真正的工程可行域，例如 R≤1% 或 49%≤T≤51%。独立方案可定义上限残差 max(0,C−u) / (N Tol)，下限残差 max(0,l−C) / (N Tol)。这是对文档语义的公开数学实现提案；手册没有给出 hinge 公式或“<”在精确等号处的处理，应在兼容测试中确认。

01，物理 p33–34 / S2 pp23–24：每个连续波段指定起止 λ、起止目标值、角度、偏振、公差和环境；同公差时一条连续目标与一条离散目标有相同的整体权重。p53–54 / S2 pp43–44 称积分并内部转成离散点，但未给积分归一化、插值形状、求积规则、细分准则。独立方案推荐每带归一化积分，再乘用户指定的波段重要性。不能让加密采样意外增加整带权重。

01，物理 p35 / S2 p25，锥角目标含中心角、半角/f-number、角度数量、Lambertian/Equal/User 分布等。p60 / S2 p50 要求奇数角数，并描述加倍点数误差约缩为 1/4；这提示二阶精度行为，但不足以认定具体算法为某种求积法。

独立的三维锥角积分可在锥轴坐标中用径向角 α、方位角 β：cosθ=cosθc cosα−sinθc sinα cosβ（方位原点换向不改变整圈积分）。按 W(α,β) sinα dα dβ 加权、归一化，逐条射线计算局部偏振。若输出探测器收集功率而非每射线功率比例，还须说明投影、孔径及入射偏振基底。不要只对几个 θ 作算术平均。

### 3.3 推荐的目标架构

Target = observable + units + environment + sampling + polarization + constraint + tolerance + normalization。强度平均、偏振差、R×T、相位、色坐标、导数各自有类型，避免把负号同时用作 dB、增益、缺失值等多个含义。

分层保留：物理 residual → 归一化 weighted residual → objective aggregate。UI 同时显示工程单位下的偏差及加权偏差，便于理解优化为什么牺牲某个波段。

## 4. 独立光学内核：公开物理与数学推导

下述为独立项目设计，不能称为 TFCalc 内部算法。公开理论参考可从 [Byrnes, Multilayer optical calculations](https://arxiv.org/abs/1603.02720) 入手，特别关注其相干/非相干层、复折射率分支和吸收入射介质章节。本研究使用其作为公开物理风险核对，具体项目推导与验收应在自身文档中完整声明约定。

### 4.1 稳定的传播和功率

采用 e^(−iωt)、N=n+ik；保守切向波数 u=N0 sinθ0。每层纵向量 q_z=√(N²−u²)，被动材料选使前进波衰减的分支，并在无吸收时保持向前功率方向。δ=2π q_z d / λ。

以切向 E 振幅定义非磁各向同性层的导纳：η_s=q_z，η_p=N²/q_z。界面 r=(η_i−η_j)/(η_i+η_j)，t=2η_i/(η_i+η_j)。这种 p 振幅定义的正常入射 r 与 s 相同；若采用另一种标准 p 单位矢量定义则需适配符号，不能混用各文献的 t、r 和 Poynting 功率公式。

令 r_next、t_next 是从某层内部向后看见的剩余叠层响应，传播因子 p=e^(iδ)。递归合成可写为：

r_total = (r_interface + r_next p²) / (1 + r_interface r_next p²)

t_total = t_interface t_next p / (1 + r_interface r_next p²)

被动层 p 的模不超过 1；避免直接累乘含 e^(+|Imδ|) 的传输矩阵。在多层高反、高吸收、近擦边条件下，优先散射矩阵或稳定递推。普通短栈可保留传输矩阵作为第二套独立交叉验证实现。 稳定散射矩阵作为公开独立方法有 [Ko & Sambles, 1988](https://opg.optica.org/josaa/abstract.cfm?uri=josaa-5-11-1863) 的原始文献依据；此次核实其摘要所述数值稳定性及超临界角应用，没有获取订阅全文，也不把它当作 TFCalc 内部证据。

非吸收入射介质下 R=|r|²，切向 E 约定的 T=Reη_exit / Reη_incident × |t|²；吸收介质、复角、增益需用完整场功率及可适用条件。不能一概强制 R+T=1，更不能见到 T>1 就裁剪到 1。主基线因其入射 k 强制为 0，避免了部分此类情况，但内部的吸收基底仍需正确处理。

### 4.2 非相干厚基底的检查用简式

在透明基底或满足普通独立前/后行波功率定义的情形，前膜正向 R_f,T_f，基底看前膜反向 R'_f,T'_f，后膜 R_b,T_b，单程功率衰减 a：

T_total = T_f a T_b / (1 − R'_f R_b a²)

R_total = R_f + T_f T'_f R_b a² / (1 − R'_f R_b a²)

这是求和几何往返级数的结果。a=exp(−2 Im k_z D)。透明无膜空气/玻璃/空气，单面 R=0.04 时 R_total=2R/(1+R)=0.076923076923…，T_total=(1−R)/(1+R)=0.923076923077…。这个解析值是比截图更强的验收基准。

注意：吸收基底的相干接口处前后波交叉项会影响边界局部吸收，不能无条件把所有界面都当成 R+T=1 的透明散射块。生产内核应完整实现吸收介质的相干/非相干通量衔接，并以能量、吸收积分和第二实现交叉检查；上述透明简式只作明确适用条件内的 oracle。

### 4.3 场、椭偏与相位导数

由每层前后波振幅恢复 E(z)，EFI=|E(z)|²（p 应包括矢量分量），并区分 EFI、归一化能流和局部吸收密度。验收以切向 E/H 跨界面连续，吸收积分与总 A 相符，而非只看曲线“像不像”。

椭偏通常使用 Ψ=atan|r_p/r_s|、Δ 为声明了 p 符号约定的相位比。文献 Δ 定义有符号/常数差异，手册片段没有完整规定所有包装范围，须将测试的约定写进夹具。r_s 或 r_p 为零附近不应输出貌似可靠的相位/比值。

对于固定参考面的 z(ω)=r 或 t，φ=arg z。在 z≠0 的平滑区，φ′(ω)=Im[z′(ω)/z(ω)]，可避免先整体相位展开再求一阶导数；高阶仍需稳定导数或局部拟合。令 a=2πc，λ 使用与 c 一致单位：

GD = −λ² φ_λ / a

GDD = (λ⁴ φ_λλ + 2λ³ φ_λ) / a²

TOD = −(λ⁶ φ_λλλ + 6λ⁵ φ_λλ + 6λ⁴ φ_λ) / a³

这些是 d/dω=−λ²/a · d/dλ 连续应用的链式推导；不能把相位对 λ 的二阶导数直接当 GDD。采用 SI 时结果分别乘 10¹²、10²⁴、10³⁶ 转成 ps、ps²、ps³。振幅接近零时相位导数本身可发散，必须报告无定义/低可信区，不能通过随意平滑产生虚假的可实现目标。

## 5. 局部优化、针法、隧道与全局搜索

### 5.1 公开局部算法选型

建议独立基线：有界投影梯度 + 有界准牛顿（例如 L-BFGS-B）+ 导数自由 simplex（例如 Nelder–Mead），均有明确版本、停止条件和数值日志。

[L-BFGS-B 作者主页](https://users.iems.northwestern.edu/~nocedal/lbfgsb.html) 提供有界有限内存准牛顿方法的原始说明及参考资料；[Nelder–Mead 1965 原始论文](https://academic.oup.com/comjnl/article-abstract/7/4/308/354237) 描述 n+1 个点的 simplex 函数值比较。二者都是独立项目候选，名称对应不等于 TFCalc 使用同一实现。

独立梯度迭代 x_new=P_[l,u](x−αg)，用充分下降线搜索避免不可行点。准牛顿搜索方向 −H g，曲率更新需处理 sᵀy≤0、非光滑 active set 和不良尺度。Simplex 的反射、扩张、收缩、缩小需要对边界使用一致策略，不能简单裁剪到同一点导致退化。

参数应尺度归一化：d、组因子、n、k、色散系数单位差很大。终止区分 projected-gradient small、objective change small、step small、iteration limit、user stop、numerical failure。只有第一类和联合一致性检查可支持“收敛”；碰到上限不等于找到最优。

### 5.2 高效导数与验证

短栈的传输表示 M=M1⋯ML，可以用 prefix/suffix 得到 ∂M/∂d_l=(M1⋯M_{l−1})(∂M_l/∂d_l)(M_{l+1}⋯ML)，而 ∂δ/∂d_l=2πq_z/λ。同一波长的所有厚度导数由前后累计得到，不必对每层完整重算整栈。稳定散射递推也可用自动微分/伴随法。

组变量 g_h 对所有所属层同时作用，d_true=g_h d_base；∂F/∂g_h=Σ_{l∈h} d_base,l ∂F/∂d_true,l。共享材料 n/k 的导数必须汇总所有使用该材料的层，并考虑色散和折射角导数。

用中央有限差分核验内点方向导数，有界零厚处用单边差分。复步长不能直接跨过 abs、conjugate、实部功率和非解析分支；把所有导数“用 complex step”不是正确方案。

### 5.3 针插入的独立数学实现

01，物理 p78 / S2 p68：零厚新层插入后由 Gradient/Variable Metric 局部优化使其生长，参与插入的材料为 2–8 种，不能与 Simplex、组优化或敏感度优化共用。物理 p61 / S2 p51 支持重复插入、一次多插、先局部优化。

公开文献基点是手册引用的 [Tikhonravov 1993](https://opg.optica.org/ao/abstract.cfm?uri=ao-32-28-5417)，后续应用论文 [Tikhonravov/Trubetskov/DeBell 1996](https://opg.optica.org/ao/abstract.cfm?uri=ao-35-28-5493) 描述针法应用与物理解释。这次公开访问仅核实摘要/书目信息，未读取订阅正文；以下具体构造是独立数学方案，而非声称取自未读全文。

对原层 a 内位置 z 插入材料 b、厚度 ε，分割原层成左/右两段。新设计 F(ε;b,z)，F(0;b,z)=F_original。定义一侧针灵敏度 g_insert(b,z)=lim_{ε→0+}[F(ε;b,z)−F(0)]/ε。g<0 是小正厚度能改善目标的方向。

为了固定总厚度，可构造用 b 替换一小片 a：M_a(z) M_b(ε) M_a(d−z−ε)，此时导数含 B_b−B_a；如果定义为“加一层”而不减原厚度，则总厚度随 ε 增加、导数定义不同。项目必须明确选用哪种变分，不能把不同针函数混用。禁止插入位置、最小 d、厚度上限及允许材料需要进入搜索可行域。

实作可先用若干 ε 的有限差分排名，再升级解析 topological derivative；选择负灵敏度点，添加 0 或很小正 d，局部优化，删除未成长/过薄层，重分析。批量插入会相互作用，负分数并不保证一起改进，因此每次局部优化后检查真实 F。所谓 needle-optimal 仅指该材料、位置采样、局部算法和容差下没有改进插入，不是全局最优证明。

### 5.4 隧道与全局搜索不可过度承诺

01，物理 p62 / S2 p52：needle-optimal 后，Grow、总厚度上限、偏差阈值共同控制 tunneling。p79 / S2 p69 描述选某层生长、到新谷后局部优化、再针法，且明确没有一般规则说明哪层会增长。不能从示意图推出内部评分式。

独立隧道方案可做“逐层生长/厚度扰动 → 局部优化 → 针插入”，按目标、可制造厚度、总厚度和复杂性保存 Pareto 候选，并限制求解预算。它是启发式搜索，不能保证每次变好或有限步达到所有指标。

01，物理 p62–63 / S2 pp52–53 全局搜索生成系统网格或均匀随机变量，受 ±变化比例、非负及约束限制，最多 32767 个设计。依据最近邻目标比较挑可能局部极小点，再局部优化。距离度量、参数缩放、邻居数据结构、去重、并列处理未公布。独立实现必须补定义，尤其不能让 nm 厚度的数值尺度压倒 n/k 和组因子。

验收应表述“在给定材料/层数/界限、预算与随机种子下的最好已找到设计”，不能把 best-found 写成 mathematically global optimum。

## 6. 敏感度、良率、监控与反演

### 6.1 误差分析

01，物理 p64 / S2 p54：厚度误差可相对或绝对 nm/QWOT，n/k 误差为相对；均匀或正态。正态生成限制在名义值 ±2σ，框内值为 σ。手册未解释是 rejection-truncated normal 还是 clipping，二者统计分布不同，不应默认为无界正态。

Monte Carlo min/max 是样本极值，不能称为严格最坏可能；quartile 是逐波长分位曲线，不是一片真实试验膜系的整条曲线。Worst-possible 用优化求更坏性能，但未给全局证书，只能报告 worst-found，除非另有严格证明。

鲁棒目标推荐 sample-average 并固定/复用 common random numbers，使局部比较不被每步换样本的噪声淹没；最终用新的独立随机批次核验。相关误差（全批系统偏移、材料共同偏移、沉积层间反馈）对良率影响可能比独立误差大，这是新模型扩展而非手册明确披露。

### 6.2 良率和层敏感度

01，物理 p58 / S2 p48：良率是所有不等式指标通过的试验膜系百分比。须用 joint pass：只要任一波长/角度/偏振失败，整片即失败；不能把各波长通过率再平均当良率。项目应显示二项抽样置信区间、试验数、种子和误差模型。

同页把优化点的一阶敏感度接近零、二阶敏感度体现谷底曲率作为解释。数学上 Hessian 在非优化点也可存在，“未定义”是手册对此功能的语义，不能当作微分学定理。在有边界活跃约束的最优点，普通梯度也未必为零；应考察 KKT/projected gradient。

### 6.3 监控曲线

01，物理 p64–65 / S2 pp54–55：R/T/Δ/Ψ，R/T 可 P/S/平均，最多三监控 λ，指定 chip、背面是否反射、厚度、角度与分辨率。监控比例可每材料不同，文档称其与 rack distance / monitor distance 的平方成比例，但没有完整规定常数和 thickness mapping 的方向。

独立项目需明确工件厚度与 chip 厚度的换算定义，按每层沉积进度构造部分膜系并计算响应。灵敏度、转折点可用于监控选波长分析，但这不是自动生产控制授权，也不能将独立 Reoptimize 产品的 DDE 功能自动算进基础程序。

### 6.4 光谱/椭偏反演

01，物理 p80–83 / S2 pp70–73 支持可变 n/k 或色散参数拟合，输入最多 3 组 T、R、backside-R，共同波长，角度/偏振、背面条件、基底及其厚度、层厚估计、抽取间隔、参数开关和界限。层厚默认固定，开启后才参与拟合；自然约束防止色散极点/除零。

反演不等于唯一识别。厚度与折射率耦合、薄膜数据只有单调段、未知基底、测量偏差、太宽的色散模型范围均会造成多解或伪拟合。应报告 residual、候选多解、参数相关性与不确定度；用不同角度/偏振或额外测量作外部验证。不能只给一个低 RMS 数值就断言得到真实 n/k。

## 7. 优化指南的使用技巧与中文资料纠错

04，物理 pp32–38 / 印刷 pp31–37 的可采纳技巧：

- 目标限定了被控制的波长、角度、偏振；随着层数/总厚度增大必须补足采样
- 端点较差可降低端点 Tol，提高权重，但会牺牲其他位置的表现（p34 / 印刷 p33）
- 多带目标数量失衡会导致某一带被忽视；按工程重要性/求积权重平衡，不以目标数量代替优先级
- global search 可找更好的起点/其他局部极小值；排除阈值过低会导致没有候选（p35 / 印刷 p34）
- needle 初层厚度影响最终厚度和复杂性，单一“正确起点”不存在；保留多个起点与候选
- 当 needle 开始制造大量极薄层时，可提前停止针法，转局部优化，评估第三种中间折射率材料及制造下限（p36 / 印刷 p35）
- tunneling 随结构变复杂增加目标，保留候选，按厚度/复杂性/可制造性选择，不只挑最小 F
- 指南建议 Variable Metric、1000 次迭代、误差容差 1e−6；近极小可用 1e−8；通常 k=2，等波纹可试 k=16；Simplex 初始 Max.Change=10%（p37 / 印刷 p36）。这些是历史配方，不是现代求解器停止容差的等价保证

必须显式纠正/保留不确定性的地方：

1. 04，物理 p53 / 印刷 p52 说单层或 needle+tunneling 效果“不好”；01，物理 p78 / S2 p68 原文是 works best，意义反转。实际建议按英文理解。
2. Variable Metric 应译“变尺度/变度量（通常为拟牛顿类）”，Simplex 应译“单纯形”；不是可变评价函数或“简单”。derivative 是导数，不是偏差。
3. 04，物理 p9 / 印刷 p8 把 G1(HL)^5 G2(HL)^5 第二部分写成 7 层；数学上两部分均为 10 层。
4. 04 部分入射角文字省去法线，01 以表面法线为零度；不得误用与表面的夹角。
5. 04，物理 p35 / 印刷 p34 说最后用 10 nm color grid 较合理；01，物理 p31 / S2 p21 指出 10 nm 优化和 5 nm 分析可能不同，若有问题应用 5 nm 最后优化。项目最终验收应使用更细的独立采样。
6. 04，物理 p34 / 印刷 p33 的 band balance 显示 ΣW_i/N_j，却把 W_i 称公差、未显示明确相等条件。因与 inverse-tolerance merit 解释不一致，不直接编码这段规则。
7. 04，物理 p35 / 印刷 p34 的 CIE(x,y) 示例约为 (2,3)，超出归一色度有效域；不能当测试参数。
8. 02，物理 p4 的“16 位浮点”以及 dispersion→散射、cavities→通道等用词需要核对；数字精度未由英文手册证实，不能据此选 float16。
9. 04 含旧式独立 Compute Cone-Angle Average 入口，01 将其并入 Analyze Only/Analysis Parameters；不能将中文旧界面作为 3.5 精确 UI 基线。

## 8. 独立项目的阶段验收

### P0：可信计算与数据模型

- 完成 layer order、方向、单位、QWOT、材料表/色散、相位约定、相干前膜及非相干厚基底
- 有材料范围、复数分支、零振幅相位、增益、近擦边的明确行为
- 支持 R/T/A、声明约定的复 r/t，按基线限制入射吸收
- 至少通过 V01–V18 相关解析夹具、能量/接口场检查、第二套独立数值实现对比
- 对随机被动小栈功率总和误差目标 1e−10；解析基本例 1e−12；病态长栈采用条件数/精度-aware 阈值，不能所有例子一刀切

### P1：工程可用分析与局部优化

- typed targets、离散/连续、不等式、偏振/环境、各量单位及明确的归一化
- 有界局部优化，有每变量开关、组因子及清晰停止原因，解析/自动微分梯度经过差分核验
- 结果含原始/加权观测区别，单位、版本、假设及可复现 seed
- Monte Carlo、quartile、joint yield，通过零误差极限及独立采样验证
- 目标点之外的密集 holdout、峰/边缘搜索也通过工程指标，不能仅接受训练网格 RMS

### P2：高级综合与可制造性

- 针法、tunneling、多起点有材料/厚度/算力预算、完整候选、最好已找到说明
- EFI/GD/GDD/TOD 的参考面和有效区域明示，网格加密验证
- 锥角/颜色有独立积分/数据源校验，制造监控 mapping 有实测或公开验证
- 反演报告多解和数据误差，带通 prototype/等效层转换以公开文献独立实现
- 用户确认工艺最小/最大层厚、误差模型、材料可用性、目标优先级后再宣称设计可制造
