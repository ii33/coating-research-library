# TFCalc功能与技巧及项目实现方案

2026年10月5日　版本 1.0　研究与实现准备

## 1 结论与边界

建议把 TFCalc 的功能重新组织成一条可验证的工程链：材料和膜系数据 → 稳定光学前向计算 → 光谱目标与约束 → 固定结构局部优化 → 结构搜索 → 制造误差与良率 → 监控预测 → 沉积厚度分布对应的光学性能分布。优先建立这条链的计算与数据边界，再逐步接入桌面界面和任务管理。

当前项目已有材料光学常数模块，研究库已有 T07 稳定散射矩阵与独立递推核，以及 T08 厚度导数、目标函数和优化实验。它们是可复用的起点，不代表产品已经具备完整膜系设计功能。宜先适配已有参考核、建立回归用例，再扩展功能；无需从零重写薄膜物理。

本次交付是功能研究、操作经验和实施方案，不是完整软件实现，也不是对 TFCalc 的位级复刻。功能等价应以公开物理、明确语义和验收用例为标准；商业软件未披露的内部算法、界面、标识和专有源代码不属于实现依据。

### 资料权重与阅读方式

英文《TFCalc 3.5》手册是主要功能依据，版权页为 2002 年；附件为 92 个 PDF 物理页，包含 Section 1、Section 2 及其附录和索引。总目录列出 Section 3 优化指南等内容，但附件中没有这些章节。中文 56 页说明书 M04 则实际含优化指南，见 PDF 32–38、印刷页 31–37，并含后续实例。应分别记录两份文档的覆盖，不能由英文附件缺章推断整个资料包缺少指南。中文 18 页“最新说明书”主要是功能介绍；中文译文与教程可补充操作经验，出现冲突时优先核对英文原文。

文内“M01 PDF 53，S2 43”表示英文手册的第 53 个物理页、Section 2 印刷页 43；中文 PDF 与转换后的 DOC/DOCX 引用均使用物理页。章节、公式和页码的证据清单随派生研究保存。原附件不重新分发。

### 三类结论

- 文档确认：TFCalc 3.5 手册明确列出的功能、控制项和限制
- 代码确认：已检查的现有产品模块或研究参考实现，范围有限
- 实施建议：本项目拟采用的数据结构、算法、接口和验收方法，尚需实现与验证

## 3 材料和膜系数据先统一约定

### 材料来源和未知量

现有产品 optical_constants 模块已有离散表格线性插值、Cauchy 和三项 Sellmeier、nm/µm 单位校验与禁止外推。这些可直接作为材料提供器的起点。Cauchy/Sellmeier 在现有实现中描述 n；缺失的 k 仍为未知值，不能自动解释为 k=0。若用户明确选择“无吸收假设”，结果应记录这个假设，而不是改写原数据。

手册材料章节描述表格波段外使用最近端点；配置页另有允许外推选项，关闭时会警告，但是否直接拒算未明确。端点钳制仅作为显式启用的历史兼容策略理解；本项目默认 ERROR，保留现有材料模块的越界拒绝，兼容模式须记录警告与来源。手册还允许配置增益材料，不属于首期被动核的范围。M01 PDF 10，S1 6。温度等条件下的多环境材料替换，是不同环境使用不同材料数据的机制，不等于内置了可信的热膨胀或 dn/dT 模型。M01 PDF 40–43，S2 30–33。

### 四个必须显式处理的约定

1. 复折射率：TFCalc 层表记作 n−ik；T07 使用 N=n+ik 与 exp(−iωt)。导入时转换成内部约定，不能只改符号而不改传播相位。被动吸收必须对应衰减。
2. 层顺序：TFCalc 第 1 层靠近基底；建议内核采用入射侧到出射侧顺序。前后面、反向照明都要通过几何转换处理，不能只翻转结果数组。
3. 厚度：QWOT = 4n(λ₀)d/λ₀，是参考波长处的标称四分之一波光学厚度。物理优先时保持 d；光学优先时保持 QWOT，λ₀ 或材料 n 改变后重新求 d。斜入射相位另由传播模型计算。
4. 偏振相位：Muller 与 Abelès 的 p 反射相位约定在法向入射可相差 180°；比较相位或椭偏数据前必须对齐，不能将约定差当成算法错误。

出处：M01 PDF 10，S1 6；PDF 13、23，S2 3、13。数据模型只允许一个厚度量作为权威值，另一个是带参考条件的派生显示值。

### 建议的数据对象

MaterialSnapshot 保存稳定 ID、版本/摘要、n/k 模型、波长单位、有效区间、工艺与温度条件、来源、未知量和外推政策。StackSnapshot 保存两面膜层、各层材料与物理厚度、基底厚度、层顺序、厚度编辑优先量及限制。Environment 保存光线方向、介质、入射角、偏振、背面/收光模型和光源探测器。

所有计算绑定材料快照。材料库后来更新，不应改变一个已完成任务的数值含义；修改库后重算需要新任务和新摘要。

## 4 稳定的光学前向计算

### 核心模型和数值选择

先支持各向同性、平面、非磁性、被动层，以及实折射率入射介质。T07 已有散射矩阵 star 组合和独立 Airy 递推；普通特征矩阵只保留作教学与小问题交叉检查。厚吸收层或高反长膜堆会让直接矩阵乘积溢出，不能以“公式等价”代替稳定性验证。

在内部 N=n+ik 约定下，令 β=N₀sinθ₀，qᵢ=√(Nᵢ²−β²)，选择被动介质的衰减分支；δᵢ=2πqᵢdᵢ/λ，传播因子 pᵢ=exp(iδᵢ)。界面散射矩阵与传播散射矩阵依次用 star 运算组合。实传播端口的切向电场导纳可取 Y_s=q、Y_p=N²/q。

功率反射率 R=|r|²，透射率 T=Re(Y_out)/Re(Y_in) × |t|²。A=1−R−T 只在模型、端口和功率定义一致时使用。透入吸收半无限介质的 T 是进入该介质的通量，不是穿过一块有限吸收基底后的透射率。能流归一化错误会让光谱曲线看似合理，却破坏守恒与优化导数。

### 背面和相干性必须跟随可观测量

TFCalc 对有限基底的 R/T 考虑背面反射，将厚基底两侧的多次往返按非相干强度叠加；相位变化与 psi 按无限厚基底计算，EFI 也忽略背面。它不是一个对所有输出同时生效的“相干/非相干”开关。M01 PDF 68–69，S2 58–59。

对于一个非相干分隔层、实传播端口和单程功率衰减 a，示意强度组合为 T = T_f T_b a /(1−R_f′ R_b a²)，R = R_f + T_f T_f′ R_b a² /(1−R_f′ R_b a²)。反向前表面系数必须按同一横向波矢和正确方向计算。该参考组合器不直接覆盖任意混合相干、吸收界面或有限数值孔径收光系统。

建议每种 Observable 明确请求的模型与限制：强度、半无限基底复振幅、场分布、仪器平均结果分开。相位在振幅接近零时无定义；GD=dφ/dω、GDD=d²φ/dω²、TOD=d³φ/dω³，ω=2πc/λ。它们需解缠相位、统一参考面、正确 λ→ω 链式换元与均匀频率网格加密检查，不宜从粗波长网格直接反复差分。手册未在有限基底段单独说明全部超快量的背面政策。

### 必须保留的数值保护

检查非有限输入、负厚度、零分母、极角与临界角附近、材料范围及无意义相位。T07 当前不支持吸收入射介质、增益、各向异性与磁性层等范围；产品不能静默接受这些模型。下溢得到 T=0 时应报告数值下限，不能称为已证明无限光学密度。

## 5 目标函数和工程约束

### TFCalc 的目标语义

离散目标指定波长、角度、环境、偏振、目标量、目标值、容差与关系；连续目标在内部转为离散目标，原手册没有公开积分节点和自适应规则。颜色、亮度、波长/角度导数和超快目标是不同的可观测量转换；还包括偏振差、R×T 与通带匹配等复合量。平均偏振达标并不能证明 P、S 分别达标。M01 PDF 28–31、53–54，S2 18–21、43–44。

已核对的历史评价函数是绝对归一化残差的 Lp 型聚合：

F = { (1/m) Σⱼ |(Iⱼ Dⱼ Cⱼ − Tⱼ)/(Nⱼ Tolⱼ)|ᵏ }^(1/k)

其中 C 为计算值，T 为目标，Tol 为容差，N 为不同量的归一化常数；I、D 为光源强度和探测器效率。I、D 按各字段定义转换为相应响应因子；C、T、Tol 与 N 必须在同一历史单位口径下使用。手册列出 k=1、2、4、8、16 与 Max；Max 取最大绝对归一化偏差。外层的 1/k 次幂和绝对值不可遗漏。M01 PDF 53，S2 43。

R/T/A/亮度的 N=1，相位角度值为 1.8、密度为 0.09、颜色为 0.01，均应结合手册原始单位理解；不要将百分数反射率的容差或角度相位常数直接用于内部比例值、弧度制。GD/GDD/TOD 与导数目标的归一化没有在这段公式中给出。历史 k=Max 只配 Simplex；可变折射率又不能由 Simplex 调整，因此算法与变量组合需要校验。

### 本项目建议的可解释目标

对上限要求，例如 R≤u，使用 e=max(0,R−u)/tol；对下限要求，使用 e=max(0,l−T)/tol；等式要求使用 e=(C−target)/tol。离散点权重与连续带积分权重分开，按波段、角度、偏振与场景规范化。T08 已有这类代数和梯形积分权重，但其平方残差目标不是 TFCalc 所有历史 k 的完全复刻。

工程规范与优化权重也要分开：Tol 可以影响搜索权重，但最终合格判据必须来自实际规格，不应因放大容差而“变合格”。硬约束保存最小/最大层厚、可用材料、层数、总物理厚度、固定/联动层和设备工艺限制。超出约束的漂亮光谱不进入可制造候选集。

优化网格与独立验收网格分别保存。连续带目标仍是数值采样；采用自适应加点与密集留出检查，不称为已证明整个连续区间无漏峰。

## 6 固定结构的局部优化

### 已确认的历史方法

TFCalc 3.5 明确描述 Gradient、Variable Metric 和 Simplex；说明变量度量通常较快、梯度法内存较少、Simplex 可能需要较多迭代，且不同初值可能得到不同设计。手册没有公开内部 BFGS 更新公式、完整 Simplex 变体或阻尼最小二乘算法。M01 PDF 60–61，S2 50–51。复现功能时可采用现代求解器，但要标为本项目选择，不能写成“TFCalc 使用了某求解器”。

### 复用厚度解析导数

T08 的 spectrum_jacobian 使用前缀/后缀散射组合传播切线，在 M 个光谱样本、L 层的情况下，时间和存储为 O(ML)。独立的前向切线版本约 O(ML²)，适合小问题交叉检查。对固定 n、k 与角度，∂pᵢ/∂dᵢ = i(2πqᵢ/λ)pᵢ，∂R/∂dᵢ=2Re[r*∂r/∂dᵢ]；透射导数要带同一通量因子。

该导数不包含材料、角度、温度或 GD/GDD 对参数的完整导数。折射率、混合比与工艺参数作为变量时，必须增加对应链式导数或带标度的有限差分。R/T 是复振幅的非全纯函数，不能把未经处理的复步法当成通用真值。

### 建议的求解流程

先做参数范围和约束校验，将厚度变量按合理尺度归一化，再评估名义光谱和目标分项。用有界最小二乘或 L-BFGS-B 完成固定结构细化；有总厚度等约束时使用经过验证的约束方法。记录真实目标值、最大规格违差、约束违差、停止原因、预算与候选摘要。

参考库的 TRF、L-BFGS-B 和 SLSQP 是已实现研究选项；算法适配到产品前要隔离其研究目录与材料加载依赖。局部线性代理只用于提出步长，每一步都用真实光学模型验收，不将代理预测当成最终光谱。

交互预览使用较粗网格，最终优化和验收使用明示的网格策略。先实现 CPU 矢量化、缓存和批处理；只有测得光谱节点、角度、场景或空间网格足够大时，再选择 GPU 后端。不能假定一维膜堆需要机器学习或 GPU 才能运行。

## 7 Needle 和全局候选搜索

### 结构搜索的物理含义

Needle 在允许位置试插很薄的新材料，判断目标变化，再对有希望的结构细化。它改变层数与拓扑，必须与固定结构局部优化分开。手册支持允许的 needle 材料、增长膜系及相关控制；不能将一次“没有改善的 needle”解释成全局最优证明。Tunneling 的作用是找到较好的新起点，内部细节仍不完整。M01 PDF 61–63、78–79，S2 51–53、68–69。

现有 T08 是有限厚度候选插入实验：add/replace、宿主层拆分、相同材料合并、制造约束检查，再局部细化。它不是已经完成的解析零厚度 needle 合成器。独立的针灵敏度可定义为 g=lim[ε→0⁺](F(ε)−F(0))/ε。添加厚度与保持总厚度的局部替换是两种变分；后者必须同时移除等厚宿主材料，不能混用二者的灵敏度。应先保留这个原型作为比较基线，再实现可验证的插入灵敏度、删除/剪枝、预算化搜索及候选回溯。

### 独立实现建议

1. 冻结材料和环境，明确允许插入材料、位置、最小可制造厚度、层数和总厚度上限
2. 用小厚度差分或验证后的解析灵敏度筛选位置，使用多步长检查而非单步判断
3. 对通过筛选的候选细化，独立重算光谱和制造违差
4. 合并相同材料、逐个删除过薄层后重新细化，保留变化前后的结果
5. 没有改善时按预算停止或发起新的候选起点，报告“本次搜索未发现更好解”

### 全局搜索的真实边界

历史全局搜索以当前设计为中心，对选中的厚度、层组或变量材料生成网格/随机候选，用近邻偏差识别可能的局部极小值；维数高时系统网格迅速膨胀。M01 PDF 62–63，S2 52–53。项目可采用多起点、网格、差分进化等独立策略，保存种子、预算、可行/不可行/未知状态和最优候选。

所有这类有限搜索都不保证找到了全局最优。有限样本 minimax 只约束采样节点，权重权衡只产生部分候选，不能称为完整 Pareto 前沿或连续带证书。更强的区间/集合方法必须注明适用范围；现有第三轮研究仍有 UNKNOWN，不可改成已证明合格。

## 8 制造容差和良率

名义光谱通过只是第一道门槛。制造模块应区分层厚、材料折射率、系统性漂移、逐层独立误差及空间相关误差，输出对工艺可解释的分布与失败模式。

### 历史功能和统计限制

TFCalc 可模拟厚度和折射率的均匀/正态误差，厚度可按相对量或绝对物理/光学厚度变化；手册的正态误差截断在 ±2σ。worst-case 使用 Monte Carlo 估计样本最小/最大曲线，quartile 给出分位曲线；worst-possible 通过优化寻找给定误差内的不利情况。M01 PDF 57、64，S2 47、54。

样本中最差值不是理论边界；优化找到的最差值也不是已证明的最差可能值。逐波长最差曲线可能来自不同样本设计，不能将其当成一件实际产品的完整光谱。制造报告应同时保留具体失效样本与对应参数。

### 建议的误差模型

用 d′ᵢ=dᵢ(1+b_material(i)+b_run+εᵢ) 表示一种相对厚度模型，其中公共偏差与独立误差显式分开；该形式是项目建议，不是对历史软件随机规则的推断。也支持绝对 nm 误差、材料 n/k 的有证据模型和多源协方差。截断后分布、有效协方差及异常处理需记录，不能假定截断后的相关性仍等于输入值。

固定随机种子用于可复现；比较两个设计时采用共同随机场景减少比较噪声，另用独立留出场景检查。无效厚度或越界材料样本应计入失败/模型不可判定，并说明原因，不可悄悄丢弃来提高良率。

### 合格率的输出

对每个样本，在独立验收网格、必需角度与偏振上检查所有规格和制造限制，再统计整件通过率。仅在独立同分布抽样假设成立时，附二项比例置信区间；带相关时间序列或空间样本时需相应处理。增加样本直至关键分位数或通过率达到预设精度与预算，并明确仍有的统计不确定性。

T08 已有示例 ±1% 场景及固定种子的 64 个留出样本，它们是合成误差实验，不是实际镀膜良率。应将其用作算法回归，再接入实测设备和材料误差数据。

## 9 监控预测与沉积空间耦合

### 从曲线到终止判据

TFCalc 可模拟 R、T、delta、psi 监控，选择 P/S/平均、芯片材料、背面反射、芯片厚度、角度与最多三个波长；每种材料可有独立 monitor ratio。M01 PDF 64–65，S2 54–55。

项目应把“正在生长的层”作为随厚度变化的膜系，输出监控量、斜率、转折点和可用终止区间。接近转折点时信号对厚度不敏感，反演可能多解；预测器必须保存分支和适用范围，不能把一条静态曲线直接当成闭环终止控制。

monitor ratio 必须定义方向与单位，例如 d_chip/d_product，并按材料、源、安装位置和工艺校准。手册以距离平方比解释比例是一种简化几何关系，不能直接推广到挡板、行星转动、非点源和遮蔽条件。本项目已有沉积几何和 QCM 校准信息，应由适配器提供比值与不确定性。

### 逐层厚度图到光学性能图

空间耦合的输入应是每一层 dᵢ(x,y)，或名义厚度 dᵢ与已校准的相对分布 uᵢ(x,y)，使 dᵢ(x,y)=dᵢuᵢ(x,y)。同时保存坐标系、单位、网格、有效区域、源与转动程序、材料映射、掩膜和插值方法。

不能仅拿整堆总厚度分布平均分给每层；不同材料、源位置、蒸发时间与转动轨迹可能给出不同形状。只有实验证据支持各层同一相对分布时，才可使用公共 u(x,y) 简化。

在每个有效位置形成局部膜系，批量计算 R/T/颜色/所需相位，再生成性能图及区域最差值、分位数和合格面积比例。厚度均匀度好不必然意味着光学规格通过；同样的百分比误差对不同膜系或波段的影响可以很不同。

### 实施边界

先做离线预测与校准导入，不直接连接设备实时控制。监控测量的时间戳、噪声、仪器响应与芯片更换历史，与沉积空间数据分开管理。若后续增加在线控制，需要独立设备协议、安全联锁和工艺验证。

## 10 教程中可借鉴的技巧和陷阱

### 一套可执行的设计检查流程

先确定真实使用与测试条件：规格带、保护带、角度、偏振、入射/出射介质、基底、背面收光与材料有效波段。再设初始结构与可制造范围，进行名义分析；不要在环境还未确定时立即优化。

增透教程把 400–700 nm 的要求放到 300–780 nm 的分析范围中，提醒优化边界需要余量。它提到的 20 nm 保护带是案例经验，不能成为统一参数。初始膜系也只是起点，材料应替换成实际可用且有可信色散的数据。T10 PDF 1–3。

删除极薄层后必须重算整段光谱；教程中删除一层明显破坏了局部波段，随后重新添加目标并优化。若正在固定结构做可制造整理，应关闭会把层重新插回的 needle。提高一个子带的权重可能损害另一个子带，每次结构编辑后都检查全部规格。T10 PDF 6–9。

中文优化指南提醒优化器只控制指定的波长、角度和偏振，节点更多的波段可能占据更大权重。端点容差减半会加强端点约束，也可能使其它区域付出代价；应在界面显示各波段归一化权重和独立最大违差，不能照抄译文中不清楚的权重公式。M04 PDF 33–34，印刷 32–33。

线性 n/k 插值在数据节点处存在导数不连续，导数目标和超快量必须检验网格与材料模型，不能把尖点都当成真实色散。优化指南的迭代次数、误差容限与颜色步长属于历史示例设置；现代默认值要由用例和精度需求确定。M04 PDF 35–37，印刷 34–36。

最终用更密波长节点、全部必需角度和偏振检查峰谷，核对层厚、层数、总厚度与容差。保存初始、名义优化、结构整理、容差验证四个阶段，不用最后一张曲线覆盖失败过程。

### 不应直接抄用的两个案例

可见增透教程作者说明内容为自学粗略示例，并承认 H4 的 n≈2.05 偏低。BK7/K9、400–700 nm、R<1% 可作为后续重建的教学基准条件，但教程曲线不是经生产测量确认的配方。T10 PDF 1、10。

高反教程写 GaAs 基底、ZnSe/YF3、10600 nm、R>99.9%，环境却使用 1580 nm 参考波长，并以倍率 7 近似关联两者。应先解释其 QWOT 和色散设定，再独立重建；不能直接导出镀膜配方。材料保持原文 YF3，不能误改成 YbF3。T11 转换 PDF 1–2；完整操作文件 T11 与 T12 为重复内容，不能计作两份独立证据。

### 翻译和显示注意事项

M04 PDF 53、印刷 52 将单层初值和 Tunneling 后的 needle 效果译成“较差”，而 M01 PDF 78、S2 68 写的是效果最好，含义相反；不能据中文结论排除该策略。M04 的 derivative 有处译成“偏差”，应按上下文理解为导数；Variable Metric 宜称变尺度方法，Simplex 宜称单纯形方法。

中文资料中的“透视”在相关处应理解为透射；公式 OCR、厚度符号和菜单翻译可能丢失细节。原始 R/T 与光源/探测器加权曲线要区分；平均偏振、光学厚度与物理厚度都要在显示与导出中明确。单条曲线和很小的评价函数值不能替代完整规格验收。

## 12 独立于界面的任务与接口

### 分层边界

领域层负责材料、膜系、可观测量、目标、约束和结果；光学核只计算明确输入，不能读取 QML 状态或全局文件。求解层负责优化、容差、搜索和预算；任务层负责提交、取消、进度、缓存和结果保存；桌面界面只是调用者。未来服务器或批处理可调用同一接口，但当前队列不能直接称为已具备完整无界面服务能力。

### 建议的不可变 JobSpec

| 字段组 | 内容与校验 |
| --- | --- |
| 标识 | schema_version、任务类型、输入摘要、算法版本 |
| 材料 | 固定材料快照、来源摘要、模型、有效范围、未知 k 处理 |
| 几何 | 前后膜层、基底、照明方向、内部层序与相位约定 |
| 网格 | λ/ω 单位、节点、角度、偏振、环境、优化/验收网格 |
| 目标 | 可观测量、上下限/等式、权重、容差、响应加权 |
| 约束 | 层厚、层数、总厚度、固定/联动变量和材料候选 |
| 策略 | 求解器、变量标度、预算、网格加密、停止条件 |
| 随机与空间 | 种子、分布/相关性、逐层厚度图与坐标系 |

serialize/validate 必须可独立运行；NaN、单位缺失、越界材料和不支持模型在任务开始前明确拒绝。计算摘要绑定所有影响结果的参数和版本，而不只绑定界面文件名。

### 建议的调用契约

- evaluate(job)：光谱与场诊断，返回带轴标签和单位的结果
- refine(job)：固定结构细化，返回候选、真实分项偏差和停止原因
- search(job)：预算化拓扑/多起点搜索，返回候选台账与未决范围
- tolerance(job)：误差场景、通过率、分位数、置信度与失效样本
- monitor(job)：逐层生长曲线、终止候选与分支/灵敏度警告
- map_response(job)：逐层厚度图对应的光谱图与区域验收

以上是拟议领域接口，不是已有网络端点。未来 TaskService 可提供 submit/get/cancel/result；任务状态至少区分 queued、running、succeeded、failed、cancelled、inconclusive。取消只能在安全批次边界发生，不能把未算完结果标成成功。

结果要保存输入摘要、材料与算法摘要、网格、输出单位、约定、数值警告、预算消耗、终止原因及验收状态。按波长×角度×偏振×层数×场景×迭代估算工作量，分块缓存并报告实测进度；不要用一个不断增长的假百分比代表搜索完成度。

## 13 分阶段实施与交付门槛

| 阶段 | 交付范围 | 进入下一阶段前的证据 |
| --- | --- | --- |
| P0 数据与前向核 | 材料快照、单位/约定、层序、稳定 R/T/A、基础背面模型 | 独立递推对照、守恒、吸收稳定性、双向与导入测试 |
| P1 目标与局部细化 | 目标/约束、厚度导数、固定结构优化、可复算任务 | 导数方向检查、规格留出网格、制造约束与取消测试 |
| P2 工艺分析与耦合 | 容差、良率、监控预测、逐层厚度图到性能图 | 已知误差模型回归、场景收敛、空间及监控校准用例 |
| P3 合成与高级功能 | needle、剪枝、多起点、反演、颜色、超快目标及高级等效结构 | 每项单独物理/数值验收，并明示有效范围与搜索预算 |

P0 首先保留 T07 的两个独立解法及异常策略；P1 接入 T08 已验证的代数，不把求解器藏在界面事件里；P2 形成可用于工艺决策的结果；P3 再扩大结构与模型范围。阶段由验收证据推进，暂不以未经评估的日历工期作承诺。TFCalc 3.5 的层数、数据点数等历史上限仅用于解释旧格式；新软件应采用可测量的内存、计算预算和任务资源限制，不继承任意旧上限。

### 材料反演的专门门槛

手册附录 C 提醒膜层不均匀、老化、工艺依赖和厚度不准会导致多组 n/k/厚度得到相近测量。典型 ±0.5% 测量精度是历史说明，不是现代仪器统一误差界限。M01 PDF 80–82，S2 70–72。

拟合前建立仪器带宽、角度分布、偏振、背面收光及测量协方差。优先用多角度、多偏振和 R/T/椭偏信息；测量不足时选更简单色散模型。输出参数剖面、条件数/秩、多起点候选和留出残差。残差接近测量误差并不证明解唯一；需要独立厚度或材料测量时明确提出。

### 开始实施前需要固定的产品决策

先确定第一批基准膜系与材料数据、真实规格、未知 k 政策、基底/收光假设和厚度导入约定。监控和空间耦合另需每层工艺映射、芯片比值与校准数据。所有高级功能采用统一服务契约，但按阶段开放，不把“最终全部功能”解释为第一版全部同时交付。

## 14 验收矩阵

阈值应按浮点精度、病态程度与实际测量能力设定，并与各用例一起版本化。下表列出独立依据和失败时应该拦截的风险，不以单一误差数覆盖所有问题。

| 用例组 | 独立依据或不变量 | 通过门槛 |
| --- | --- | --- |
| 裸界面 | Fresnel 解析式、法向/斜入射、Brewster | P/S 数值和通量定义一致 |
| 单层与周期膜 | 四分之一波增透/反射、独立 Airy | 谱形与极值一致；层序转换无误 |
| 长高反/厚吸收 | 散射与递推、溢出反例 | 有限输出；不靠截断掩盖错误 |
| 守恒与被动性 | 无损 R+T=1、吸收 R+T+A=1、通量积分 | 适用范围内守恒；吸收非负 |
| 反向与背面 | 同横向波矢互易性、相位平均板 | 正反几何一致；非相干平均收敛 |
| 约定和单位 | n−ik/n+ik、nm/µm、QWOT/物理、p 相位 | 往返不漂移；未知 k 不变成零 |
| 相位与场 | 振幅零点、频率网格加密、吸收密度积分 | 无定义输出有警告；导数收敛 |
| 厚度 Jacobian | 独立递推有限差分、方向导数 | 多步长收敛；能量导数一致 |
| 目标与约束 | 手算残差、重复场景、上下限 hinge | 权重不被节点数改变；约束不漏 |
| 局部细化 | 可重现合成用例、真实模型与留出网格 | 目标改善且规格/制造约束分别报告 |
| Needle 和合并 | 插入/替换厚度守恒、同材合并 | 结构变化正确；拒绝候选不丢失 |
| 搜索和 minimax | 固定预算/种子、密集留出峰值 | 不宣称全局保证；UNKNOWN 保留 |
| 制造误差 | 已知分布与相关性、公共误差样本 | 分布与种子可重建；无效样本不静默丢弃 |
| 良率与最坏值 | IID 统计用例、分位数收敛 | 样本极值/优化极值/置信度分开 |
| 监控 | 已知逐层曲线、芯片与产品倍率 | 单位/比值方向正确；多解和转折点有警告 |
| 空间耦合 | 均匀图退化到名义光谱、逐层人工图 | 坐标/材料/层映射正确；区域指标可复算 |
