# 膜系优化算法探索：第三轮云端研究

日期：2026-10-20。本目录汇集四项已完成的独立数值研究；发布研究记录、代码和可读数据，不涉及软件仓库发布。

## 主要结论

- **有限目录的停滞两编辑修复**：[研究报告](growth/研究报告.md)、[逐次结果](growth/results/runs.csv)。在12个合成种植谱族、每族4次顺序重复、721次光谱调用下，两编辑法密采样达标32/48；宽4前沿12/48、一编辑重启17/48、随机四层19/48。低预算检查点表现较差；单窗与双窗AR仍未达标。48次是12个任务的顺序重复，不是48个独立物理任务。
- **连续厚度双窗AR小试**：[结论](growth-continuous/小试结论.md)、[逐种子结果](growth-continuous/pilot/runs.csv)。两方法密采样最坏R中位数都是2.945886%，原1%目标均0/4达标。两编辑算子没有触发、两法轨迹相同；这既没有新增收益，也没有检验触发后的两编辑机制。4%校准4/4通过不能算作1%任务成功。
- **经典种子与混合搜索**：[研究报告](hybrid/研究报告.md)、[所有运行](hybrid/results/runs.csv)。4个固定问题、6种方法、5个种子共120次；全部未达到双窗逐点1%要求。完整n/k组中，混合法相对纯DE为3胜2负，配对差中位仅−0.00844个百分点；没有稳定普遍优势。
- **角度约束交换**：[研究报告](hybrid-angle-exchange/研究报告.md)、[逐种子结果](hybrid-angle-exchange/results/runs.csv)。10个起点中仅1个触发有效交换；合成10层seed47单例相对固定加密角方案改善0.371264个百分点。组中位数无总体收益，30次续优化仍未达标。

## 共同边界

这些结果属于固定有限搜索空间或特定连续优化小试。材料为合成常数n/k或有来源的表格n/k，采用平整、相干、各向同性层和半无限基片等模型。加密波长/角度网格与局部峰搜索仍是有限审计，不是连续域证书；搜索失败也不是不可行性证明。它们不构成真实器件、工艺容差或生产资格结论。各报告保留了负结果、撤回基线与计费限制。
