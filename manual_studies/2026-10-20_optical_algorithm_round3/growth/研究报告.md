# 停滞触发的两编辑结构修复：第三轮有限目录实验

日期：2026-10-20。独立云端研究，未修改主软件，未操作用户电脑，未发布仓库。模型全部为明确标注的合成无损常数材料。

## 结论

这次有一个值得继续研究、但尚不能替换默认策略的信号：在原有限2332栈目录、12个固定四层种植谱目标、每族4次候选顺序重复下，721次真实光谱调用后，“一编辑停滞才触发两编辑修复”的密采样达标次数是32/48；宽4纯分数前沿12/48、随机完整四层19/48、一编辑重启17/48。按实际层数加入计费的工作代理预算复核，分别为34/48、20/48、19/48、18/48。

同时必须保留三个反面：

1. 在81和241调用时，新法仅0/48、1/48，随机完整栈是2/48、4/48，一编辑重启1/48、4/48。完整两编辑邻域的前期成本会拖慢搜索。
2. 新法不是每族都赢。721调用时，相对宽4前沿的每族V中位数为7优、1平、4劣；相对一编辑重启是9优、0平、3劣。种植11新法1/4达标，前沿4/4；种植307新法1/4，随机完整栈4/4。
3. 优势只在已知可行的四层栈谱重建任务出现。单窗和双窗AR仍全部未达1%，没有解决真实双窗设计问题，也没有优于该有限目录原有最优值。

12个目标族才是12个设计任务。48是候选顺序重复总数，不能当48个独立物理任务，更不能据此宣称普遍或显著算法优越性。新增8族在算法冻结后才运行，但属于本次同一个合成目录的探索扩展，不是跨材料、跨目录的独立泛化认证。

## 1. 相比前两轮究竟变了什么

旧两层前瞻是在指定表面连续前置h层；旧复响应多样性改变前沿入口分配。这两项没有稳定胜过纯分数宽度基线，负结果完整保留为背景。

本轮先以任意位置的一次有限层编辑下降：可以插入、删除，或替换某一旧层的材料和目录厚度。完整一编辑邻域无改善时，才搜索结构图上距离恰好为2的合法端点。两次编辑之间的中间结构必须合法，但其光谱不必改善；端点真实评分更好才原子接受。仍无改善时，与一编辑对照采用相同的均匀完整四层随机重启。最好档案始终单调保留。

因此这是“允许旧层回修、在局部停滞时支付块修复成本”的机制；不是继续增加束宽，也不使用相位多样性。未实现连续厚度优化、一般可达性下界或生产级搜索器。

六个对照均从空栈开始：

- greedy_front：只在入射侧加一层，完整评估合法首层动作后接受最好改善；无改善或达到4层时真实停止。
- frontier_w1、frontier_w4：保留未选备用入口的纯分数前沿，每批展开1或4个入口；与旧h=1同类。
- random_full：均匀打乱全部合法四层栈，逐个评估；空栈也收费。
- one_edit_restart：上述任意位置一编辑下降，停滞后直接完整栈随机重启。
- stagnation_two_edit：同一编辑下降，停滞后先搜索距离2端点，再按同规则重启。

不可逆贪心实际只用10–28次调用，主结果并未把它冒充同预算强对照。主要机制消融是一编辑重启与两编辑变体，另有宽4前沿、完整栈随机搜索作强对照。

## 2. 冻结的模型、目标和评分

空气n0=1，半无限基底ns=3.42，正入射、相干、各向同性、平整界面、无背面。三种膜材料n=1.45、sqrt(3.42)、2.35；全部k=0，无色散。这些是合成数值，不指代任何真实材料，也不使用未知k补零。

膜厚目录为0.2、1/sqrt(3.42)≈0.540738、0.9 μm；最多4层，总厚不超过3.6 μm，相邻同材排除。每层实际正厚度在0.2–0.9 μm。目录排除相邻同材是有限参数化限制，不代表所有可合并且物理合法的连续厚度结构。长度0–4分别为1、9、54、324、1944个栈，总2332。

三种AR：4 μm单线R≤0.0001；3–5 μm整窗R≤0.01；3–5与8–12 μm双窗每点R≤0.01。空档无目标。

种植谱：按种子11、29、47、83、101、131、167、197、229、263、307、347加固定51000偏置生成合法四层栈；目标为该栈在双窗的反射谱，绝对容限0.002。前四族逐字对照旧目标，没有按新法胜负筛选。先以原四族做小试，发现互补收益与失败后冻结算法扩到后八族；小试原始数据保留在pilot。

训练双窗各41点共82点，单窗和单线也实际计算同一82点，只有指定窗口参加评分。AR令g=R/τ−1，种植谱令g=abs(R−R*)/τ−1。评分词典序是(max(0,max(g)),mean(max(g,0)^2),max(g))，再按层数、总厚和目录元组破同分。V=0才满足训练约束。目标接近0时不作为归一化分母。

### AR的负结果

最简单单线，贪心和两种邻域法都保留正确单层；复杂搜索不是必要条件，随机完整四层到721调用仍有1/4未达标。

单窗、双窗所有法仍0达标。纯分数前沿及两种邻域法在721调用到达原有限训练目录最优，密审计V分别约4.114932、4.372883，对应最坏R约5.114932%、5.372883%。没有连续厚度或其他材料/更多层不可行性结论。

## 4. 机制证据和不能由它推导的结论

独立事后穷举整个训练目录的结构景观：12种植族共有808个一编辑局部最小状态（逐族计数，重复结构按不同目标分别算）；其中745个存在V更低的距离2端点，并且连接最优该端点的所有合法一步中间结构都具有更大的V。完整局部最小列表全部保留，不只选择有利例子。

例如种植83，某个实际访问的单层[材料0,厚度0]状态，训练V=125.952154。到一个三层更优端点V=94.560162的两次编辑路径，其最佳合法中间层状态V=195.743731，明确先变坏再变好。独立密审计三者V约126.110020、195.756324、94.569534。精确结构、全部中间路径判别与密审计在mechanism_diagnostics.json。

这验证“单编辑改善门槛确会挡住有限协同路径”，不证明该两编辑端点是目标全局解，也不证明每次两编辑枚举都值得付费。新法的48种植重复记录111次完成的两编辑改善跳跃；预算截断时发现而入最好档案的端点仍有效，但不能冒充已完成整邻域选择的跳跃。

## 5. 真实调用、层数、工作和时间

每次唯一候选都真实执行一次未填充TMM，同一运行仅精确相同结构可缓存；不跨方法缓存响应，不把穷举表当搜索器。拒绝候选和未改善端点都收费。所有最终种植最好栈的层数中位数为4；不可逆贪心中位数为1，逐轮精确层数及总厚见CSV。

主试验每个非贪心运行恰好721次调用。12族×4顺序重复的各法成本为：

| 方法 | 实际调用 | 活跃波长×层更新 | 搜索墙钟合计/秒 |
|---|---:|---:|---:|
| 宽1前沿 | 34,608 | 10,318,224 | 3.81 |
| 宽4前沿 | 34,608 | 10,309,368 | 3.50 |
| 随机四层 | 34,608 | 11,335,680 | 3.59 |
| 一编辑重启 | 34,608 | 10,510,924 | 3.73 |

新法主结果没有通过多执行层循环获胜，但同调用也不是精确同硬件成本。工作敏感性因此固定Σ(1+实际层数)≤3605，尾部未用余额小于5；每项至少计一次调用基础成本，再加实际层数。此代理下，两编辑48重复实际37,643次调用、11,094,764层点更新；宽4前沿37,276次调用、11,124,120层点更新。代理不是精确FLOP或墙钟匹配，真实调用和活跃层点仍分别报告。

全部15任务×4种子×6方法的主试验执行217,308次搜索矩阵调用、65,818,284活跃层点更新；搜索合计约22.85秒，包含审计与写出全流程约26.52秒。工作匹配试验为230,507次、69,928,616层点，搜索24.39秒、全流程28.11秒。另有小试完整原始数据及独立测试回放，不混入主试验分母。

结构一编辑图仅依赖目录，预处理约0.11秒，单独列于配置；两编辑结构邻接可缓存并在多次运行间共享，不含光学目标信息。首次结构缓存构建会影响局部计时。方法顺序固定、共享云端微小墙钟仅作实现量级，不用于速度优越性结论。

每组完整试验另计2332次矩阵、2332次独立递推作训练目录参照，二者各726,930活跃层点。主试验最终审计231个不同“任务/档案栈”，429次矩阵、231次独立递推，分别25,627,745和12,650,033层点。工作匹配审计227组，423/227次、25,275,446/12,428,822层点。穷举参考自身的密审计也在每个oracle记录中明确保存，不能和搜索预算相混。事后结构景观诊断另外记账，详见其cost字段。

## 6. 固定密采样审计、复现与适用边界

每窗审计合并基网 `linspace(lo, hi, 4097)`（含端点）与第二套中点网 `lo + (j+0.5)(hi-lo)/4097`，其中 j=0..4096。两套网格在窗中心重合，合并后每窗8193个唯一波长点，双窗16386点；每窗也与41点训练网格重合9点，因此不是不相交留出集。每个搜索 run 结束后，才对该 run 保存的检查点作密采样审计；审计值和穷举 oracle 数值均不反馈给之后的搜索。种植目标在这些波长直接重算参考栈，不插值训练谱。

最终全部审计的矩阵/独立Fresnel最大反射率差约1.11×10⁻¹⁵，能量闭合最大误差约1.55×10⁻¹⁵。两种预算组均未发现训练通过而密采样失败的档案。密点一致仍不是连续区间证书。

本包的原核SHA-256为fb53b898a1e3db511c7ba98bb92648fd15b38f894de79fbeed312049a0acfca6，与旧研究逐字一致。9项测试已通过，覆盖有限目录/相邻同材边界、编辑合法和可逆性、两跳恰好距离、Fresnel/四分之一波/能量、旧目标一致、精确计费、档案单调、冻结审计、完整48×方法数据，以及一个完整721候选序列的精确回放。

同一9项测试在复制到另一目录、从无关当前目录执行时仍全部通过。独立保存结果核查另对2664个检查点逐个重算“实际已付费候选前缀中的最优”，全部一致；3427个记录的停滞/跳跃事件符合合法性与改善规则；168个小试运行的完整候选序列在扩展中逐个未变。这项核查另执行2332次训练矩阵调用、726930层点更新，不反馈搜索。

执行方式见README。数值运行依赖NumPy/SciPy；测试另需pytest。没有网络或原软件仓库依赖。

## 决策

保留此算子和失败记录作为后续研究组件，暂不进入产品默认流程。下一个应检验的问题是预算感知地截断/调度块修复能否减少低预算损失，并在更大目录、连续厚度精修和经过来源验证的真实材料数据上保留收益；必须给强基线同等自由度和真实成本。当前证据只支持这个明确有限机制的继续研究，不支持“新膜系算法已解决双窗AR”或“一定优于宽度基线”。
