# 2026-10-21 coating simulation follow-up

本目录汇总 0a631b7 研究快照中已经完成的多子堆、缓冲层、材料假设审计，以及一个公开 TFCalc **43 个物理膜层**实例的只读复算。它是研究记录，不是软件发布，也没有改动原研究基准或软件源码。

## 关键结论

- 原始冻结目标 `hr_broad_visible` 是 400–700 nm、0°/30°、s/p 均要求 R≥0.98，32 层、单层 10–500 nm、总厚≤5000 nm。有限枚举与受限结构搜索中，最佳 32 层候选为 4 个定中心子堆，中心约 447.330/546.194/618.896/734.475 nm，对数分配 4/2/6/4；独立审计最低 R=0.9566273，位于 424.612607 nm、30° p。未通过原门槛。完整离散枚举了 31,396 个 2/3/4 子堆排列，但不构成连续空间或目标不可行证明。
- 显式接缝缓冲研究的最佳 B2 参考含 70 层、6 个新增 HL 缓冲层、总厚 5354.571729 nm，最低 R=0.8865849，位于 686.500723 nm、30° s。它超出原基准层数及总厚上限，不能计入原基准通过率。
- 对上述 70 层几何，真实来源 k 模型在该最坏点 R/T/A=0.886585/0.000657/0.112758，损失主要是吸收；仅作为归因对照的全 k=0 0.25 nm 网格最低约 0.988420。此 k=0 结果不是材料替换、修复或资格通过；源 k 模型也显示不能忽略吸收。
- 公开 TFCalc 示例的 43 层最终物理厚度表，在原文常数折射率、无损、50° p、400–800 nm 条件下复算得波长均匀平均 R=98.02935%，加密网格最低为 97.11012%@800 nm。来源目标是“约 98% 平均”，不是全带最低 98%；该 43 层参考不属于原 32 层基准。
- TFCalc 固定几何只替换折射率的 M2 模型平均 R=98.21927%，但最低只有 79.55129%@400.692 nm；再加入 ZnS-A 与 MgF₂-R 来源 k 的 M4 模型平均降至 94.87910%，最低为 79.30715%@400.635 nm。M4 仍使用原例玻璃 n=1.52；不是块体 SiO₂ 仿真。
- 独立导纳矩阵与项目 TMM 的交叉复核中，A32/B70 的 R 最大差约 1.83×10⁻¹⁴、T 最大差约 8.05×10⁻¹⁶；现有数据未发现实现、层序或单位错误的证据。

## 材料和范围边界

多子堆、B2 与材料假设审计均是历史来源膜层数据场景：MgF₂-R 为 Rodríguez-de Marcos 2017 薄膜数据，ZnS-A 为 Amotchkina 2020 薄膜数据；其中 SiO₂-R 半无限端口来自 2016 薄膜数据，来源说明明确不可用来代表熔融石英块材。相关材料数据及有效域/工艺记录见 `material_source_records.json`，n/k 样点和行波损失示意见 `nk_attenuation_anchor_samples.json`。

TFCalc 原公开 M0 基线单独使用常数无损 n(H=2.35, L=1.45, glass=1.52)，没有采用上述 SiO₂ 薄膜数据。其 M1–M4 逐项替换仅针对膜层 n/k，M4 的基底仍是玻璃 n=1.52；M5/M6 才把 SiO₂-R 薄膜数据作为单独诊断替换。k=0 材料消融仅用于归因诊断，绝不是推荐的物性数据。

用户要求的新低 k 数据与块体 SiO₂ 场景尚未在本目录的这些已完成研究中验证；对应新研究仍在别处进行，本次有意不纳入，也不把旧结果标成新材料模型的验证。

## 可复核文件

- `prescription_tfcalc43.csv`：公开 43 层物理厚度表，保留源的基底向外次序并给出空气入射求解顺序；不可再套 QWOT 或角度缩放。
- `candidate_32l_multistack.csv`：最佳低维 32 层结构的沉积/入射序厚度及光学集标识。
- `candidate_70l_independent_HL_buffers.csv`：70 层 B2 结构处方。该候选超出原基准约束。
- `audit_summary.json`：核心审计数字、场景、来源与局限的紧凑记录。
- `recompute_tfcalc43_public_case.py`：独立固定几何前向复算脚本，仅依赖 Python 3 和 NumPy；运行后产生 `tfcalc43_lossless_reproduction.json`。不做优化。
- `material_source_records.json` 与 `nk_attenuation_anchor_samples.json`：薄膜材料的来源条件和少量核验样点，并非完整色散曲线。
- `PUBLICATION_MANIFEST.json`：文件哈希、来源审计包标识、公开引文和研究限制。

多子堆/B2 的正式终审采用 0.2 nm 密网格、0.1 nm 偏移和括住的局部极值。加密网格与局部极值检查是强数值审计，不是区间算术证明。多子堆/B2 的完整优化脚本需要特定软件快照（commit `0a631b7428486ab08fe0f27aa8938c50783f5280`）、依赖库和其材料目录；相关程序不是可直接在本目录执行的便携脚本，因此不伪称单靠 CSV 即可重现整场搜索。这里收录其紧凑审计结果与候选处方，不含原始大谱、全搜索转储或压缩包。
