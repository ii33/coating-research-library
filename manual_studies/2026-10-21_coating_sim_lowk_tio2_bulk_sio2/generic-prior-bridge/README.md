# 无答案处方种子的通用生成器桥接验证

该补充实验使用由来源数据和用户目标自动推导的止带宽及两个内部子堆栈中心，没有读取或使用既有答案处方作种子。在同一 32 层 TiO₂/MgF₂/块材 SiO₂ 案例中，生成先验、全层优化和独立审计通过 400–700 nm、0°/30° s/p 的 R≥98% 目标；生产冻结审计也通过。结果只验证这一固定材料/目标/架构案例的桥接，不等于通用可行性证明、软件集成完成、制造认证或连续谱证明。

中心 438.4511/638.6117 nm 是由端点范围、来源折射率对比及 1/3 无量纲调度参数计算得到的此次输出，不是硬编码常量。初始先验最低 R 约6.15%，优化后训练最低 R 98.7418%；独立审计最低 R 98.7354944% @402.5051 nm、30° p。生产审计最低 R 98.7354944% @402.5051 nm、30° p，并明确只对来源没有 k 的块材 SiO₂ 假设 k=0；已知薄膜 k 保留。

- `protocol.json` 记下来源依赖的止带宽公式、调度、预算和源哈希。
- `generated-prior.json` 是未优化生成种子；`optimized-candidate.json` 是后续优化结果，两者需区分。
- `independent-audit.json` 与 `production-frozen-audit.json` 是独立物理模型和软件生产冻结审计。
- `production-frozen-request.json` 的 seed 是自动生成、未优化先验，不是优化后的答案。
- 两个脚本仅将原路径改为本仓库相对路径/`COATING_SIM_ROOT`；需按根 README 的环境设置运行。运行会在本目录覆盖结果文件，请先备份或另行复制此目录复现实验。

这只是通用生成器的一个已验案例；需更广范围、无答案种子、不同材料与约束的独立验收后，才能说明更普遍的自动合成能力。锚点调度仍属候选策略，生产软件尚未集成此功能。
