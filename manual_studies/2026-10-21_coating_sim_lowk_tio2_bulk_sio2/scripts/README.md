# Reproducibility scripts

These research scripts are adapted only to remove the original machine-specific checkout path. They require an unmodified `coating-sim` checkout at commit `0a631b7428486ab08fe0f27aa8938c50783f5280`, and read source tables beside `tio2_research.py`. They write generated files only to `COATING_RESEARCH_OUT` (default: `runs/default`). See the repository-level README for the two commands.
