## 1. 阅读指南与工程问题

目标是为现有沉积与光学 MVP 形成成熟版理论边界、候选实现和可验证的阶段接口。受众为光学算法、沉积数据和仿真集成开发者。关键问题是如何把逐层空间膜厚映射到局部复薄膜响应，再分别交给几何偏振传输、复场成像与非顺序杂散光计算，同时避免把这些模型误称为一个已经存在的端到端引擎。

首轮范围是：逐层厚度资产、局部平面薄膜 TMM、Jones/Mueller、顺序几何结果到复光瞳、标量/矢量波动成像、光谱源/探测器、非顺序反射与散射。当前产品 MVP 的事实边界按稿件说明为共面顺序几何、透明体介质、局部 TMM R/T/A；稿件没有检查实际产品代码。反射树、衍射、体吸收和生产材料闭环不应表述为已经交付。

阅读顺序：先读专题一建立厚度—膜层—偏振契约；再读专题二连接相干场、PSF 与探测器；最后读专题三处理非顺序路径、杂散光和统计。原始全文分别见 [专题一原稿](incoming/01_polarized_thickness_mapping.original.md)、[专题二原稿](incoming/02_wave_imaging_bridge.original.md)、[专题三原稿](incoming/03_spectral_straylight.original.md)。

## 2. 符号、术语与单位

建议本项目接口统一采用 SI：位置、路径长度、真空波长为 m，角度为 rad，方向为单位向量，功率为 W；存储层可用 mm/nm，但在边界显式换算。逐层厚度记作 `d_i(u,v)`，坐标 `u,v` 属于带版本的物体/曲面参数化；mask 表示该层数据的有效域。`surface_id / side_id / layer_id / material_id` 是不同身份，不应由世界坐标正负推断。

波动计算的候选约定为 `Re{E exp(-iωt)}`、被动复折射率 `N=n+iκ` 且 `κ≥0`、正向传播因子 `exp(+ik0Nℓ)`。这使振幅衰减 `exp(-k0κℓ)`、功率衰减 `exp(-2k0κℓ)`；须与现有 TMM 采用的相位约定核对。来源分别采用不同 API 单位：Prysm 示例使用 nm/µm/mm，Optiland 常规顺序几何使用 mm/µm/degree，Raysect 使用 m/nm，均不得直接混用。[SRC-000048]、[SRC-000049]、[SRC-000090]

复电场 Jones、相干矩阵 C、Stokes 和 Mueller 各有不同信息量：Jones 保留确定场相位；C 保留偏振二阶统计；Stokes 是其四个实分量；Mueller 作用在 Stokes 上。Stokes V 正负、横向基方向、传播/观察方向与矩阵乘法次序尚需由项目统一。几何辐照度/点列图不等同衍射 PSF；单位积分 PSF、绝对响应和峰值显示图也必须分开。

## 3. 结构、理论与机理

### 3.1 沉积厚度到局部膜层响应

每次曲面命中先将全局交点映射到对应 `body/surface/side` 的局部 `(u,v)`，对每层按有效 mask 采样法向厚度和材料色散。局部平行、各向同性层堆可以用复数 s/p 反射和透射系数 `r_s,r_p,t_s,t_p` 及通量因子描述；其适用边界是局部平膜近似，不包含横向散射、光栅衍射或任意非平行层的全波耦合。[SRC-000001, §2–6]、[SRC-000002]、[SRC-000006]、[SRC-000014, §3–5]

原稿建议对有效域之外、缺失数据、真零厚度、未镀区域作不同状态；禁止静默填零、外推或从总厚度按比例反推每层厚度。膜厚物理含义（法向、固定方向或质量/面积换算）、沉积坐标变换、层序及相位参考面都应成为资产契约。

### 3.2 偏振输运与功率

相干单路径使用复 Jones 算子和横向正交基；部分/非偏振光使用相干矩阵或 Stokes/Mueller。每次 s/p 局部基改变都要显式变换到路径输出基。局部 Jones 可转 Mueller，但 Mueller 丢失公共相位，因此不能从其恢复后续衍射所需的复瞳。不同独立路径可在公共探测器基底上加 Stokes；同一相干组应先加场再算强度。[SRC-000008, §2–3]、[SRC-000024]、[SRC-000077]

透明、无吸收端口的简式可写 `T=|t|² q_out/q_in`，其中 `q=n cosθ`。若用端口导纳表达，则 `T_q=Re(Y_out,q)/Re(Y_in,q)|t_q|²`，Y 必须与切向场幅定义一致。两种写法不能不加条件地外推至吸收介质；此处保留为实施前需数值核对的接口约定，不宣称已由本包求解器验证。膜层吸收、体吸收、未追踪反射、遮挡、窗口外泄和数值截断应分项记账。

### 3.3 从几何路径到波动成像

波动桥至少需要 `field_id / wavelength / mode_id / branch_id`、命中和传播坐标、差分 OPL、局部基、复 Jones、孔径面积/采样 PDF、有效状态和功率归一化信息。复瞳的候选结构为 `Pλ(u)=M(u) a_geom(u) J̃λ(u) exp(i 2π W_bulk(u)/λ0)`；膜层复相位单独留在 J 中。参考面、参考球、piston/tilt/defocus 处理及光线管面积 Jacobian 要明确。近轴 Fourier 示例、Fresnel、角谱、Huygens/RS、矢量聚焦和 Gaussian beamlet 适用域不同；高 NA、焦散、亚波长结构或明显非局域效应需要更强模型，不能靠增加 FFT padding 补回。[SRC-000008]、[SRC-000028]、[SRC-000031]、[SRC-000033]、[SRC-000036]、[SRC-000058]

偏振成像应在场域或相干矩阵上传播，再按输入 C 形成 `Tr(H C H†)`。非偏振输入为 `C=I/2`；斜线偏振有交叉项。宽带通常按每个波长传播并在共同物理像面网格上按光谱、吞吐率、QE 和 `λ/(hc)` 积分；不把不同波长复场直接相加。PSF 的绝对通量、单位积分形状和显示峰值归一化分开保存；像素面积积分先于采样，随后才叠加 QE/噪声/增益。

### 3.4 非顺序、鬼像与表面/体散射

局部膜堆内部反射已经包含在一次 TMM 复响应中；它与宏观表面间往返是不同层级。非顺序模型需追踪宏观反射/透射分支、双面位置重采样、体吸收和表面 BSDF，并保留路径类别、深度、权重和统计量。重要鬼像可枚举/有限分裂，其余采用按正确 PDF 补偿的重要性采样/俄罗斯轮盘；不得静默丢弃路径，Q/U/V 不能按正概率夹紧。相干路径保留场和 OPL，互不相干路径才加 Stokes/强度。[SRC-000079]、[SRC-000080]、[SRC-000081]

实测 BRDF/BTDF 要带波长、入射/出射角、偏振基、镜面峰处理、角分辨率和校准误差；单独 RMS 粗糙度不足以定义散射尾部。若 BSDF 已含镜面峰，不得再叠 Fresnel delta；与光滑 TMM 相结合时需重新分配 specular/scatter/absorption 能量。均匀体吸收可按 `exp(-αℓ)`, `α=4πκ/λ` 作为候选，但偏振体散射、各向异性吸收及强吸收斜入射仍是独立开发/验证项。[SRC-000083]、[SRC-000084]、[SRC-000085]

### 3.5 公开实现能力边界

推荐按用途选型，而不是寻找一个“现成全链”：Optiland 可作为顺序几何、薄膜偏振与波前/PSF 对照；Prysm/HCIPy 作为波动传播与偏振参考；Mitsuba 3/Dr.Jit 作为需自定义膜层 BSDF、色散、偏振和工程探测器的非顺序输运底座；PBRT-v4/Raysect 作标量光谱/采样/辐射度交叉检查。以上能力均是原稿报告的公开实现范围，不代表已在本项目集成或运行。Poke 的开放 PRT/beamlet 内核不等于无需商业追迹器的完整几何入口。

## 5. 工程方法与可复用步骤

以下是建议的数据流，不是已经实现的接口签名：

1. **`ThicknessSampler`**：输入有版本的逐层厚度资产、`body/surface/side/layer/material` 身份、命中 `(u,v)`；输出带单位的厚度、mask/有效状态、误差/置信度与插值来源。超域/缺层返回明确错误，不外推。
2. **`CoatingResponse`**：输入真空波长、入射侧、方向/法线、入出介质、层序和每层复折射率/厚度；输出复 r/t、功率 R/T/A、端口通量因子、局部入/出基、适用域和错误标志。复振幅、电场归一化和功率归一化不混用。
3. **`PolarizedTransport`**：输入相干模式/路径、Jones 或 coherency/Stokes、局部基、OPL、膜层算子和分支选择；输出变换后的场/统计、能量分类账、路径及相干组标签。每个算子明示其是 field/Jones、Mueller 还是辐亮度 BSDF。
4. **`WavefrontExporter` / 波动后端**：输入参考面、复场、面积 Jacobian、OPD、mask、波长和模式；输出有绝对通量标度的场、PSF/OTF/MTF及收敛记录。
5. **`NonSequentialTransport`**：输入确定版本场景、材料/散射表、谱和源分布；输出分路径类别的探测器通量/Stokes或指定相干通道复场、Monte Carlo 方差/截断账。
6. **`DetectorIntegrator`**：输入谱辐照度/光子率、像素面积、QE、时间响应和像素矩阵；输出 electrons、DN及噪声字段。输入若已是 e⁻/s 或 photons/s/nm，不重复乘 QE、`λ/(hc)` 或 `Δλ`。

唯一状态所有者、异步取消边界和软件模块名必须以后由实际 API/数据结构确定；本研究没有修改或声明产品签名。当前研究 package 仅列逻辑契约供审核。

## 8. 失败、反例与局限

- 局部平面 TMM 不产生边缘衍射、横向散射、光栅级次或近场耦合；波长尺度结构应升级到 RCWA/FDTD/FEM 等局部模型或拒绝标记。
- 只存 R/T/A 或 Mueller 不能给后续衍射所需相对复相位；非偏振 Stokes 射线路径也不能恢复不同空间位置间的互相干。
- 薄膜堆内的相干反射与宏观表面之间鬼像不能重复计算；功率和复场两套归一化不可双重乘损耗。
- 随机追迹未命中某个弱鬼像不提供上界；零命中界限仅在适用独立 Bernoulli 条件下成立。重要性抽样、分裂子路径相关性和长尾需按批次/父样本统计。
- 单一 RMS 粗糙度不能确定 BRDF 尾部；散射测量中的镜面峰若已包含，不能再叠加 Fresnel delta。
- 厂商/软件公开的功能、许可证和动态文档版本不能跨版推断，也不自动验证产品环境。
- 三份原稿的版本快照日期不同；Optiland 与动态文档尤其不能合并成“统一版本事实”。
- 本包来源未重新打开，因此可能保留原稿元数据/结论错误；有争议但无法裁定的事项已列入“待裁决”。
