# 位置相关逐层膜厚到偏振光追：成熟版理论、开源证据与工程边界

研究日期：2026-10-10。用途：光学生产仿真研究库增补稿。范围：沉积输出的逐层厚度场 → 局部薄膜复振幅 → Jones / Mueller → 几何光追及后续波动光学接口。

## 0. 结论与证据等级

建议保持现有“逐层资产显式 ID 映射 + mask 有效域”，把成熟版增量组织为三个独立接口：`ThicknessSampler`、`CoatingResponse`、`PolarizedTransport`。先完成复振幅、坐标基和功率归一化契约，再增加三维路径、反射分支、体吸收和衍射。仅有局部 R/T/A，不能推得偏振相位，也不能推得系统 PSF。

- **已核验**：直接阅读论文正文、官方源代码或官方文档；代码阅读仅证明实现存在，不等于已经运行通过。
- **工程推断 / 建议**：基于上述物理模型给出的本项目数据契约、误差控制和实现分期，不冒充论文原结论。
- **未核验**：本次没有运行这些软件，没有复现论文图、没有检查用户仓库或 Windows 环境；商业软件许可证、供应商精度承诺和端到端复现实验均未验证。

当前 MVP 仍是共面顺序几何光追、透明体介质、局部 TMM R/T/A；没有反射分支、衍射和体吸收。本稿不改变这一已交付边界。

## 1. 六组优先来源与可复用范围

### S1. Byrnes：平面膜堆参考物理

Steven J. Byrnes, *Multilayer optical calculations*, arXiv:1603.02720。阅读版本为 v5，提交记录日期 2020-12-30；引用年份可保留初版 2016，不采用 HTML 自动生成的页眉日期。重点是 §2–4 的复振幅与功率、§5/附录 D 的复角分支、§6 的相干/非相干混合、附录 A 的反射符号。[全文与章节](https://arxiv.org/html/1603.02720v5)

适用模型是局部均匀、各向同性、非磁性平行层。它不是横向变化膜层的 Maxwell 全波解。吸收入射介质时，界面处净入射功率不必等于 `1-R`，不能对全部场景机械应用 `A=1-R-T`。

### S2. tmm 与 PyMoosh：数值参考核

**tmm 已核验**：版本 `0.2.0`，commit `462b63b517472b3b18245c98d70e700f4d312866`（2024-11-26），MIT。`coh_tmm` 返回复数 r/t、R/T、`power_entering` 和层内场；`inc_tmm` 提供相干层组与非相干层混合的强度解。标量参考实现一次处理一个波长和入射角；不是几何追迹器。其极不透明层有 `Im(delta)>35` 的数值截断，比较极小透射时必须记录。[源码](https://github.com/sbyrnes321/tmm/blob/462b63b517472b3b18245c98d70e700f4d312866/tmm_core.py)、[版本](https://github.com/sbyrnes321/tmm/blob/462b63b517472b3b18245c98d70e700f4d312866/pyproject.toml)、[许可证](https://github.com/sbyrnes321/tmm/blob/462b63b517472b3b18245c98d70e700f4d312866/LICENSE.txt)

**PyMoosh 已核验**：稳定分支 commit `b236ec8bc18f2f725ae691b530e98823ecd3d4b2`（2026-07-23），MIT；`core.py` 有 `cascade`、`coefficient_S`、`absorption_S`。论文 §II.2/II.6 比较 S-matrix 与 T/Abélès 的稳定性，适合作为高反膜、倏逝波和金属层的独立数值参考。不要把“更稳定”写成所有输入均无奇点；文中也列出特殊失效点。[论文 v4](https://arxiv.org/html/2309.00654v4)、[实现](https://github.com/AnMoreau/PyMoosh/blob/b236ec8bc18f2f725ae691b530e98823ecd3d4b2/PyMoosh/core.py)、[许可证](https://github.com/AnMoreau/PyMoosh/blob/b236ec8bc18f2f725ae691b530e98823ecd3d4b2/LICENSE.txt)

工程选择：普通膜堆用 tmm 对齐物理与符号；病态/深衰减情形再用 S-matrix 交叉校核。PyMoosh TM 使用的场变量和相位基准须适配后才能比较复数系数；不能只按函数返回名直接替换。

### S3. Poke：膜层到三维偏振传播的直接参照

Ashcraft 等 2023，*Poke: An open-source ray-based physical optics platform*，§2、§3.2–3.3 已展示几何 ray data、Jones pupil、空间变厚度膜层和物理光学接口。2023 文中自动追迹接 Zemax / CODE V，§5 把开源几何追迹接口列为未来工作。因此该论文证明的是开源偏振/物理传播桥接能力，不能证明当时的几何建模链无需商业软件。[论文](https://arxiv.org/html/2309.04649v1)

当前核验 commit `2e4a29ecce321315724ecf88be63ad7a4b4e5c07`（2025-05-05），BSD-3-Clause；`setup.cfg` 声明 `1.0`，文档显示 v1.0.0，论文参考文献出现 v1.0.1，故本稿以 commit 为复现定位，不混称成同一发布版本。[许可证](https://github.com/Jashcraf/poke/blob/2e4a29ecce321315724ecf88be63ad7a4b4e5c07/LICENSE.md)、[包元数据](https://github.com/Jashcraf/poke/blob/2e4a29ecce321315724ecf88be63ad7a4b4e5c07/setup.cfg)

源代码确有逐射线数组膜厚、3D 局部基变换、系统 PRT 连乘、double-pole 输出基以及 Jones→Mueller；它们是可读实现，不只是论文设想。[thinfilms.py](https://github.com/Jashcraf/poke/blob/2e4a29ecce321315724ecf88be63ad7a4b4e5c07/poke/thinfilms.py)、[polarization.py](https://github.com/Jashcraf/poke/blob/2e4a29ecce321315724ecf88be63ad7a4b4e5c07/poke/polarization.py)

代码里的相位修正是与本库系数定义配套的；尤其反射分支会对特定薄膜求解器的 p 系数加 π。不能复制该行去“修正”另一个已经遵守 Byrnes 约定的求解器。[官方薄膜教程的相位约定说明](https://poke.readthedocs.io/en/latest/notebooks/thinfilm_optimization.html)

### S4. GSMT coating variation II：空间变膜厚的应用实证及限制

Ashcraft 等，A&A 695, A28 (2025)，DOI `10.1051/0004-6361/202452671`，arXiv:2501.03897。直接读到 §3 的 Zernike / PSD 厚度屏、§4 的统计试验、§5 的偏振成像。实验变化主要施加于保护/氧化层，反射层理想化，并用理想 AO 消除公共相位。其地面天文情形下“额外影响小”的结果不等价于任意生产光学系统的膜厚容差宽松。[论文正文](https://arxiv.org/html/2501.03897v1)、[出版信息](https://arxiv.org/abs/2501.03897)

配套仓 `polarization-gsmts-II` 已公开，核验 commit `8a63490092c427baf82253c02c7a100d8c30dc36`（2024-03-09）；`gsmt.py` 确实把厚度数组送入 Poke，并可选择读取序列化 Rayfront 或调用追迹。完整文件树未见 LICENSE，不能把 Poke 的 BSD 许可自动套给此仓。仓库脚本、论文和 Zenodo 快照的逐文件一致性未核验；本次 Zenodo 页面未能读取。[仓库](https://github.com/Jashcraf/polarization-gsmts-II/tree/8a63490092c427baf82253c02c7a100d8c30dc36)、[实际脚本](https://github.com/Jashcraf/polarization-gsmts-II/blob/8a63490092c427baf82253c02c7a100d8c30dc36/gsmt.py)

### S5. Optiland：可自给的顺序几何 + 薄膜偏振候选

## 2. 成熟版必须明确的物理状态与接口

以下为工程建议，基于 S1/S3/S5/S6 的物理结构。

### 2.1 射线、场、功率三种对象不能混写

建议每条几何路径保存：位置 r、单位方向 k、真空波长 λ、介质 ID、累计光程、命中 surface/body/side ID、分支父 ID、有效状态；另保存横向正交基 B=[e1,e2]、偏振状态和相干组 ID。

偏振数据可选：

1. 确定的相干输入：2 分量复 Jones 向量，或输入到当前面的累积 2×2 Jones 算子。
2. 部分偏振或非偏振输入：2×2 coherency matrix C=〈EE†〉，或 Stokes S。确定的 Jones 算子仍可作用于部分偏振输入：C_out=J C_in J†。不能用一个 Jones 向量代表非偏振光。
3. 需计算衍射时：还必须有跨 pupil 采样点的相对相位、采样权重/面积、坐标、OPD、遮挡和相干关系。逐射线 Stokes 本身不足以恢复这些相位。

选定一种强度归一化：电场振幅系数与功率系数分开，或将振幅定义为“平方模等于分支功率”的功率归一化振幅。禁止既在 Jones 中乘透射振幅，再在同一强度上重复乘 T。

### 2.2 膜层响应应返回的最小集合

输入：λ、入射侧、局部入射角、按光学穿行顺序排列的复折射率 N_i(λ)、每层法向厚度 d_i(u,v)、材料与厚度资产版本。

输出：r_s、r_p、t_s、t_p；R_s/R_p/T_s/T_p；可选逐层吸收和总膜层吸收；入/出通量因子；相位/时间/反射基约定；半无限边界声明；适用域与错误标志。

`A_coating`、`A_bulk`、未追踪反射、出孔径/遮挡、数值截断损失应分别入账。当前 MVP 未生成反射光线，不代表局部反射功率被吸收。

### 2.3 统一约定，而不是追求某个符号“绝对正确”

建议内部统一 `exp(-iωt)`，被动材料 N=n+iκ、κ≥0。层相位厚度 δ_i=(2π/λ) N_i d_i cosθ_i。边界前向根由衰减方向和前向 Poynting 通量确定，不能仅使用语言默认的复 arcsin 分支。S1 与 tmm 的 `is_forward_angle` 是直接可检查的参考。

对透明入/出体介质，选局部 s=normalize(k_in×n)，p_in=k_in×s，p_out=k_out×s；于是 [s,p,k] 为右手基。按 Byrnes 的 p 反射约定，可以用：

`E_out = B_out · diag(a_s,a_p) · B_in^T · E_in`

其中 B_in/out 是 3×2 基矩阵，反射 a=r，透射 a=t。3×3 PRT 只是这一几何映射的方便扩展，其纵向分量不是第三个可传播偏振自由度。若应用层保存另一个横向基，则在两侧额外投影到该基。

**反射检验**：空气到玻璃正入射，在该约定下 r_s=-r_p。因为 p_out 与 p_in 相反，实际全局反射 E 场的两个横向分量仍具有相同的物理相移。只看到 r_s/r_p 相差 π 就宣布“正入射镀膜有半波延迟”是错误的。Poke/Optiland 所需的显式负号与其求解器定义有关，必须测试完整“系数 + 出入基”，不做孤立修补。

**正入射退化**：k×n 趋于零时，不能正规化零向量；应从上一横向基连续延拓、投影并正交化，必要时选与 k 最不平行的固定轴作确定性备用。阈值与双精度相关，不能只判断严格相等零。输出 Jones pupil 还要统一 entrance/exit 基；几何平行输运的旋转与材料延迟应分别报告，避免把几何基旋转误报为膜层 retardance。

### 2.4 通量归一化和 Jones→Mueller

对透明边界，T=|t|² q_out/q_in，q=n cosθ。若使用功率归一化振幅，透射系数应为 t_hat=t·sqrt(q_out/q_in)；反射留在同一介质，可直接用 r。电场幅度 t 可能大于 1，这不意味着功率增益。吸收边界的 q 定义需按 s/p 的 Poynting 公式处理，不能把实折射率公式外推。

建议文档显式定义 S=(I,Q,U,V)，采用 V=2 Im(E1* E2)，则 C=1/2 [[I+Q,U-iV],[U+iV,I-Q]]。使用与此一致的 Pauli 基，可由 M_ab=1/2 Tr(σ_a J σ_b J†) 生成 Mueller。该公式是本稿约定的写法；与外库对接必须检查 V 的符号、传播/观察方向、向量排序和矩阵左右乘顺序。

同一几何基下，非相干样本可加 C 或加 Stokes；不能先平均 J 再取强度。一个确定的局部各向同性平膜自身是非退偏 Jones 元件，但对波长、角度、位置、粗糙结构或多路径进行不可分辨平均后，有效 Mueller 可能退偏。Jones→Mueller 会丢掉公共相位，不能再从 Mueller 唯一恢复用于衍射的 Jones 场。

## 3. 逐层厚度有效域、插值、双面与曲面

本节是项目接口建议；S1 的横向均匀假设和 S3/S4 的空间变厚度实例是依据，不声称这些开源包已实现下述资产管理。

### 3.1 每层资产必须带有的语义

- `body_id / surface_id / side_id / layer_id / material_id`、单位、批次与版本、物理层序。
- 沉积坐标系与光学曲面坐标系之间的刚体变换/参数映射；原点、轴向、手性、镜像/翻面标志、曲面参数化版本。
- 厚度是沿局部法线、固定测量方向，还是由质量/面积换算而来；三者不能无条件互换。
- 厚度值、有效 mask、置信度/误差、插值模式及禁止外推域。

特别区分：真实零厚度、未镀区域、未测得数据、曲面之外。mask 外不得默认填零、边界夹持或从相邻零值混合得出“薄膜”。某层数据缺失时，不从总厚度或其他层比例反推，除非存在独立、显式授权的模型与不确定度。

### 3.2 曲面映射

几何交点 r_hit 先进入物体局部坐标，再由曲面参数化 r(u,v) 找采样位置；同一次命中同时获得局部法线 n(u,v)。姿态变化应改变变换，而不重新解释沉积资产本身。前后两面分配独立 side_id 与映射，不能靠 world z 的正负猜面。

TMM 所需 d 是层法向间距。若已知“厚度”严格定义为沿单位方向 a 穿过一对局部平行界面的距离 d_a，可局部换算 d_n=d_a·|a·n|；但沉积通量的投影面积定义、QCM 标定值和表面法向增厚并不自动满足这一几何定义，必须先查资产物理含义。

需另外声明 TMM r/t 的参考面在实际膜顶、理想基面还是基片界面。若把总膜厚加入几何 sag，同时再使用以另一参考面定义的膜层相位，会双算或漏算相位。膜厚导致的几何形貌、膜内干涉相位和基片外部光程只能各计算一次。

### 3.3 插值规则

优先插值物理 d_i，再求局部 TMM。规则网格可双线性，三角网格可重心插值，但仅使用同一连通有效域内节点；孔洞、边缘、不同段镜接缝不能跨越。插值失败应带原因返回，不静默外推。高阶样条必须验证不产生负厚度或边缘过冲。

响应缓存若直接插 r/t，应在统一相位基准下插实部与虚部，并细分迅速旋转的相位区；在系数零点附近禁止依赖 unwrap(angle) 的相对相位误差。插值平均 d 后求响应、平均响应、平均强度三者一般不同，选择应由“单条射线命中”还是“探测器空间平均”的语义决定。

### 3.4 局部平膜近似的失效门槛

每个命中位置独立求 TMM，隐含该处各层近似平行、横向变化在相互作用范围内足够缓慢。需同时检查曲率尺度远大于波长/总厚度、局部厚度变化尺度、斜入射的层内横向位移，以及边缘/缺陷附近的局部性。没有适用于所有材料和精度要求的单一“梯度阈值”。

因此：缓变膜厚可以生成位置相关复振幅；它不会自动生成边缘衍射、横向散射、光栅级次或近场耦合。较大相位梯度可能影响波前/能流方向，但不能用一次普通 Snell 折射声称已处理；须由后续波动传播或受控的相位面模型承接。陡变、波长级结构、非平行层、各向异性膜应触发升级/拒绝标记，而不是继续输出“高精度局部 TMM”。

### 3.5 双面与反向入射

沉积次序通常从基片向外，光学入射次序可能恰好相反；这是两种不同排序。把 layer_id 对应的物理层序固定，再由入射侧生成 n/d 列表。反向命中须交换入/出体介质并反转有限层顺序，重新计算角度和系数；不能复用正向 r/t，不能假设有吸收的不对称膜两侧 R 相同。

双面元件应追踪“前表面膜 → 基片路径 → 后表面膜”。后面命中坐标与前面一般不同；内反射返回前面时又是新坐标。即使平行平板，内部往返也有约 2L tanθ_sub 的横向偏移。只有横向均匀或这种偏移相对于变化尺度可忽略，才可以把双面/基片折叠成一个一维等效膜堆或局部无限级数。这是空间变膜厚系统的重要额外限制。

## 4. 相干、非相干基片与体吸收

### 4.1 三种计算模式应显式选择

1. **薄膜内相干，体介质几何传播**：当前最自然的成熟版第一步。膜层内多次反射已在局部复 r/t 中求和；不能再把这些纳米层内反射当几何分支重复生成。
2. **有限基片也相干**：窄线宽、平行/稳定基片形成 etalon 时，需保留各次穿越的相位并在同一输出模式/参考面相干求和，或在满足一维条件时将其作为有限层加入相干解。普通强度反射树不够。
3. **基片往返去相干**：源带宽、角度分布、厚度变化或探测分辨率使不同往返相位被平均，可用混合相干/非相干模型或非相干路径求和。不能仅依据“基片毫米级”自动选模式。

S1 §6 与 tmm `inc_tmm` 支持第三类的标量 s/p 功率处理，但没有提供任意三维多路径完整偏振算子的即插即用接口。**往返去相干不等于同一路径中的 s/p 相对相位被清空**，更不等于每经过一次厚基片就将光强重置为非偏振。

工程上的完整偏振平均应为 C_out=Σ_m J_m C_in J_m†；相干路径则先加复场或算子，再求 C。若是有限带宽的部分相干问题，可对物理波长/角度/厚度分布进行相干求解后按探测规则平均，或引入互相干模型。仅有四个标量 R_s/R_p/T_s/T_p 不能唯一确定一般 Mueller。

### 4.2 体吸收的渐进式支持

对弱吸收且采用实折射方向的均匀体介质，可先实现功率 Beer–Lambert：I(ℓ)=I(0) exp[-(4πκ/λ)ℓ]，ℓ 是真实几何路长，而不是元件轴向厚度；复振幅相应衰减一半指数。该模式应标注“弱吸收实射线近似”。

强吸收/斜入射时，复波矢、衰减方向和能流方向可能不共线。不能把 complex N 简单塞进原实数 Snell 求交，再称已支持一般吸收介质。局部平面问题应按复角/Poynting 模型求解；一般三维体传播须另行建立并验证，暂不支持比静默取 real(N) 更安全。

对透明入射介质的局部膜堆，膜内总吸收可用 1-R-T；T 若流入吸收性半无限基片，表示刚进入基片的通量，不表示穿过真实有限基片后仍存活的能量。若入射半空间也吸收，应按 `power_entering-T` 和实际场通量区分有限膜层吸收，不能把异常 R+T 直接裁到 1。

## 5. 复杂度、缓存和误差预算

以下复杂度为算法分析，不是跨平台实测性能。

- 设有效命中总数 H、每命中膜层数 N：局部 2×2 相干核的算术量 O(HN)，s/p 为常数倍。顺序系统 H≈N_rays×N_surfaces×N_λ；若 λ 已按单射线分配则勿重复乘计。
- 每命中只求外部 r/t，可用 O(1) 累积矩阵工作内存；保留各层内场/吸收所需中间量为 O(N)。批处理 B 条命中时，通常为 O(BN) 输入/中间储存，可分块。
- tmm 参考代码为方便索引分配 N×N 的 r/t 数组，因此它的实际工作内存及分配开销不是最小 O(N)。生产 kernel 可只存相邻界面，不必照搬该数据结构。[S2 tmm 源码]
- 3D 基变换与 2×2/3×3 累乘，每次命中 O(1)。新增反射/透射双分支若无控制，随事件深度呈指数增长；要规定最大事件数、最小分支功率、遗漏能量账和路径合并条件。随机采样还需方差/置信区间，不能只报告均值。
- 高反/厚吸收/倏逝层的 T-matrix 可能溢出或抵消。建议保留稳定 S-matrix 路线；不要用裁剪 R/T/A 掩盖数值失败。[S2 PyMoosh §II.6]

### 5.1 缓存键和维数问题

精确键至少包括膜堆物理层序、材料/色散版本、每层 d_i、λ、角度或切向波数参数、入射侧、入/出介质、时间/相位/功率归一化约定、算法版本。局部各向同性堆的 s/p 系数不需把全局方位角放进光学核缓存，但几何基旋转必须在缓存外正确执行。

N 层厚度独立变化时，稠密查表维数约 N+2，不适合盲目张量网格化。优先方案：

1. 缓存色散和固定层界面项，批量直接求局部厚度；
2. 对有证据的低维工艺参数（整体比例、少数 Zernike 系数、几种实际相关层模式）建立响应代理；
3. λ/角度自适应网格 + 逐命中精确回退；
4. 用层敏感度指导分辨率，而不是所有层统一纳米步长。

不能为省维数把独立层厚度强制缩成“总厚度倍率”。

### 5.2 缓存必须验收复量和最终指标

局部一阶误差估计可写为 δJ≈Σ_i (∂J/∂d_i)δd_i+(∂J/∂λ)δλ+(∂J/∂θ)δθ；这是线性化估计，不是共振附近的严格上界。厚度场测量误差、映射误差和缓存误差应分项记录。

对独立随机验证点，与直接核比较复 r/t 的绝对误差、R/T/A、延迟差和 Jones 算子范数；在 |r|≈0 或 |t|≈0 时用绝对复误差，不用不可定义的相位相对误差。增加 Brewster、临界角、窄带峰谷、mask 边缘、极值厚度和反向入射的加密测试。

系统误差可用矩阵乘积的逐项扰动界分析；对于正确功率归一化、被动且框架正交的单分支算子，范数不超过 1 时，绝对算子误差有保守的逐面累积上界。高消光比/暗场指标可能受相消影响，局部 10⁻⁴ 误差并不保证最终暗场的相对精度；必须额外验证用户实际的透过率、消光比、色差或 PSF 指标。

## 6. 验证矩阵与验收策略

下列是建议测试计划，不是本次已完成的测试。先用 float64、无缓存、明确单位和约定构建可复现基准；给一般良态案例设约 10⁻⁹ 量级的绝对系数/能量测试是可研究的起点，病态点应采用专门误差预算，不能强制统一阈值。

| 类别 | 案例 | 必须检查 |
|---|---|---|
| 单界面 | air→glass 正入射、倾斜入射 | Fresnel r/t 复数、通量因子、正入射全局偏振等价 |
| 角度极限 | Brewster 两侧、临界角两侧、TIR、近掠入射 | 根分支、有限值、TIR 相位；零点不用 phase 相对误差 |
| 膜层极限 | d=0、同折射率相邻层合并、单层四分之一波 AR | 与解析极限一致；层序和单位正确 |
| 吸收膜 | 介质/金属混合、厚不透明层 | 逐层吸收非负（容差内）、通量闭合、S-matrix 交叉对照、截断标志 |
| 反向堆 | 不对称有损多层，双方向照明 | 入出介质与层序反转正确；不强制两侧 R 相等 |
| 三维基 | 整体坐标旋转、绕光线换基、正入射穿越 | 最终物理量不随任意坐标选择变化；基连续、无 NaN |
| 非共面路径 | 两/三折叠镜、空心角锥类基准 | 交叉偏振、几何输运、材料延迟区分；与锁定 Poke 算子比较 |
| 输入偏振 | H/V、±45°、两圆偏振、非偏振 | Jones 与 C/Mueller 一致；Stokes 满足 I²≥Q²+U²+V² |
| 厚度映射 | 常量、线性梯度、局部二次、旋转/翻面、前后面 | 同一物理点同值，layer_id 乱序不改变映射，单位一致 |
| 有效域 | 孔洞、断开区域、缺层、真零厚度、外推 | 无跨 mask 污染；缺失不伪装成裸片 |
| 有限基片 | 均匀 Fabry–Pérot，逐渐谱/角度平均 | 相干条纹、非相干平均、相干组正确；无双计薄膜内多反射 |
| 空间变双面 | 两面独立梯度 + 斜入射鬼像 | 每次返回重新采样位置；区别于一维局部折叠模型 |
| 体吸收 | 直线和斜路径、路径长度翻倍 | Beer–Lambert 与 ℓ 一致；膜吸收和体吸收分开 |
| 分支预算 | 平板多次反射直至收敛 | 出射+吸收+截断+遮挡功率闭合，阈值收敛 |
| 缓存/抽样 | 分辨率加倍、分块尺寸改变、随机 holdout | 复振幅/系统指标收敛；缓存命中不可改变物理结果 |
| 后续衍射 | 均匀无像差孔径、单一相位梯度、双路径干涉 | 正确相位与权重；有/无偏振的解析极限 |

验收报告应附：材料谱表来源、模型版本、软件 commit、坐标与相位约定、测试输入、参考输出、误差量纲、有效域、未覆盖场景。tmm 与 Poke 使用相似物理推导，不能把两者数值一致当成独立实测证明；至少再加入解析极限、S-matrix 及实验/商业参考中的适用一项。

## 7. 成熟版分阶段建议

### A. 固化数值与资产契约

保留现有显式逐层映射；补齐单位、法向厚度、物理层序、前后面、坐标/相位参考面、色散有效域。局部核增加复 r/t、错误状态与吸收账。完成单界面/单层/反向/有损基准。交付仍可保持当前共面顺序范围。

### B. 三维顺序偏振传播

实现稳健横向基、累积 Jones、C/Stokes 输入输出、通量归一化、统一 entrance/exit Jones pupil 基；对照 Poke，但使用自己的几何命中/法线数据，或以 Optiland 顺序路径作为第二参考。没有反射分支时，只能支持指定的镜面/透射路径，不宣称一般鬼像追踪。

### C. 双面、分支、相干策略和有限体介质

增加反射/透射事件树、路径预算、每次命中重新采样、双面映射和弱吸收体传播。根据源与探测器明确相干/非相干组合，提供均匀平板解析特例。一般强吸收体介质单列为需要额外模型验证的功能。

### D. 系统性能与生产容差闭环

将统一输出面上的复 Jones 场接波动传播；按需求选择标量近轴、矢量或其他传播器，并声明适用域。非偏振源可传播两正交输入场后按强度相加。引入实际沉积误差的层间相关性、测量不确定度和抽样分布，计算系统指标的统计分布；GSMT 的 Zernike/PSD 只是可借鉴参数化，不应替代生产工艺证据。

缓存和 GPU 优化应置于各阶段基准稳定之后。导数、逆设计和工艺优化也必须跨越 mask/相干模式切换等非光滑边界的测试，不能以“底层支持 autodiff”作为全流程可微保证。

## 8. 暂不应写入能力清单的断言

- “局部 R/T/A 已经等于偏振光追”或“Mueller 可以恢复相干衍射相位”。
- “一个总厚度场足以恢复每层误差”。
- “所有厚基片必然非相干”或“非相干基片把偏振相位全部抹掉”。
- “空间变厚度 TMM 自动包含横向散射和表面衍射”。
- “Poke 的几何追迹链完全不依赖商业软件”。
- “Optiland 的非顺序模块已经支持 Jones 薄膜”。
- “公开 GitHub 示例默认继承依赖库许可证”。
- “GSMT II 中非均匀镀膜影响小，所以本项目可以忽略膜厚不均匀”。

这些区分是研究结论中比候选库数量更重要的内容。
