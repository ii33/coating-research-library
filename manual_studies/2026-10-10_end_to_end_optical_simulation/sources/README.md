# 来源目录说明

- `source_register.json` 是从三份原稿中的 Markdown 链接提取的登记表。
- `index.md` 是 104 个唯一链接的可点击目录；`claim_map.md` 将结论 ID 映射到来源 ID、原稿中的章节位置和命题核验状态。
- `evidence_level=U` / `read_status=metadata_only` 描述整合者没有重新访问来源；来源索引逐条指回原稿行/章节，保存作者的直接阅读或官方核验范围自述及逐源访问限制。不得把包级U/metadata-only误写成原作者只查元数据，也不因此把作者声明升级为整合者独立核验。
- `topic_ids` 留空，直到权威库 T01–T11 分类对照表可读后再映射，避免猜编号。
- `sources/originals/` 仅保留目录说明。没有明确合法存档依据的论文/受限全文不会复制进包；保留稳定链接和原创摘要。
- 原稿链接是研究代理提供的定位线索。本包未重新访问其目标，链接有效性仅做语法和重复检查，不声称 HTTP 可达或内容已复核。
