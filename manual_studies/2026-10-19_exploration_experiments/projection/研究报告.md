# 谱响应正交手术：首轮否证试验

日期：2026-10-19。结论：停止把“正交投影后的未归一化线性分数”当成新的候选排序机制。本轮没有证据支持它，也没有观察到有界补偿优于更简单的真实有限编辑预筛的实质收益。保留全部负结果，不接入主软件。

## 1. 需要更正原方案的一句话

令 A=WJ_F，P 为 A 列空间的正交投影。如果活动乘子满足自由坐标的 KKT 条件 Aᵀb=0，则对任意 v，

−bᵀ(I−P)v = −bᵀv。

这里 v 可以是任意大小的真实有限编辑，不限于无穷小插层。因此“改成有限编辑”本身不能解除这个线性分数的退化。约束驻点只投影自由坐标时也一样。内点处即使改求有界 z，使用同一个线性分数评价 v+Az 仍不会得到新信息。

可能改变排序的是不同的评分函数，例如方向余弦、预测/真实最大功率反射，非 KKT 活动法向，以及真正的有界非线性修复。边界处不能把整个 J 的无界线性空间当成双向可行补偿空间。本试验把错误的全 J 投影仅当作诊断反例。

## 2. 物理模型与公平口径

- 法向入射、平面相干、各向同性、无吸收；空气 n₀=1，半无限基底 nₛ=3.42。候选膜材料 n={1.2,1.45,2.35,3.1} 为无色散合成数值，不代表真实材料或可制造工艺。
- 目标为 3–5 μm 全部采样点 R≤0.01。31 个训练点同时作为硬约束；没有另外强加反射相位目标。无吸收时 min T=1−max R。
- 从已精修的单层 n=1.45 出发。内点例厚度域 [0.05,1.2] μm；边界例全部最终候选和修复层的厚度域为 [0.05,0.4] μm。出生厚度目录 {0.05,0.15,0.35,0.7} 经相应边界筛除。相邻同材层合并后检查连续膜厚，不以拆层绕过上限。
- 枚举界面出生、材料替换、删除，以及同材拆分的冗余诊断；合法去重后内点 32 个、边界 23 个。没有宿主内部异材分裂、双编辑、方向去重或高 Q 专项例，不能声称已测试完整假设二。
- 功率计算使用先前已核验的薄膜内核的逐字拷贝。复振幅另用独立标量 Fresnel 递推，统一入射参考面 z=−10 μm、基底界面 z=0。r、通量归一化 t 均补偿移动外表面的传播相位；排序只使用 r 的实部/虚部。W=I。
- 厚度变量 x=d/(0.2 μm)，中心差分 hₓ=10⁻⁵，即物理厚度 2×10⁻⁶ μm；SVD 相对阈值 10⁻¹⁰。边界外的中心差分探针只用于光滑模型导数，不作为可接受膜系。
- 内点活动波长为 3、5 μm，KKT 乘子约为 0.375、0.625。边界例活动波长为 5 μm，自由厚度坐标为空。
- 每个有限编辑都获得相同的最多 160 次实际功率内核调用上限，用 SLSQP epigraph 最小化 t，全部 R_q≤t，保留实际算过的最佳合法厚度。此次全部求解提前正常结束，实际调用次数不同；“同精修上限”不等于“同端到端实际计算量”。
- 每个结果在 2049 点密网格和 2048 个不与训练内点重合的区间中点加端点上复算，使用两者最大值作标签。它仍是有限网格审计，不是连续波段证明或独立全局最优解。

## 3. 真实结果

内点一层最优厚度 d=0.6465517241379303 μm，初始最坏 R=0.1024997977。自由切空间的驻点残差约 4.93×10⁻¹⁷。32 个真实有限编辑中，raw 与 projected 未归一化分数最大差 1.42×10⁻¹⁴，完整排序相同。

边界一层最优为 d=0.4 μm，初始最坏 R=0.2094713289。正确冻结边界后 raw/projected 分数差为 0；错误投影全部 J 的分数最大变化为 35.53。这是非法无界补偿的警示，不是算法优势。 本例采用冻结活动边界后的自由坐标子空间；它不是完整的不等式切锥处理，因为从边界向内移动仍可能可行。所谓正确冻结仅相对于这里选定的子空间检验，不能把受边界影响的所有方向都判成永不可行。

按各评分选前 1 个编辑，再做真实修复后的最坏反射率：

- 内点：raw=0.282066；projected=0.282066；投影余弦=0.282066；直接真实有限编辑 R 预筛=0.01721546；有界补偿预测=0.01721546。
- 边界：raw=0.368794；projected=0.368794；投影余弦=0.07045929；直接真实有限编辑 R 预筛=0.03540324；有界补偿预测=0.03540324。

选前 3 个编辑再修复：内点所有方法约为 0.01721546；边界 raw/projected/余弦约为 0.07045929，真实有限编辑预筛和有界补偿约为 0.03540324。后两者在内点的微小差异不超过 10⁻⁷ 的预定实质差异门槛，不能当成收益。

以上数值是被选编辑的真实标签，尚非完整搜索的最好档案。若保留原最好栈，raw/projected/余弦在内点的前1名会被拒绝，档案仍为0.10249980；边界raw/projected前1名会被拒绝，档案仍为0.20947133。结果另记 archive_best_audited_max_R，不能把变坏的编辑写成已接受结果。

两例的有限目录“逐个同预算局部修复”参照最佳值分别为 0.01721545649、0.03540323578。它是对这批修复结果的最优选择，不是连续厚度/层序的全局最优值。没有任何方法达到目标 R≤0.01。

均匀随机选编辑的精确期望结果（枚举标签分布计算，不是靠少量种子估计）为：内点前 1/3 个修复最优 R 的期望 0.13080724/0.05856012；边界 0.13723768/0.07267926。另保留随机选择种子 11、29、47。精修本身是确定性的，不能把这三个随机选择种子误称为三次独立优化复现。

## 4. 成本与检查

- 原始完整运行约 0.35 秒，环境 Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0；这个微型例的墙钟时间仅供复现，不支持提速外推。
- 完整标签生成、全部修复、两组审计共 1626 次功率内核调用，61 次振幅递推；每阶段调用与耗时完整记录在 results.json。单位/物理 sanity checks 的调用不计入搜索预算，另行报告。
- 前 3 个编辑的实际修复调用：内点 raw/projected=185、余弦=136、直接真实预筛=87、有界补偿=97；边界相应为 96、96、44、44。
- 对应 shortlist 的实际训练点×层等效工作量也逐方法记录；空栈按一个界面等效单元记账，不能把它叫作字面层更新数、FLOP 或相同运行时间。
- 真实功率预筛无需复振幅/J/SVD；成本表没有给它强加这些额外开销。完整共享实验测量与各方法在线重建的调用数分开记录。不声称与随机法或任何基线已严格匹配端到端实际成本。
- 独立振幅对核验功率内核的最大 R/T 差约 7.8×10⁻¹⁶/2.4×10⁻¹⁵；能量守恒误差 1.8×10⁻¹⁵。共同参考面环境层插入不变性、μm/nm 一致性、同材分裂等检查均通过。
- 8 个单测通过，包含逐候选合法性、预算、KKT 分数恒等、边界错误投影、物理检查及确定性重复运行。初次运行曾因 JSON 中的 −∞ 无信息余弦占位值序列化失败，日志保留；已改用明示无信息的有限占位值，所有最终结果可序列化。

## 5. 停止条件与下一步边界

本轮到此停止：线性投影排序的新信息主张已被代数和物理数值例否证；有界补偿没有显示超越简单真实有限编辑预筛的实质效果。不要据此新增主功能，也不要把局部筛选报告改写成端到端搜索成功。

如果以后继续，应先明确一种可被单独否证的新收益来源，例如多层有界修复或剩余方向去重，并与真实有限编辑预筛、随机和双编辑比较；补高 Q、吸收/通量、真实色散、不同尺度/阈值及成本匹配。当前数据不支持优先扩建“正交评分”模块。

## 复现

在本目录执行：

python -B run_projection_experiment.py
python -B -m unittest -v test_projection_experiment.py

verified_power_kernel.py 是先前实验 run_experiment.py 的逐字拷贝，SHA-256 在结果和 MANIFEST.json 中记录。入口脚本仅通过自身目录的相对路径导入，不依赖云端绝对路径。results.json、candidates.csv 与 test_report.txt 保留可追溯数值和测试记录；本研究发布排除临时运行日志，实际文件以 MANIFEST.json 为准。
