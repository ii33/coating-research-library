# 吸收目标的端口边界与失败证据分类

膜系优化可以把吸收率 A 与反射率 R、透射率 T 一起作为目标，但必须先说明**能量统计边界**，不能把不同端口或基片模型的 A 混为一谈。搜索结果的诊断标签也只表示观察到的证据，不自动解释优化失败的原因或证明物理不可行。

## A 的统计区域与厚度导数

在入射端口非吸收、R/T 按同一入射功率归一的前提下，本项目以 `A = 1 − R − T` 表示有限系统的吸收：

- **半无限出口模型**：T 是进入出口半空间的功率通量；A 统计有限膜层，不包含功率进入半无限出口后在其中发生的吸收。
- **有限基片模型**：有限厚度基片及其前、背面膜层属于系统；A 包含有限基片和膜层的吸收。相干与非相干模型的传输计算不同，均须明确入射面、背面和端口。

这一定义依赖端口归一和非吸收入射介质，不应无条件推广到吸收入射半空间；相关复折射率、复角及非相干层细节可参阅 Byrnes 的 [*Multilayer optical calculations*](https://arxiv.org/abs/1603.02720)。该文是背景参考，不意味着它为本项目所有实现和测试结果背书。

对所选有限膜层的物理厚度 `d`，相同条件下平滑物理余量的解析导数为

`∂A/∂d = −∂R/∂d − ∂T/∂d`。

前向结果对绝对值小于 `5×10⁻¹³` 的 A 余量清零，以去除浮点残差；这不是将真实小吸收全部视为零、不是放宽目标的公差，也不对 R/T 做归一化修正。厚度 Jacobian 则对**清零之前的平滑物理余量**求导，不能假定它等于该阈值处被清零函数的导数。在零附近用有限差分检查时，应考虑前向清零带来的数值差异，或在远离阈值处核验。

## 核验与非证明

直接按 `A = 1 − R − T` 构造时，`R + T + A = 1` 主要是代数一致性检查，**不是独立物理正确性证明**。更有说服力的核验需要分别比较光学响应和导数：项目回归在所覆盖的相干情形使用独立特征矩阵参考，在非相干有限基片情形使用独立的有限相位平均；然后比较 R/T 与 A 余量，并用厚度中心有限差分核查解析导数。该有限测试覆盖不能证明所有材料、角度、精度、连续谱或生产工艺均正确，也不是实测材料验证。

## 用证据描述未达标，而不是臆断原因

离线诊断只读取已有结果；它不重新运行搜索或仿真。标签可以重叠、缺失字段保持未知，未出现某标签也不代表反证：

| 观察标签 | 需要的直接证据与边界 |
|---|---|
| 预算停止 | 明确的时间或评价预算停止原因／信号；它可与目标违规或名义通过并存。 |
| 运行异常 | 明确的错误状态、错误字段或看门狗超时；普通取消不自动等于异常。 |
| 原约束违规 | 报告中至少有明确的 `targets_met=false`；缺目标结果或未完成审计本身不自动等于违规。 |
| 材料来源缺失 | 明确的 n、k、材料或同一光学组覆盖缺失等阻断；不凭空补零或推断真实材料性能。 |
| 指标不支持 | 有明确的 unsupported metric 阻断；其他阻断不强行归类。 |
| 审计未完成 | 明确 `audit_complete=false`；空值为未知，独立审核状态另行保留。 |

梯度停滞、结构停滞或局部最优需要适当轨迹和判据；单个进度快照不能证明。预算中断、局部搜索失败、未审计或材料数据缺失，都不能单独推出物理不可行。原目标、角度、波长和指标口径不同的偏差不能任意合并成一个因果结论。单次插桩或局部阶段耗时也不能外推为整个任务的性能改进。
