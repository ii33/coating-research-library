# RI-S04 · Robust Experimental Designs for Model Calibration

原作者讨论非线性模型校准试验的模型形式不确定性和参数不确定性。方法把局部参数设计与估计/发现差异的覆盖点区分，并说明局部最优依赖猜测参数。本包只借此保持两种设计目的，不宣称复现其MaxPro或工业例结果。

原始来源：https://arxiv.org/abs/2008.00547v1
