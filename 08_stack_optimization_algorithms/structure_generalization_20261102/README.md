# 面向泛化的目标条件化膜系结构搜索

日期：2026-11-02。状态：研究设计，尚未实现或验证下述改进。代码基线：coating-sim dev.20261102.07，提交 04b7398619085a03aaed7587bcc964e21db1a4a4。

## 1. 研究问题与边界

根据任意合法输入目标、材料光学数据、基片、角度和偏振，自适应生成、选择和重构膜系拓扑；在相同计算预算下提高完整原始指标的达标机会。研究对象是可重复使用的搜索规则，不是特定样本的最优层序、固定波长的补丁或类别名称查表。

“针对目标进行优化”是逆向设计的必需行为；“把开发样本答案写进算法”不是泛化。算法可以识别宽带高反、窄带阻、腔结构等物理条件，并采用有适用域的先验，但应由连续目标及材料特征触发，不依赖样本 ID、文件名、训练/测试标签或预存答案。材料 ID 只用于读取实际数据，不作为成功答案的检索键。

当前讨论的训练指标是算法开发用任务，不等于已进行神经网络训练。不得称本研究已经证明通用性、全局最优性或任意目标可达。

## 3. 拟研究的方法：原目标残差驱动的结构操作组合

以下为本项目拟议规则，尚无本项目实验验证。

### 3.1 输入表达

以实际波段上的 n(λ)、k(λ)、入射介质/基片数据和原始目标约束为真值。构造波长比、相对带宽、过渡带比、相位折射率对比、材料吸收、角度和偏振等无量纲/有明确单位的特征。不能仅按“高折射材料/低折射材料”二元标签处理所有任务。

建议用规范排序后的完整目标集合计算参考尺度；禁止仅靠用户列表第一项决定全部初始化。目标排列、材料展示名称和无语义 ID 重命名不应改变问题本身。材料候选顺序的确定性需明确设计：在同种子下规范化，或仅承诺并验证统计等价，不能混用二者。

波长及厚度同比缩放只在相应的无色散理想模型下可作为等变测试。真实材料换波段必须重新取 n、k，不能套用缩放保证。

### 3.2 结构提案组合

复用已有物理先验，同时研究通用操作的选择和组合，而不是不断新增特定目标模板：

1. 零厚针插与联合有限厚精修，沿原目标残差改善方向增加自由度。
2. 有限厚跳跃：插入一层或短子堆，在局部梯度失效时探索不同干涉相位。允许探索分支短期更差，已审计冠军独立保留。
3. 局部重构：材料替换、层分裂、连续片段重建、交换或拼接后整体重新优化。不得把两个子堆各自的优点直接相加，耦合必须通过全系统计算确认。
4. 删除、同材合并、厚度压缩与增长交替，避免把持续增厚当作唯一进展。
5. 保留多类初始化与重启；未命中特定物理先验的目标仍有通用提案路径。

所有操作服从用户显式层数/厚度/材料/表面约束与现有格式边界；不会偷偷把资源上限当作“建议”。本轮不设计新的隐藏制造上限。

### 3.3 残差表示与调度

维护原目标逐条件违反情况，保留波长、角度、偏振、点值/均值的语义。均值目标不能转换为每一点都须达标的约束；A 目标不能用 T≈1−R 替代。

候选选择可比较两种独立消融：

- 当前窗口 min/mean/max 签名；
- 带最坏违反位置、分段残差和角度/偏振分组的紧凑签名。

签名只决定探索多样性，绝不替代原目标评分、完整网格与独立审计。比较要控制档案容量与总预算，防止把增加内存或算力误记成算法收益。

操作调度先建立固定轮换对照，再研究根据“该操作最近实际降低原目标违反的收益/消耗”调整预算。保留非零探索份额，避免早期奖励把某类操作永久淘汰。奖励归一化、探索比例和停滞窗口均属项目超参数，只能在开发/内部验证部分选择。

无需先上大型神经网络。若以后训练提案器，其输出仍是候选，不是达标证据；不得把旧测试上的优选调度权重带入所谓新盲测。

### 3.4 统一验收与可恢复性

新候选进入同一条 feasible → resource check → 原目标 evaluate → archive → 独立审计路径。原目标不降级；提案用近似只允许影响搜索方向。

状态应保存操作来源、父体、预算、随机状态、残差摘要和实际进展，区分失败/未评估/预算截断。依赖动态档案的操作不可假装成仅凭静态游标可复建的流；续跑 fingerprint 必须包含新算法语义，不能错误复用旧检查点。

## 4. 泛化验证设计

### 4.1 隔离开发与验收

- 现有训练部分：开发候选规则，并在其中按目标族或材料组做内部留出。
- 反复观察过的旧测试：仅作回归，保持原分组和指标，不再称盲测。
- 新的最终留出：先冻结生成协议、分组、代码和预算，不根据求解结果选容易任务、不移除失败项。首次查看留出结果后，该批次成为已使用测试；继续调参要另设留出。

同一模板的近邻波段、轻微阈值扰动及同源膜系派生目标应放同组，避免近重复泄漏。只扰动中心波长能验证邻域稳定性，不能证明跨任务族泛化。

### 4.2 两类互补任务

1. **有可行见证的合成任务**：独立生成物理合法膜系，再从前向结果导出具有余量的目标范围。见证膜系仅由评估端保存，求解器不可读取、用作种子或调参。检查全部显式工艺限制后，才能称在该模型中有见证。分组应覆盖不同生成结构族，避免只测“反演本算法模板”。
2. **独立工程目标**：直接定义未调参的工程窗口和限制，不预设已有可行解。它补足见证任务的生成器偏差，但求解失败只记未找到，不当作物理不可行。

两类任务分别报告，不混合包装为统一现实生产成功率。

### 4.3 验收维度

分别测未见目标组合/过渡带、材料组合、波段、基片、角度与偏振；只在数据覆盖有效的区域执行。外推、未知 k、材料代用和相干性假设显式登记。跨材料组合成功不等于跨所有材料体系成功。

固定多种随机种子进行配对。先筛选小规模机制实验，最终再对冻结版本扩展多种子；不能以最佳种子或最佳一次代替统计。区间估计按独立目标组处理相关性，不能把同一目标的种子视为独立新任务来夸大样本量。

记录完整原指标达标率、首次达标用时、预算内未达标的最坏违反、层数/总厚度、独立审计结果、未完成/异常/材料不足数。墙钟、逻辑评价、物理前向次数、实际波长×角度×偏振×层工作量分别记录；这些不是可互相直接换算的常数。

比较基线、仅改初始化、仅改重构、仅改档案/调度、最后组合。对时间预算和工作量预算分别做配对实验，严格保留取消后的结果标记，不能算预算内成功。分析整段改善轨迹，不能仅凭最后一张曲线诊断局部最优。

## 5. 执行顺序与停止条件

1. 先验证目标排列/候选顺序与结果的关系，建立纯语义变换的变形测试，并补齐操作级进展证据。
2. 在相同原目标求解与审计链下，一次只改变一种通用提案或选择规则，做开发集内部组间留出消融。
3. 只有收益跨组稳定且未牺牲其它任务族，才组合为候选版；无改善或成本变差则保留负结果，不发布为“泛化提升”。
4. 冻结候选后运行未用于开发的验收。明确哪些维度获得证据、哪些仍未支持。

本轮研究并未修改软件或执行上述新实验。尤其不能把已有 A 目标链路接通、单例成功或资料覆盖数当作结构泛化证据。

## 6. 理论依据与适用限制

- Tikhonravov, Trubetskov, DeBell (1996), [Application of the needle optimization technique to the design of optical coatings](https://doi.org/10.1364/AO.35.005493)：针插是具有物理解释的结构合成手段；采用该方法本身不提供任意目标可达保证。
- Tikhonravov, Trubetskov, DeBell (2007), [Optical coating design approaches based on the needle optimization technique](https://doi.org/10.1364/AO.46.000704)：把总光学厚度、层数与误差共同考虑，并可获得不同设计折中；支持研究多种结构而不是只盯一个标量冠军。
- [OptiLayer 官方 Gradual Evolution](https://optilayer.com/automatic-design-options/gradual-evolution/)：描述针插结束后插入有限厚层，再启动针插的路线，插入时误差可能先变大。这里据此选择研究有限幅结构跳跃，不把产品描述当本软件性能证明。
- Tikhonravov, Trubetskov (2012), [Modern design tools and a new paradigm in optical coating design](https://doi.org/10.1364/AO.51.007319)：强调制造可行性与实用设计，不仅追求最低数值误差。

傅里叶/rugate、腔结构和反射子堆可作为有适用域的初始化研究方向，但从连续折射率映射到离散材料、强反射/吸收/色散、多角度及多子堆耦合都需额外处理，不能作为普适解析解。此处未把它们纳入已经完成的算法。
