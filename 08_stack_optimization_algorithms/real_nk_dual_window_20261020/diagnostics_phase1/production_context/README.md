# 生产吸收背景与显式敏感性（2026-10-20）

用户生产经验：“实际生产时吸收数据总是更低的”。该经验单独记录；样品、厚度、逐谱数据和误差仍待校准。

Querry高k仅作为原来源样品的参考情景，不能作为生产材料必然性能，也不据此否定实际双窗成品可行性。原实验与原k完全保留。

Coherent原始厂家规格在10.6um给出体吸收系数<0.24cm^-1，是可追溯低损耗线索；不是全3–12um色散表。Edmund多光谱ZnS/3–12um BBAR产品提供现实材料背景，不是本项目实测数据。

额外情景仅将1mm基片的k显式乘以1、0.1、0.01、0.001；n与全部薄膜n/k不变。它不满足已验证的KK一致重建，不是实测或拟合，也不替换原目标。见protocol.json及sensitivity.csv。

膜系反射优化与基片损耗适用性应分别报告；实际整片高透设计需要可追溯低损耗块体数据或测得透过谱、厚度及背面状态。
