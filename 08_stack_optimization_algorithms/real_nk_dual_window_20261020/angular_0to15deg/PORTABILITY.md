# 可复算范围与公开证据

从本目录运行`python -B scripts/verify_angular.py --check-inputs-only`，检查处方、原目标、材料CSV和包哈希，不执行光学评价。

完整独立审计：`python -B scripts/verify_angular.py --output <包外的新建或空目录>`。
已有参考环境为Python3.13、NumPy2.5.4、SciPy1.18.1、mpmath1.3.0；不依赖产品软件、网络、私钥或其他本地工程目录。
它重新计算两级不同波长/角度网格、局部极值、全局Maxwell边界与60位高精度交叉检查，并输出JSON、CSV和显示NPZ。
输出必须在整个研究包之外，非空目录拒绝；不会覆盖本包参考证据。

8个科学函数的源文本和AST与原已独立接受的审计完全相同，记录见provenance/portable_derivation.json。
改动仅为相对输入路径、已校验CSV数据加载、显式输出目录和去除机器元数据。原CSV与官方YAML逐值一致性已在原独立验收核实；便携运行只重新核对CSV字节，不伪称重新读取原YAML。

推荐层表、作者11层审计、历史12层处方、独立包络CSV/显示NPZ/极值、搜索设置/改善/结构目录保持原字节。
独立summary仅去除机器标识并替换相对路径，所有数值字段保持不变；HTML仅去标识及调整本地链接。
显示NPZ是抽稀视图，不能当作完整加密网格；完整网格层级、哈希、包络及极值保存在独立摘要和CSV。原作者完整2D数组留在未覆盖的本地288文件v2包；公开副本不包含这些可重生成数组、运行检查点或心跳日志。

发布时仅执行身份检查、代码结构/公式身份、路径/隐私与证据一致性检查，没有新增优化或完整数值审计。
完整搜索依赖未发布核心；本程序仅复算固定11层，不能把其结果宣称为生产软件新增算法。

来源、材料有效域和薄膜/块体边界见../normal_incidence/materials/sources.json。
半无限ZnS功率通量与有限板透射不同，生产材料批次未标定。原正入射A/B与54例诊断不被本新角度目标替代。
