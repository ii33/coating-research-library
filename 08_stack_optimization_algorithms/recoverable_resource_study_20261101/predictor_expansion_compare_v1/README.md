## 固定比较

- 拟合资料：原pilot_v4a的12项模拟任务，加material_expansion_v1预先声明的48项模拟任务。仅有审计见证者产生数值标签，未知不填数值。48项都必须完成并保存，不能按结果筛掉某组或改变目标。
- 留出对照：material_pilot_v1a的全部36项已观察过的文献模型/数据表任务。其32项已知资源用于误差，4未知保持未评分，任何一项均不参与本轮模型拟合。
- 旧模型：前一协议严格源组件第0折，只有原12项模拟任务参与训练。读取原输出摘要绑定的已保存模型，并核验其训练ID，不能用前一全44标签最终模型冒充留出对照。
- 新模型：原208维特征，128棵联合树，深度6、叶至少2例及相同种子，完全不调参。
- 简单对照：新训练集中同族二维log资源坐标的中位数邻近真实样本，沿用同一N/D配对，不拼接两个标签。

除材料变化，新增训练任务也与留出组共享相同目标几何；因此若改善，不能只归因于材料多样性，更不能据此声称未知目标几何已泛化。模拟曲线不是实测材料，局部正n/非负k不等于全频因果或工艺可制造。原文献数据也包含模型表及显式未知k=0假设。
