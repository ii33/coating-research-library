# 快速资源预测原型：速度已验证，严格来源迁移质量未过关

2026-11-01。[冻结算法协议和源码](../predictor_pilot_v1/README.md)。本轮首次完成并实际运行了独立于合成器的联合预测原型；**没有将其接入生产预估，也没有用此结果宣称通用能力。**

## 主要结论

使用208维固定材料/目标特征和128棵联合输出树，在线只读取少量材料采样并遍历树，不调用合成、厚度优化、候选审计或TMM。22项边界测试通过，JSON树推断与离线模型在检查样本上的log输出最大差为0；另有紧邻float32边界的测试，避免阈值被错误舍入。

预热、模型与输入均已在内存时，完整特征提取+推断240次的P50为 **2.96 ms**，P95为 **6.94 ms**，最大 **27.81 ms**。这不包含模型加载、首次导入、文件读取或GUI，不能说界面已达到该延迟，也不代表准确性达标。

## 不能省略的限制

- 没有独立校准集，区间返回null；未测出或宣称90%联合覆盖率。树间分散程度不是已校准区间。
- 组合留一仅37.5%的全部任务落在该折训练特征逐维最小/最大范围内；严格源组件留一为0%。这个简单范围只报警，不是经过验证的适用域判定。
- 数值误差条件于成功找到参考设计的44项；四个未知仍可能使模型对困难任务过于乐观。
- 原文献材料任务全部依赖显式缺失k=0假设；已知吸收保留。源数据零值不是工艺零吸收证明。
- 当前接口拒绝未建模的几何、显式初始膜系、不同参考请求配置和额外工艺约束。它是固定有限流程的研究原型，不是可对任意优化任务直接使用的模型。
- 同一多输出树给出N和D的联合点预测，但并不生成对应可行设计，也不保证预测整数层数下存在该厚度的达标膜系。

## 后续方向

速度不再是当前主要障碍。应在保持线上无搜索的边界下，增加真正独立的材料来源和不同目标几何，预先隔离训练、校准和测试组，再评估联合区间与低估风险；生产替换需要这些质量证据。当前模型的严格源迁移没有超过简单基线，暂不发布为用户可依赖的通用预估器。
