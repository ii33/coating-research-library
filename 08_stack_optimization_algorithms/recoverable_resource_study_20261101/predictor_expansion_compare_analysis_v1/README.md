# 固定快速预测器的训练扩展对照

2026-11-01。[执行协议与代码](../predictor_expansion_compare_v1/README.md)。模型超参数与208维特征不变，在增加模拟训练资料后，对同一组36个文献模型/数据表任务作比较。**文献任务未进入本轮拟合，但其结果在实验设计前已经看过，不能称为盲测。**

## 结果

新增8组曲线 × 6类目标，共48项模拟参考任务，43项找到有条件审计通过的设计，5项保持unknown。拟合使用原12项模拟标签加新增43项，共55项；文献组36项全部留出，其中32项有资源标签参与误差，4项未知不补值、不评分。

| 方法 | 层数MAE（向上取整） | 正厚度MAPE |
|---|---:|---:|
| 原12项模拟训练模型 | 5.53 层 | 73.52% |
| 新55项模拟训练模型 | 1.56 层 | 20.66% |
| 新训练集同族中位数邻近样本基线 | 2.53 层 | 28.13% |

这里比较的是同一32个有标签文献任务，不能直接拿前一报告跨全部44个标签的5.00层/65.65%当本表旧基线。新训练集同时扩大了材料范围和与测试组匹配的目标几何覆盖，因此改善不能单独归因于材料多样性。

## 为什么仍不部署

1. **特征范围覆盖仍不足。** 新模型的36个文献请求全部至少有一维超出训练特征逐维范围；该简单包络通过率为0%。三个基片首窗口n统计特征在36项中均越界，30项的高折射率膜首窗口色散变化/标准差也越界。包络只是诊断，不是可靠适用域，但这些证据不能被平均误差改善掩盖。逐项明细见feature_envelope_diagnostics.json。
2. **仍有偏小的点预测。** 32个可评分任务中，62.5%的新模型预测在N或D至少一项低于选中的参考设计；这是相对参考方案的提示，不是物理最小需求低估的证明。没有校准区间，不能把点预测当作保守预算。
3. **资料与问题有限。** 只有8组新增模拟曲线，非实测、非工艺标定，不保证全频率因果或制造可行。原文献任务也保留缺失k=0条件假设。目标几何固定、角度固定，未验收任意多波段或用户的可见—红外四窗口工程目标。
4. **没有独立校准/新盲测。** 参数未改、训练ID与文献组无交叉，也不等于已经建立通用统计保障。预测目标还是有限参考流程找到的资源，不是全局最小需求。

## 速度与复算

预热且模型/请求已在内存时，完整特征提取与JSON树推断的240次记录：P50 3.07ms、P95 6.51ms、最大18.61ms。不包含导入、模型加载或GUI，测试集合也不同于上一轮，不能把两个P95差异当作加速结论。在线没有合成、候选审计或厚度优化。

比较源码先发布并远端核验，随后只拟合一次，没有为改善该文献组而重选模拟曲线或调整模型。独立只读审阅复算了72条树预测、36条基线、总体/分族指标与计时统计，核对55训练ID及数值光学源不与36留出交叉；没有独立重训，也不是新的物理实验验证。

[六项完整输出归档](../predictor_expansion_compare_v1_checkpoints/outputs-01.tar.gz)包括新模型、三组逐项预测、指标与计时；[逐文件摘要](../predictor_expansion_compare_v1_checkpoints/outputs-01.json)绑定每项字节。verification.json记录源和数据检查点。扩展的原大数据包因连接器大小限制未直接复读，其412个执行文件从两个远端小包恢复并逐项核验，再对43个选中设计分批重审；不混淆对象身份核验和字节恢复。

**本轮结论：固定预测模型在这个已观察、同目标的文献材料留出组上有明显改善，但仍不具备通用上线证据。** 下一步需要覆盖真实基片/色散/吸收范围的独立资料，以及不同目标几何的预先隔离校准与测试。
