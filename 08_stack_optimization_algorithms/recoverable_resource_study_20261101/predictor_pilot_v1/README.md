# 快速层数／总厚度联合预测原型

2026-11-01。研究原型，不修改 coating-sim 软件或当前线上预估器。**在线计算不合成膜系、不做厚度优化、不审计候选。**

## 当前交付与明确边界

输入本研究固定参考流程的完整冻结请求（材料、基片和光学目标）；输出同一个多输出模型的层数及总厚度点预测。模型预测已记录的有限参考流程通常找到的资源规模，不代表全局最小或保证存在对应膜系。`estimated_layers` 为预测浮点层数向上取整，厚度保留物理 nm。相关性由共享树叶联合建模，不取不同候选的最小 N/D 拼接；但预测仍不是实际设计实例。

仅接受已记录参考流程配置：请求字段 max_cycles=4、max_evaluations=300、max_seconds=None、审计倍数32、legacy参考请求、无显式种子/续接；这些是离线样本请求的接口边界，不会在在线路径执行legacy合成。目标原网格固定17点，实际局部拟合与独立审计仍沿用记录的参考流程。基片模式auto、1mm、单前面、出射空气；其他几何或参考策略明确拒绝，不静默忽略。原型适配最多3个 R/T 目标窗口、2–3种候选膜材、每目标最多9个明确角度，单前面、空气入射、无附加工艺资源限制。保持平均/逐点、上下界、严格比较、角度列表、偏振、权重、归一化尺度与允许归一化误差。标签沿用原请求的0.001允许归一化误差，未改成0；其值显式进入特征。

每窗口固定9点读取各材料 n/k，特征包含折射率统计、色散斜率、吸收统计、基片及缺失k假设。保留已知k，完全缺失时仅遵守显式 assume_lossless；严格源采样，不能外推。稀疏特征可能遗漏窄谱行为，不承诺所有复杂目标可预测。候选按光学采样值排序，改变显示名或记录顺序不改特征；不读取case/family/group身份或已知结果。目标和材料身份完整保存在源输入但不作为模型捷径。

## 训练方法

固定128棵 ExtraTrees，最大深度6、叶至少2例、不bootstrap、所有特征可分裂、种子20261101、单线程。双目标为 log1p(N) 与 log1p(D/参考波长)，其中参考波长是各窗口几何中心的几何平均。参数在本次诊断前冻结，不根据交叉验证结果调整。模型导出为普通JSON的树节点数组；在线仅依赖NumPy与固定核心的材料源采样，不需要sklearn训练器，不加载pickle。

研究原型调用形式：先用 `load_model(path, expected_sha256)` 验证文件摘要和全部树图，再调用 `predict(model, frozen_request)`。输入数值先转float32，再提升为Python double与double树阈值比较，与离线sklearn实现一致。未访问分支也在加载时校验。在线不得在预测失败后调用搜索补救。

训练集特征最小/最大范围仅作诊断警告，不是可信适用域判定。当前统一返回 `research_uncalibrated`、`interval=None`；不把树间散布冒称90%预测区间。

## 数据与验证划分

- 使用已持久化的 pilot_v4a 12项和 material_pilot_v1a 36项，共48项；44有审计见证，4项未知不构造资源标签，不以假高层数替代。
- 不重复计入同任务的pilot_v3。输入、结果、见证引用与摘要在dataset_inventory.json中保存，复算从相邻已发布实验目录读取。
- 8组按组合/合成组留一，仅为组合迁移诊断。文献组合共享膜材或基片，不能称独立材料源泛化。
- 把膜材和基片光学源的共享关系连成组件，只有36/6/6三个组件。再做严格组件留一，揭示不同来源域间迁移难度；三个组件也不足以代表总体分布。
- 参考流程共享主要预算，但两套数据的随机种子策略和条件性材料假设不同，不能称完全一致的实验分布。已观察过这些任务结果，本次属于诊断交叉验证，不是事先封存的盲测。
- 对照基线为训练折同任务族的联合log资源medoid，取同一标签的N与归一化D，不从测试集读取数值。基线使用既有任务族标签，预测器本身不用该标签。

报告整数/浮点层数MAE、正厚度MAPE、任一资源低估率、标签可评估比例、各任务族和数据集误差；不只报告平均分。四项未知始终列出，误差只能解释为已找到参考设计条件下的误差。

## 区间与速度

目前没有单独封存的独立校准集，因此不输出校准区间或覆盖率。后续校准必须以材料组/任务组为单位避免共享源泄漏，适用性和交换性假设另验；不能把现有交叉验证残差自动包装成可信区间。

速度测量为模型已加载、冻结请求已在内存，预热48次后连续240次的完整特征提取+JSON树推断，报告P50/P95/最大值；不包含GUI、首次导入、文件加载，也不能声称是完整界面延迟。指标即使满足速度目标，也不代表预测质量达标。

## 方法依据

[scikit-learn 1.8 ExtraTreesRegressor](https://scikit-learn.org/1.8/modules/generated/sklearn.ensemble.ExtraTreesRegressor.html) 提供树集成、多输出及参数定义；本项目选择的树规模和光学特征是研究约定，非文献对本问题的有效性保证。

[Angelopoulos 与 Bates：Conformal Prediction 入门](https://arxiv.org/abs/2107.07511) 说明预测集校准与分布假设的关系。本轮没有独立校准资料，不借用其理论宣称覆盖率，也不把点预测的不确定性省略成“准确”。
