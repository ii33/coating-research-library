# 八组模拟材料扩展：同目标材料迁移诊断

2026-11-01。此阶段为快速预测器补充8组不同的数值光学曲线，每组6类可见目标，共48项离线参考任务。**不是8种经过实测或工艺标定的新材料，也不是新的盲测集。** 原文献材料36项的结果已经被观察过，后续将留作不参与拟合的同任务材料迁移对照，不能再称未知盲测。

## 目的与预先约定

前一原型严格来源分组误差较大。此实验仅检查：在模型超参数和线上特征保持不变时，增加覆盖不同 n/k 和基片的训练参考样本，能否改善原来文献材料组的预测。不得把原文献组标签混入此迁移比较的训练集，也不得根据其结果调参或重选模拟组。8组随机实现不保证覆盖参数范围的每个端点，实际覆盖范围须随结果报告；不得因误差预期重新抽取。不是训练后自动上线，尚不承诺精度或区间覆盖。

组ID为sim_51000至sim_51007；每组的材料生成种子为20261101+137×组号，同一组的六任务共享同一光学表，不重复计为六个独立材料来源。随机数来自固定环境的NumPy Generator。

## 模拟材料的定义及限制

- 波段400–800 nm，201个均匀节点，n(λ)=n550+B×[(550/λ)²−1]。
- 低折射率 n550 均匀取1.35–1.60，B取0.001–0.025；高折射率 n550 取1.90–2.70，B取0.003–0.05；基片 n550 取1.45–2.50，B取0.001–0.012。
- 膜材 k 基础值按对数均匀取1e-6–0.015，乘以(λ/550)^p，p取−1至1；25%概率将基础曲线设为0。另有30%概率加非负高斯峰，其中心450–750 nm、宽度20–120 nm、幅度对数均匀1e-5–0.01。准确随机抽样顺序见tasks.py。
- 基片 k 不给出；组号能被5整除时低折射率膜的 k 也不给出。本轮输入显式assume_lossless=True，仅对完全缺失的k假设0；其他已知模拟k完整保留。缺失k时生成过程里的潜在随机参数不作为物理真值使用，计算仅遵守冻结表和明确的零假设。
- n/k分别参数化，只保证有限表内正n、非负已知k与严格采样域，不证明全频率因果色散一致或工艺可制造。不同曲线共享同一生成框架，不等于不同实验室的独立测量。

## 原始目标与固定参考流程

全部为单前面、空气入射、auto模式1mm基片、出射空气，0°和30°、非偏振。所有比较含等号，平均/逐点分开：

| 族 | 目标（nm，R/T为小数） |
|---|---|
| ar | 450–700，逐点R≤0.015 |
| hr | 500–650，逐点R≥0.95 |
| mixed | 420–500逐点R≥0.90；650–780逐点T≥0.90 |
| bandpass | 420–480逐点R≥0.85；550–620逐点T≥0.85；700–780逐点R≥0.85 |
| dual_ar | 420–500及650–780，逐点R≤0.02 |
| mean_mix | 420–500平均R≥0.90；650–780平均T≥0.92 |

复用已发布material_pilot_v1a的完整参考算法，固定物理核心131d3fc989c3dc9ac8d94fee3c39541a61b851df用于数据可比性；不改动或向生产软件回灌该核心。普通起点0/2/4/8/12/16/24/32层、每档3起点；带通使用不超过8个未评分原生结构起点。41点局部拟合、每起点60次评价、45秒协作式任务预算、32倍独立原条件审计。各族共享20261101+族索引的修复种子。预算、初始层数和[1e-7,2]参考波长层厚区间均是数值努力，不是需求下界或工艺规定。

局部端点完成后仍按原规则停止/减量；通过见证立即保存，成对N/D选择权重不变。未找到见证保持unknown，不转成最大资源标签、不证明不可行。已知误差阈值、目标与采样不能为获得更多标签而修改。
