输入与输出

输入完整单前面设计环境、已知复折射率 n+ik、原始 R/T 约束及角度/偏振。波长/物理厚度单位为 nm，角度为度；设计层序为基片向外，前向计算前反转为入射向基片。输出为原请求数值审计通过的完整候选、成对 N/D 资源以及有限搜索状态；未知不等于不可行。

图：候选通过审计后立即保存，不等当前优化轮正常返回；因此预算终止仍保留已经落盘的通过见证。

数值方法

λ_ref=exp(mean(log(sqrt(λ_min λ_max))))。以 x=d/λ_ref、w=λ/λ_ref 调用固定核心 TMM，折射率仍按实际 λ 从完整数据源采样；解析梯度对 x 求导。均值和逐点目标保留为独立核心约束，未把平均要求改成逐点要求。局部训练网格41点，原始请求17点，审计倍数32；审计均值沿用核心固定加密网格定义，不是连续积分证明。

周期/啁啾种子使用实部折射率的近似四分之一波厚度 d≈λ/[4 sqrt(n²−sin²θ)]。混合目标的匹配帽层以透射窗口几何中心初始化；额外固定种子在候选池中选择不相邻重复的材料，并施加0.6–1.4厚度扰动。此初始化忽略吸收和精确边界相位，仅提供起点；计算、拟合、验收始终保留已知 k，不将种子公式当作达标或下界证明。

内部局部修复把下界提高0.03(1−lower)，上界乘0.97，以留出余量；原目标和最终审计不改变。SciPy least_squares 使用解析残差梯度，max_nfev=60、ftol/xtol/gtol=1e-9，x边界[1e-7,2]。N档位为0、2、4、8、12、16、24、32，三起点；每案例45秒协作式预算（不是可抢占的硬墙钟上限；输入准备、单次调用和落盘可能超出），裸基片通过可结束，否则最多两个通过N档后减层两轮，每轮两项最薄光学层删除/相同相邻材料合并提案。

成对选点：S=log(1+N)+log(1+D/λ_ref)，同分以N、D、哈希排序。此权重是本项目约定，不是Pareto全局最优。不同的离线预算或起点可得到不同见证；误差标签应理解为所声明参考流程下的设计资源，不是真实最少需求。

恢复与环境边界

源清单包含计划但不包含其自身；由操作者发布并复读 plan 与源清单摘要，离线入口核验本地字节，不能独立证明远端 commit 关联。运行前核对无私人路径的 Python、NumPy、SciPy、OS/架构、BLAS 版本和线程摘要。即使同硬件和版本，相同墙钟预算也不保证优化轨迹或 bitwise 输出相同。已完成结果恢复必须核验所有见证、成对资源、无见证标签并重算固定选点；即时落盘是本地持久性，不等于远端备份。

实现与校验

tasks.py 生成合成输入；reference.py 实现上述离线流程；run_pilot.py 保存协议并控制准入；artifact_store.py 原子不可变保存。参考种子与波段变换来自项目实验约定，未找到外部依据，不能暗示通用有效性。单元测试核对输入确定性/语义、材料组、成对资源、层序及 s/p 吸收条件下解析梯度对有限差分。

来源与限制

光学与原始目标验收使用固定发布核心；局部优化接口为SciPy least_squares。这里只保存明确实现依据，不声称外部来源验证了本项目种子、预算或预测准确性。暂不支持多面/非空气入射或额外逐层工艺限制的此参考流程；2个合成组不能代表材料库或实际四窗口工程域。

v4a：带通未评分起点对照

在同12任务上，只对两个R/T/R任务调用固定核心的多子堆与耦合腔构造，每族最多读取256项，每层数首项再取最多4个均匀层数索引，合计去重后不超过8个。完整起点冻结在输入中，未光学评分、未预先标为通过。裸基片之后按起点实际层数升序修复，最多两个 repair 终点审计返回通过的 N 档后进入原减层阶段；其他十个任务的原初始化不变。局部修复和审计目标不改，构造副本的32层/单层2λ_ref仅为生成努力边界。构造预处理不计入45秒协作修复预算，不能将两策略称为严格等总时间。

两个原生入口为多子堆构造和耦合腔构造，都不保证通过。native_seeds.py只做有界构造和确定性取样；reference.py继续按原目标修复并即时存储审计见证。此为训练任务的初始化诊断，不是新的独立材料组、连续证书或最小资源证明。

停止计数澄清：初始起点通过的见证立即保存并保留；若其优化终点未通过，此 N 档不计入两个终点通过档的停止条件。这是 v3/v4 共有流程，本修订仅更正文案，不改变搜索或见证选择。
