# 从训练任务提炼可适应指标变化的预置结构族

2026-11-02；研究目录与准入规范，不是本轮新增的软件功能或已验证性能库。

本页承接 [目标条件化结构搜索研究](../structure_generalization_20261102/README.md)。研究产物不仅包括搜索操作，也包括多种能随实际指标和材料变化的参数化结构族。预置的是构造规则及适用域，不是训练样本的层厚答案。

## 1. 结构族清单

| 结构族 | 提案的可变参数 | 与现有代码的关系 | 适用性与研究边界 |
|---|---|---|---|
| 导纳匹配与分簇减反 | 参考尺度、簇数、各簇光学厚度、材料角色、端部/埋层比例 | 复用经典 AR、matching、ar_cluster | 按低反/高透实际要求评估；均值与逐点条件不能混同；高透不等价于低反，吸收须一起算 |
| 周期、啁啾及分段高反 | 对数、局部中心波长、啁啾方向/规律、子堆分配、端部匹配 | 复用 periodic、chirped、dual_substack_hr、multispectral_hr | 不能把每段各自反射率直接相加；全系统耦合、色散、角度和偏振需验收 |
| 窄阻带与多阻带 | 各带中心、相对带宽、单元光学占空比、周期数、相位、子堆排列、匹配段 | 复用现有 narrow_rejection；独立 digital_rugate 可作为候选研究路线 | 既有窄拒带先验有法向及窗口包围资格条件；没有生成候选不等于物理不可行；rugate 离散化需真实材料而非任意中间折射率 |
| 单腔与耦合多腔带通 | 腔数/阶次、外镜强度、耦合镜对数、腔间差异、端部匹配 | 复用 FP、coupled_cavity | 从完整通带/阻带关系识别；只给 T 下界不足以证明窄带选择性；允许研究非对称变体而非固定对称答案 |
| 短波通/长波通边缘 | 截止方向、边缘位置、阻带跨度、子堆中心、过渡匹配、非 QW 扰动 | 现有反射/多子堆可给候选；专门边缘构造规则尚待验证 | 不将边缘跨度和有限模板误记为陡度保证；方向变化和多角度边移要独立检查 |
| 多窗口透反复合 | 窗口组合、子堆数量/顺序、连接层相位、各段厚度预算 | 复用 multistack、composite 和多谱提案 | 不是为窗口编号保存固定堆；不忽略未分配给某子堆的其它原始条件 |
| 部分反射/分光 | 反射目标比例、材料角色、非 QW 厚度比例、层数、匹配端 | 基础层/反射结构可用；专门分光提案属于待研究项 | 偏振不敏感分光需显式约束各偏振通道或其差异；若输入仅规定非偏振平均，则只按原平均口径验收，不能宣称已验证偏振不敏感；偏振分束须各通道实际要求 |

每族可以有数个明确不同的机制变体，不要求压成一个万能结构。反过来，参数略变但机制相同的模板不应膨胀为很多重复预置。

## 2. 横跨结构族的条件，不另冒充新结构

- **低吸收预算**：选择符合原始 n/k 数据的材料和场分布、优化厚度，同时检查 T/R/A。A 上限并不意味着需要增加吸收层；不能把低损耗任务总结成金属吸收器结构。
- **角度、偏振和基片**：是真实物理环境与验收条件，不能通过复制一份模板名称就声称“宽角”“非偏振”或“任意基片”。
- **工艺限制**：原始最薄层、总厚、层数和材料限制必须落实到实际生成/优化/最终验收；商品名称中出现“低层数”不等于存在可执行约束。
- **双面**：两面的结构可有不同参数，但最后必须使用同一个完整有限/半无限基片物理模型计算，不能拼接两个单面成功结论。

未来若出现真正的 A 下界吸收任务，可另研究金属—介质—金属共振腔等族。光学 Salisbury 结构的公开实验是其机制依据，而不是现有低吸收训练任务的验证依据。薄金属连续性及厚度相关光学数据需要特别检查。[Nath 等，2014](https://doi.org/10.1063/1.4876117)

## 3. 每个预置必须保存的内容

1. 稳定结构族 ID、用户可读名称、理论机制、来源和实现版本。
2. 可接受的原始指标语义；选用规则只读物理目标/材料，不读样本名称、编号或划分。
3. 参数表：单位、连续/离散类型、如何由目标初始化、允许扰动方向；区分用户硬限制和搜索启发值。
4. 材料角色按实际色散/吸收绑定；跨波段排序变化、数据缺失、非法相位时明确拒绝或改用其它候选，不静默补零或外推。
5. 输出完整真实膜系、构造参数和来源；随后统一局部/全局优化及原目标审计。
6. 适用域、失败条件和证据等级；测试覆盖的参数范围不可直接写成物理保证范围。
7. 预算消耗与去重身份；多个族生成同一物理结构时复用去重，不让重复模板耗尽预算。
8. 可复现随机状态与续跑语义；动态候选依赖的状态不能仅靠静态模板序号恢复。

保留三种状态：**研究候选**、**已验证构造器**、**在声明范围内完成光学验证**。构造合法、参数随目标变化、优化后达标是三个不同层次。只有构造器证据时不能标记为已完成光学验证。

## 4. 从训练结果中提炼，而非记答案

先按实际指标形状归组，检查同族不同任务是否复现相同结构机制。仅训练样本成功一次，不能推断机制是必要的或唯一的；还应比较其它结构族及没有该预置的基线。

归纳时保留无量纲参数和真实材料相位关系；换波长必须重算实际 n/k。只在无色散理想模型中测试精确同比缩放，不将其当作实际材料通用规律。

先验的参数化关系应能解释新输入如何改变输出。若必须读取训练样本 ID 才能选取层数、厚度或次序，该规则不允许进入预置库。允许在开发任务上学习统一参数，但须冻结并通过独立留出，不得每个样本一套配置。

少量前向已知结构派生的目标可用于构造与机制测试，完整工程目标用于实用效果测试；见证解必须对求解器隔离。近邻目标扰动属于局部稳定性测试，跨材料、波段和目标组合留出才提供更强迁移证据。

## 5. 指标变化验证矩阵

每个结构族至少规划下列变化，适用时执行，不适用时记录原因：

- 中心波长移动，保持/改变绝对与相对带宽分别测试；
- 通/阻带宽度、过渡带和目标深度改变；
- 窗口数量、排序和透反角色组合变化；
- 材料组合、基片、入射角与 s/p 条件变化；
- 总厚、层数和最薄层限制变化；
- 目标行/材料候选排列等不改变物理问题的变形测试。

对照包括：无该预置、原有预置、改进预置；使用同一原目标评分、同一预算与独立审计。记录各族适用率、生成候选率、预算内达标率、首次达标成本、最终资源及失败原因。禁止只报告“选中了多少次”或“能生成多少条”作为性能改善。

启发式地把 T 上限转换为反射提案时，要保留 `acceptance_equivalence=False` 的语义；这只是获得可能的反射型种子，绝不替换吸收系统的原始约束。
