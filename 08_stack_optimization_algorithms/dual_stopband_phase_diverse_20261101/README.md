# 深阻带的色散相位先验、逐层重启与采样差距修复

**一次无种子、无检查点的直接核心研究运行，在原已知膜 k 模型上名义有限采样达标。** v5 候选 67 层、4508.289506 nm、最薄 3.944477 nm，3705 次评估后自然完成；训练、任务验证与独立复审最大违例均为 0。它是单次受控数值结果，不是 GUI AUTO 或安装器端到端验收，也不是制造、容差或连续波段保证。两个阻带最窄采样余量仅 0.0000013 透射率（0.000130 个百分点）。

## 研究动机与边界

周期层对数的近似不能充分描述有限膜栈边界、跨窗耦合及色散高阶通带阻碍。这里把多相位结构作为**起点提案**，再使用实际复数 n/k 和原目标评分及独立审计；结构启发式不是通过证据、层数下界、连续谱证明或收敛保证。此前[65 层已知 k 名义见证](../dual_stopband_known_k_nominal_20261101/README.md)来自单独的实验性暖启动、最薄层约 0.0714 nm，不能作为默认无种子流程通过或可制造性的证据。

## 结构构造：先拓宽相位，再探邻接对数

对满足准入的法向透射/反射任务，以阻带中心 λ₀ 的真实 n 将两种膜材区分为 H、L，二元单元厚度设 `dH = λ₀ f/(2nH(λ₀))`、`dL = λ₀(1−f)/(2nL(λ₀))`。已有窄带占空比可尝试互补相位；四分之一波情形还依据通带端点和中点的色散相位，生成有限谐波相位备选。每窗以 `k(λ)/λ` 构造简化吸收排序代理、保留有限备选和原始相位，候选仍须遵守原有显式层数和厚度约束；代理不建模实际场强，因此不是吸收上界或可行性筛选。

对固定材料对、占空比系数、层对数系数、窗顺序和目标反射深度，先枚举各相位组合的名义层对数，再依次尝试单窗口 N−1、N+1，避免邻数过早占用有限筛选前缀。近似周期数仅供构造；匹配帽、窗顺序及名义数邻域都是有限搜索约定，不证明任意候选可行或能覆盖所有组合。原 n/k、目标与已知吸收不因先验调整。

## until 模式：局部片与独审差距

本次策略仅在 `search_until_target` 场景添加有界额外探索：每轮选取一个已评分先验候选进行原目标局部精修；若有匹配的已审计冠军，则以原设计为父设计对所选层分别作 `d′ᵢ = dᵢ exp(δᵢ)` 的独立扰动，`δᵢ∼N(0,σ²)`，σ 随轮次在 0.03、0.08、0.18 中循环。重启种子绑定策略、结构搜索种子、轮次及父膜系的物理哈希；原约束与共享预算、资源守卫和取消边界仍生效。局部优化每个 120 次迭代片段若因迭代上限停止且仍有实质改善，可在父级时间片内继续；单次迭代耗尽不是收敛或全局最优证明。

完成局部会话后，若已有匹配训练分数与独立审计分数的当前冠军，且 `E_audit > E_train + max(10⁻⁸, 10⁻⁶ |E_train|)`，仅直到目标模式可用既有局部反馈修复：共享最多 64 次逻辑评价、最多 3 轮、原变量初值 ±5 nm 与原约束交集，补充失败波长并复审。此条件仅观察到采样评分差距，不证明原因或可修复。额外审计条件不改变原训练网格、均值积分或名义验收；实际预算耗尽、局部失败、取消均不证明不可行。成功必须保留原目标并通过相应原评分及独立审计。

## 公开复现实验协议

实际材料模型为公开 Franta TiO₂、Rodríguez SiO₂、H-K9L 及空气；膜材已知 k 保留，未知基片 k=0 明示。四个包含端点的逐点透射窗口为 400–500 nm ≥0.8、510–550 nm ≤0.0065、560–700 nm ≥0.8、1040–1080 nm ≤0.0065；0° 非偏振，基础网格 1 nm、3 mm 双面基片但只优化前表面。公开工具从仓库公开 catalog 构造空膜层问题，不读取用户导出，不提供 seed/检查点；不预装候选答案。工具会运行耗时搜索，可能一直运行；可按文档提供外部协作取消文件。[正式 .12 源码提交](https://github.com/ii33/coating-sim/commit/4b591fe63b2b665bbcc9dd292b3fd7ba0b001651)提供如下公开案例入口。此入口是独立公开问题定义，不承诺字节级重建私有请求、运行轨迹或相同结果；示例命令：
