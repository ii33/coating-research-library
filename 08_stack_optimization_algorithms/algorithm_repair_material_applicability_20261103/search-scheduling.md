# 膜系合成：局部会话交接与材料对调度

日期：2026-11-03。本文记录候选实现的设计和边界；不是软件发布公告，也不是全局最优、可行性或成功率保证。两项调度均为本项目约定，目标、物理模型和独立验收门槛不因此放宽。

## 1. 局部会话与外层搜索

固定拓扑上的局部优化只是整体结构搜索的一次尝试。局部求解器返回迭代上限或失败，并不能推论其他拓扑、材料对或参数区域不可行，也不能证明当前点收敛或驻点。改进是区分“本次局部求解停止”和“全局搜索终止”。

在启用持续搜索的路径，若已有终点回调证据，且局部会话的迭代上限或求解失败不属于既有的同拓扑继续或停滞分支，则保留真实局部停止状态；将终点以及与其不同的返回候选按原流程独立审计。只有完成必要审计且尚未达标时，才把控制交回外层探索其他结构。审计的训练与验证数据、原始条件和验收阈值保持不变；候选必须与自己的审计结果对应。正式达标、审计拒绝和资源边界仍按原契约处理。

未启用持续搜索时保留原停止行为。没有终点证据、用户取消、资源保护、外层预算耗尽或其他不可恢复停止，不以此机制继续。它不等于忽略求解失败，不证明可行解存在，也不保证无限运行。对局部会话、终点审计、预算和取消边界应分别做契约测试。

## 2. 材料对与周期数的公平调度

反射结构候选先保留既有拒带先验前缀；随后对可用材料的无序两两组合建立独立候选流，逐流轮转。每对先遍历估计的周期数及符合显式层数限制的周期结构和两种端序，再进入该对原有的多堆叠与啁啾变体。一个材料对的周期前缀耗尽后可先进入它自己的其他变体，因此这不是“所有材料对完成同一阶段后才进入下一阶段”的全局屏障。

这是**候选生成顺序**而非材料优劣判定；吸收、原目标、材料覆盖、制造约束和独立审计仍由完整物理计算与既有契约处理。预算有限、材料不适用、提前停止或拒绝前缀消耗资源时，不保证访问每一对或每个周期数。设计意图是不人为删去原有有效变体；实现仍需以受约束的候选集合、边界、关闭和取消测试验证。

续算游标与候选顺序绑定。混合搜索的指纹应包含明确的材料对调度策略标识，策略改变时拒绝旧游标静默复用，避免同一位置被误解释为另一候选。若其他候选流策略也改变，也需纳入其对应策略标识。指纹不替代内容、物理或审计校验。

## 3. 验证与声明

定向测试可以验证局部终点独审与交接、取消和预算边界、材料对轮转、周期数前缀、候选约束和旧续算状态拒绝等行为；它不能单独证明所有任务的求解质量或成功率提升。应在相同输入、材料数据、资源预算和验收协议下进行配对评估，并报告未完成、缺失和失败，独立验证候选的原始约束。有限采样不能证明全局不可行。

上述具体调度、停止和续算规则是本项目约定，未找到直接验证该调度效果的外部依据；不将其归因于其他论文。
