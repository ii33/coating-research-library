# 统一减层参考：192 个训练任务与配对交叉验证

日期：2026-10-31。**研究记录，不是生产交付、实际任务验证或独立盲测。** 本记录扩展[原 48 项统一减层研究](../README.md)，不替换原结果、原始档案、既有失败研究或生产模型。192 项是累计数，包含原有 48 项，而非新增 192 项。另一项两尺度种子单案例不计入此统计。

## 问题与统一协议

参考标签是有限求解预算下找到并审计的可行设计，不是真实最小需求。参考设计偏大可能影响资源预测，因此本试验考察在不放宽原目标时，统一的局部减层修复能否得到更紧的见证。

按编号覆盖 32 个合成训练材料组、每组六类目标任务，共 192 项，未按预测误差筛选。对已有见证，每轮从最薄光学层提出两个删除／合并候选并按原目标修复，最多四轮，每案例修复预算 60 秒；从存档中以固定平衡规则选择资源对。选择后的设计对原请求及材料源重新进行数值审计。并非每个案例都执行满四轮。未知表示未取得见证，不表示不可行；原档案和原训练标签不被覆盖。

| 全部 192 项的选中结果 | 数量 |
|---|---:|
| 按原请求重审通过的有见证案例 | 158 |
| 未知、无见证 | 34 |
| 其中选中见证层数减少 | 112 |
| 　层数与物理总厚度均减少 | 79 |
| 　层数减少、厚度未减少（权衡） | 33 |
| 　资源对不变 | 46 |

分类基数是 158 个有见证案例；79 + 33 + 46 = 158。重审通过是有限数值采样证据，不是连续波段证明或实验认证；找到更小的见证不证明全局最少层数或最薄厚度，未改进也不证明不存在更优解。**16 项触及声明的 60 秒预算**：原见证和已完成求解轮的结果保留，但当前 `solve` 在中途被停止时不会返回正在执行轮的部分候选，甚至可能丢失该轮已审计候选；因此不能说每个已发现候选都被保留。

[逐案例索引](case-index.csv) 给出原和选中 N、物理总厚度 D（nm）、运行状态、结果分类、原请求重审标志、选中设计物理哈希及输入文件哈希。空值代表未知而非零。`pass` 表示存储的重审记录同时具有 audited、targets_met、solver_acceptable 和 within_constraints；不代表连续证书。

## 配对训练组交叉验证

在同一 158 个有见证的基础任务上，固定特征、相同的 8 折原材料组划分（组号 modulo 8）与 ExtraTrees 配置，对原参考标签和统一修复后标签分别训练、预测并评价。N 和 D 来自同一选中见证；D 以参考波长归一化并对数变换进行训练。使用训练折组加权标准化；每折四个材料组；未混入未经对应统一修复的增强变体。34 个未知案例不参与评分。[协议](paired-cv-protocol.json) · [逐案例配对预测记录](paired-cv-records.csv)。

| 标签口径 | 样本 | N MAE（层） | 正 D 的 MAPE |
|---|---:|---:|---:|
| 原参考 | 158 | 4.5823 | 29.2120% |
| 统一修复后参考 | 158 | 3.8797 | 26.4167% |

这两组评价使用**不同目标标签**；总体数字下降只说明对各自标签的训练组交叉验证误差变化，**不能保证相对于真实最小需求的误差改善**。细分族群并非都改善，例如 bandpass 的 N MAE 从 5.8333 变为 5.9583 层；dual_ar 的 D MAPE 从 49.8520% 变为 52.1027%。两组总体仍均未通过既定 N MAE ≤3 层、正 D MAPE ≤25% 的工程门槛。它们不是独立盲测、校准、区间联合覆盖或对任意材料和目标的泛化证明。

训练数据仅有这 32 个合成材料组；没有运行实际四窗口任务、独立校准集或测试集。核查发现训练目标的精确波段—指标对均不同于四个实际留出目标的精确对，但这一精确匹配检查不能排除所有邻近任务泄漏。

## 输出表示的训练内比较

在同一 158 项修复后标签、固定特征与 8 折材料组划分上，比较联合预测 N / log D 的对照，与独立 N 和 log D 两头，以及联合预测 N / log(D/N) 的每层厚度表示。配置保持 ExtraTrees（200 棵树、叶节点最少 2 项、max_features=0.5）；均为训练组交叉验证。

| 输出表示 | N MAE（层） | 正 D 的 MAPE |
|---|---:|---:|
| 联合 N、log D（对照） | 3.8797 | 26.4167% |
| 独立 N 和 log D 两头 | 3.7025 | 26.1761% |
| 联合 N、log(D/N) | 4.3418 | 36.6357% |

独立两头在这个训练内比较中略低，但两项总体误差仍未通过既定 3 层和 25% 门槛；每层表示在该样本中更差。该探索不是独立验证，不能挑选最佳结果替换既有研究或视为生产性能。下一步应增加独立训练材料组并开展预留校准和盲测，而不是只更换输出公式；这些结果不证明数据量是唯一瓶颈，也不保证增加数据即可达标。

## 证据核对与限制

[独立只读数据契约复核](independent-contract-review.json) 重新计算文件和物理设计哈希、资源对、平衡选点、分折和已记录 CV 指标：192 项身份和输入哈希一致；467 个已存见证的设计哈希、N/D 和已存审计标志一致；158 个选中点与原请求重审记录的哈希和资源对一致，未发现所查契约错误。**复核没有重新运行优化、模型拟合或物理审计**；物理结论依赖已有数值审计记录。这份索引与哈希用于追踪已存证据，本目录本身不包含完整逐层设计、材料输入和求解环境，不能独立重做完整光学实验。

依赖导入快照是在运行开始后补录，不是预先冻结的完整环境证明，动态导入可能遗漏；192 项编码等价证据只报告匹配计数，未逐案例列出对比。CV 执行来源记录亦为补录，并不构成预注册。所有指标保留原口径；不能把本试验与既有 416 行增强数据的交叉验证指标当作同一实验比较。
