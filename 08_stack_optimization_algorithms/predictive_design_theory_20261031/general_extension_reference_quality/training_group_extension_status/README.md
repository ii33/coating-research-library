## 48 组：固定旧锚点比较

在同一 158 项旧有见证案例、相同特征、修复后参考标签及原材料组 8 折划分下，比较 32 组与 48 组训练池。每折从旧池使用 24 个训练组，扩展池则使用相同 24 个旧组加 14 个新组，均排除该折组；ExtraTrees 配置相同。表中 log D 简称对应无量纲 d = D/λ_ref 后的 log(d + 0.01)，而不是对纳米厚度直接取对数。旧特征此前核对为逐元素相同，32 组两种模型的旧案例预测逐案重现。

| 输出表示 | 训练组池 | 锚点案例 | N MAE（层） | 正 D MAPE |
|---|---:|---:|---:|---:|
| 联合 N / log D | 32 | 158 | 3.8797 | 26.4167% |
| 联合 N / log D | 48 | 158 | 3.6013 | 24.4982% |
| 独立 N 和 log D 两头 | 32 | 158 | 3.7025 | 26.1761% |
| 独立 N 和 log D 两头 | 48 | 158 | 3.4873 | 24.3753% |

在这一固定旧锚点的训练组 CV 中，两种表示的总体误差均下降；但 48 组的 N MAE 仍高于原定 3 层门槛，因此不能称为整体通过。这里的参考值是有限数值审计见证，而非真实最小需求；结果不能保证真实最小值预测误差下降，也未验证区间覆盖或跨真实材料的泛化。

独立两头在全部 234 个有见证案例上的 N MAE 为 3.4274 层、正 D MAPE 为 23.6173%。该评价集较旧锚点增加了案例，不能把其总体变化当作纯粹的学习收益。类别差异仍明显：AR 的 D MAPE 为 46.4400%，dual AR 为 51.9396%，总体均值不能掩盖这些误差。
