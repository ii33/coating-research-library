# 通用扩展：参考标签质量与训练组交叉验证

日期：2026-10-31。**研究记录，不是生产交付或独立盲测。** 生产版本仍为 dev.20261031.06，未替换模型；新研究的校准、测试及实际任务尚未运行。先前通用扩展首轮失败结果保持不变。

## 参考见证质量：同一合成任务的改进

在一个**合成的双窗口均值任务**上，而非用户实际四窗口任务，原参考见证为 48 层、7180.956292 nm；新见证为 24 层、5067.354468 nm，层数和物理总厚度均更小。原约束为 s 偏振、39.8473388°，631.597–972.712 nm 窗口的 R 均值严格大于 0.9619543424，2094.108–3848.820 nm 窗口的 T 均值严格大于 0.9892575914。

过程先以两尺度匹配 cap 构造先验，并按原目标局部修复，再进行删除、合并、重新修复和审计；没有放宽原目标。新设计已按原请求再次独立数值审计，均值分别为 R=0.9628634122、T=0.9895864720，均通过原严格阈值。审计是有限数值采样，不是连续波段或实验认证。新见证支配旧见证，但**不证明全局最少层数或最薄厚度**。[可复核的目标、合成材料数值源、逐层设计及审计摘要](reference-quality-case.json)。

旧模型对该案例预测约 21 层；新 24 层见证表明旧 48 层参考对这一比较偏大，厚度预测仍有误差。这既不能证明旧模型准确，也不能确定最少层数。

## 数据与训练组交叉验证

基础数据有 32 个材料组、192 个训练任务，其中 158 个有见证、34 个未知；源增强产生 316 个衍生任务，其中 258 个有见证、58 个未知，仍属于同一 32 个组。合计 416 个有见证、92 个未知；**不是 416 个独立材料**。源增强仅从 158 个已有见证的基础任务生成，未覆盖 34 个未知基础任务，因而存在选择偏差。源变体来自自有合成输入，不是测量数据；无见证是未知而不是不可行。

| 分组 | 有见证行数 | N MAE（层） | D MAPE |
|---|---:|---:|---:|
| 基础 | 158 | 4.278 | 27.476% |
| 色散变体 | 140 | 4.436 | 27.578% |
| n/k 变体 | 118 | 4.483 | 28.534% |
| 全部 | 416 | 4.389 | 27.810% |

这是 8 折训练组交叉验证：按原材料组分组，衍生样本随原组分折；模型为 ExtraTrees，非生产模型，也不是新盲测；按原先 N MAE ≤3 层和 D MAPE ≤25% 的门槛，各分组与总体均未通过这两项。未做新校准或测试，不能据此宣称联合覆盖、生产性能或跨任意材料目标泛化。

## 输入表征与语义

本轮修复 v2 池化丢失 R/T 与位置对应关系的问题；保留同一材料的 n/k 联合关系和原生窄峰位置矩。评分权重与 normalization 不作为物性预测信号。未知 k 只有在明确许可后才可按零建立数值模型，假设与来源知识单独记录；预测区间不是材料测量误差。上述是输入与研究方法的描述，不代表预测器已经验收。
