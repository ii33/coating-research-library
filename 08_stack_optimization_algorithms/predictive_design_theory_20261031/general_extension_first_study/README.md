# 材料函数与完整约束集合：快速联合资源预测的首轮扩展研究

日期：2026-10-31。**研究结果，未通过验收；不发布模型，不构成通用预测功能。** 本研究的方向是根据材料光学函数和完整任务约束集合快速联合预测层数 N 与物理总厚度 D，而不是以材料白名单或单一任务类型决定准入。生产版本仍为 dev.20261031.06；本研究的编码与候选模型均未发布到软件 main。任务输入编码已有实现且 19 项定向测试通过，但编码测试不等于预测能力已经通过或获得支持。

## 设计与边界

原计划含 252 个合成模板任务、48 个材料组：训练 120、原校准 60、测试 72；带通模板仅出现在测试集。组间材料不同，但数据仍来自少数模板，不能据此证明对任意材料或目标的泛化。训练组交叉验证比较 ridge、PCA 和 kernel 后，依 one-standard-error 规则选择较简单的固定 ridge；测试集未用于选择。原校准集因区间过宽而转为开发用途；另以 12 个新组的 60 个任务校准后评估保留测试集。训练 120 个任务中 116 个有可用见证。

标签是固定参考流程和候选选择政策下同一审计见证的成对 N、D，不是全局最小值。未找到见证为 **unknown**，不是不可行。有限采样审计也不是连续波段或实测的保证。此处材料组留出不等同于真实材料或生产任务验证。

## 修正后的盲测结果

各类指标基于有见证的可评分任务；可评分比的分母包含未知任务。N MAE 单位为层；D MAPE 和联合覆盖以百分数表示；厚度区间宽度为上限/下限的中位数（倍数）。下限为零时该案例比值为无穷。高覆盖若伴随极宽区间并不意味着有用的准确预测。

| 类别 | 可评分/总数 | N MAE | D MAPE | 联合覆盖 | 厚度区间上/下限比中位数 |
|---|---:|---:|---:|---:|---:|
| AR | 12/12 | 1.17 | 94.66% | 91.67% | 无穷 |
| HR | 10/12 | 5.10 | 28.04% | 100% | 40.06 |
| 混合目标 | 12/12 | 3.92 | 22.77% | 100% | 9.85 |
| 双窗 AR | 12/12 | 3.67 | 88.21% | 91.67% | 无穷 |
| 均值混合 | 12/12 | 4.17 | 23.27% | 100% | 10.19 |
| 带通（仅测试） | 10/12 | 7.00 | 20.05% | 100% | 9.55 |
| 总计 | 68/72 | 4.06 | 47.47% | 97.06% | 无穷 |

预设门槛为 N MAE ≤3 层、D MAPE ≤25%、联合覆盖 ≥90%、厚度区间比中位数 ≤3、可评分比 ≥70%；**所有类别均未同时通过**。四个测试任务无见证，不能计算误差。覆盖是本测试上可评分样本的经验统计，不是对分布外任务的保证。在线热态 P95 ≤200 ms 仅是目标，尚未测量。

原未更正报告只要存在任一下限为零就将该类中位数记为 null，这是汇总错误。现将每个零下限案例的比值计为无穷，再计算中位数；无穷中位数在机器可读数据中以 `null` 加明确的 `is_infinite` 标记表示。该修正未改变逐案例预测，也未重新拟合。

## 局限与后续问题

响应变换 `log1p(D/λref)` 对薄膜的相对误差可能不够敏感，值得作为待改假设检验；这不是已证实的全部误差原因。参考流程重复试验只有 6 个任务、每任务 3 个种子：其中 1 个任务的 N 从 4 变为 8，其余层数稳定；样本太少，不能泛化稳定性。历史宽泛数据仅盘点，9 个任务组、25 次运行对应 11 个设计，不作为本次训练数据。

真实色散/吸收材料、生产任务及更广泛目标组合仍需独立验证，且当前结果不支持交付新模型。下一步需检查目标变换、标签和模型误差，再以独立分组数据重新校准和盲测；不能通过放宽报告语义掩盖失败。

外部数据状态：核查 [IrisFlow 官方仓库](https://github.com/z-one-l/IrisFlow) 时，其 README 表示训练和测试数据将发布至 Hugging Face，但未给出具体数据集地址；本研究未据此声称已取得可用训练数据。
