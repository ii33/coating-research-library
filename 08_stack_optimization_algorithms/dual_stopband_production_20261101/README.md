# 双阻带四窗口生产路径诊断报告

**结论：生产路径在明确的低损耗参考模型下，从空膜层和无手工种子出发，找到了通过原四窗口有限数值审计的 95 层候选。** 这是固定参考数据上的数值证据，不是用户实际材料、制造容差、连续全谱或最小资源的验收。研究阶段的未达标结果与材料模型变更必须一起阅读，不能把差异全部归因于算法。

## 原目标和材料边界

0°、非偏振。严格透射率目标：400–500 nm T > 0.8；510–550 nm T < 0.01；560–700 nm T > 0.8；1040–1080 nm T < 0.01。原评分和审计始终使用这四项 T 条件。

最初诊断使用 TiO₂ Franta、SiO₂ Rodríguez de Marcos 和 H-K9L 参考数据；用户尚未确认真实数据组。后续通过案例把 SiO₂ 膜换成 **Malitson 块材 n-only 低损耗参考模型**，不是用户膜层工艺标定。已知 TiO₂ 膜 k 保留；Malitson 膜和 H-K9L 基片缺失的 k 在显式条件下假设为零。两个来源模型不同，不能把通过完全归因于算法。

## 阶段比较

| 阶段 | 结果及条件 | 记录的实际工作量 / 候选 |
|---|---|---|
| 生产旧入口，Rodríguez 参考 | 未达标，局部收敛；最大采样违例 73.395 个百分点 | 14.05 s，98 次评价；3 层 / 315.302 nm |
| 研究阻带结构提示，同源 | 未达标，评价次数到上限；最大采样违例 11.954 个百分点 | 86.55 s，512 次评价；22 层 / 2026.444 nm |
| 扩预算研究，同源 | 未达标，局部终止；最大采样违例约 11.954 个百分点 | 556.58 s，2708 次评价；24 层 / 2026.437 nm |
| 非四分之一波窄阻带研究，同源 | 约 600 s 协作取消，无完整独立审计；**不作失败或不可行证明** | 1865 次评价；保留候选 59 层 / 6271.353 nm，未作为通过设计 |
| 非四分之一波窄阻带研究，Malitson 低损耗参考 | 先前通过的候选被保留；后续裕量修正被审计拒绝 | 437.68 s，1295 次评价；95 层 / 8703.944 nm |
| 最终生产路径，Malitson 低损耗参考 | 从空膜层、无手工种子启动；`validated_targets_met` | 113.05 s，353 次评价；95 层 / 8703.944420 nm，严格目标审计零违例 |

最初两方案配置同为最多 512 次评价及外部协作式 120 秒限制，但实际耗时和评价数明显不同；扩预算阶段的上限为 4096 次评价、600 秒，实际没有耗满评价数。各阶段并非等工作量实验，600 秒等外部取消也不是硬实时中断，不作等成本效率排名。

第二窗最紧记录余量仅约 0.000002 的 T（约 0.0002 个百分点），不可解释为制造容差。审计包含有限采样和局部极值搜索，仍使用同一光学模型，不是连续谱证明或独立物理求解器验证。95 层方案不是最少层数、最薄厚度或已应用于用户设计的证明。

## 方法范围

T 上限仅用于生成反射型起始结构提示；原 T 目标、已知 k、局部收敛和审计逻辑不因此改变。对法向且被通带夹住的窄阻带，结构提案利用最近通带边界选择光学占空比，再用周期衰减启发式生成有限周期数的梯度候选。这些只是起点提案，不是层数需求下界或可行性证明。

## 代码、测试与证据链

研究阶段确认：旧生产入口在该请求上 reflector、bandpass 和 multispectral 提案为零；研究版本只把 T 上限转成 R 结构提示，不把它当作正式评分等价式。最终结果使用实际生产工作树、无 monkeypatch，`search_until_target=True`，没有手工 seed、续接或初始膜层。

结果来自基底 `818eec000eccd386124937b9627620058349dfa0` 及五个已记录工作树 core 哈希。正式版本 `dev.20261101.06` 的提交 `7bc69fcc69d92c8e2279581f7807f685d80ef6df` 的五个对应 core 文件已独立复读并全部匹配生产验证 v2 SHA-256；原 preflight 的基底记录没有改写；其中 `no_synthesis_executed` 只描述预检阶段，不表示随后没有运行合成。该映射不扩大成对所有环境或材料的验证。

定向日志记录 78 + 47 + 102 = 227 项通过；官方静态分析摘要记录新增 0、致命语法 0。它们不是软件全量测试，也不是独立物理试验；stdout 摘要本身未嵌入提交哈希。原始结果、未修正 summary 和运行日志保留在私有证据中。原 summary 的 tuple 判断曾误报 `available=false`；本报告采用逐窗 corrected summary 和 `verification-final`，不覆盖原文。

证据包按 [parts-index.json](parts-index.json) 和 [evidence-manifest.json](evidence-manifest.json) 核验：每个派生结果记录原始 SHA-256 与变换；仅删除运行主机路径和进程/CPU 标识，其余数值内容保留。生产候选和原目标审计见 `packages/06-production.tar.gz`；派生结果不应作为可恢复优化器状态。
