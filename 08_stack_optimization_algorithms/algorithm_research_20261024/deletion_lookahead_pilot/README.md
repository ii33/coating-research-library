- 执行源码为本地开发提交 7e43ebf845d82e50e7bf38bbcc227671fbc68b04；已发布主项目 [62e3712](https://github.com/ii33/coating-sim/commit/62e37123f45fa280eeaeee18fdab0e3726b067d6) 包含相同的本实验局部优化、评分、批针清理和请求解析实现。发布没有触发本实验重新运行，也没有启用试验策略。

同一个经24次局部求值的58物理层起点，比较立即选删层分支再优化（A）与每个分支先8次局部求值再选择（B）。每臂64次上限、90秒固定时间上限；实际分别完成50和43次。相同43次下最大归一化违规 A=0.023301731、B=0.035015040，A42次且工作量更低仍更好。两臂最终选中同一分支，没有实现获胜分支反转，均未达标。

本次只运行一组，没有独立密网格验收、重复种子或留出目标，不能作工程交付结论。原起点仍在明显下降，不能声称从已证局部最优跳出。当前证据不支持将此固定分配策略加入默认搜索。

研究方向参考：Trubetskov, “Deep search methods for multilayer coating design”, Applied Optics 59, A75 (2020), https://doi.org/10.1364/AO.59.000A75 。该文讨论在局部精修后比较不同结构操作的思想；本实验的四分支、八次配额和时间上限是本项目约定，不声称复现其完整算法。
