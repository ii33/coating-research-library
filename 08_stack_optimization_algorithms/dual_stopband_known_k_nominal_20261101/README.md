# 更正：已知膜吸收模型下的名义有限采样解

**后续研究已找到原已知膜 k 模型的四窗名义有限采样达标候选。** 此结果更新了[续跑报告](../dual_stopband_continuation_20261101/README.md)和[外层策略报告](../dual_stopband_outer_policy_20261101/README.md)中“当时尚未找到”的阶段状态；那些报告记录的对应历史运行结果仍然未达标，并未被改写。此新结果不采用先前反事实 k=0 膜材。

**重要限制：它是实验性相位初始化、多起点与暖启动得到的数学样本，不是默认无种子生产流程通过的证明。** 候选 65 层、总厚 4581.968480876134 nm，最薄层仅 **0.0714006628 nm（约 0.714 Å）**，薄于通常意义上的原子层尺度，不可直接作为可制造膜系。阻带距离上限的有限采样最小余量仅约 **0.0000013 的透射率**；没有制造容差、材料参数不确定性或连续波段保证。

## 原目标和材料模型

法向、非偏振、正面优化，背面无膜；3 mm H-K9L 双面基片。四个包含端点的逐点透射要求是 400–500 nm T≥0.8、510–550 nm T≤0.0065、560–700 nm T≥0.8、1040–1080 nm T≤0.0065。膜材使用公开参考 TiO₂ Franta 和 SiO₂ Rodríguez-de Marcos 的原已知 n/k，只有未知的基片 k 明确假设为 0。公开材料标识、模型来源及输入边界见[公共参考案例](../dual_stopband_continuation_20261101/public-reference-case.json)；参考数据不等于用户实际生产工艺或独立材料实测。

任务结果给出完整验证并名义达标；另行同模型审计 2148 个条件名义达标。又以 0.1 nm 网格逐窗计算 3204 个条件，四窗全部满足阈值：

|---|---:|---:|---:|

| 560–700 | 最小 0.8000281273 | ≥ 0.8 | 0.0000281273 |

另外用**独立编写的正入射特征矩阵实现**交叉计算，不调用项目 R/T 求解器；使用相同 n/k 插值、H-K9L 参数和未知基片 k=0 假设。在审计网格上与保存的审计透射率最大绝对差约 2.79×10⁻¹⁴；其 0.1 nm 网格结果亦满足名义目标。独立实现不是独立的材料数据或制造测量，网格与局部极值采样均不是连续区间证明。完整聚合量见 [results.json](results.json)。
