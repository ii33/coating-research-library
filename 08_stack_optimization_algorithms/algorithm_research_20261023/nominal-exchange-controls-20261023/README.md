# 名义约束反馈与固定工作集：公平100cloud控制及384样本验证

日期：2026-10-23。先读[训练对照](training-report.md)和[固定候选验证](validation-report.md)。这是已完成的有界光学研究，不是软件发布、v2存储任务或生产验收。前轮研究及正负结果保持原样。

## 核心结论

- exchange完整名义合格候选的训练worst为0.0007036184437906323，比固定760控制的0.0010706379975689018低34.28%。两组均耗尽100cloud预算，不是收敛证明。
- 两个终末raw稀疏状态都未通过原184600名义条件并被拒收，不能拿raw更低数值冒充可用设计。两保留候选与原基线另经529396条件dense49诊断全部通过，仍非连续域证书。
- 全新固定验证每模型64样本，三个设计共384次完整原网格评价：独立模型baseline/control/exchange均0/64；共模为4/64、5/64、0/64。
- 共模control→exchange有5次通过→失败、0次反向。双侧exact配对p=0.0625，探索性、未校正多重比较，不作强显著性或制造收益宣称。
- exchange的worst/P95超限严重度较小，但完整四窗通过数不升反降。严重度、训练目标、名义资格与yield是不同判据。

## 固定算法与预算

两组从同一原89层出发，使用同一32场景、训练seed2026102341、假设独立均匀±0.5%厚度误差，全部89变量在原厚±1%设计域内；误差幅度与设计域不是同一设置。robust目标始终为相同600光学条件，没有把新名义点混入robust目标。

两组都预先固定5个outer×20个完整cloud=100。control名义工作集固定760；exchange将完整原网格扫描发现的违规约束回注下一outer的名义工作集。全部原严格R/T门限保持不变，无额外margin；原网格扫描和已完整合格incumbent保留独立。

exchange工作集记录760→782→782→842→842→846，最后4点在终末预算后加入但没有再求解，最大真正求解集合为842，不能称846点约束已经求解。前20完整cloud逐位相同，之后的路径差异来自预声明反馈策略。额外原网格资格检查和最终前向重放不计入训练cloud，但物理工作量另报。

此策略是独立研究驱动中的实现/实测，不表明现有生产GUI或正式软件入口已集成该反馈控制。

## 统计与物理边界

所有误差均为未校准的有界假设，材料沿用理想k=0模型。0/64不表示真实通过概率严格为0，其假设iid模型的双侧95%exact上界仍约5.60%；这些区间不适用于未经校准的真实生产过程。

仅一个训练seed、一个误差档、固定材料/拓扑和局部设计域。固定验证无新增训练/候选选择；100cloud停止与dense49通过不能证明全局最优、连续可行或生产可靠性。历史耗时受共享资源影响，只作成本观察，不是加速比。GPU、MPI或生产扩展性不在本研究完成声明内。
