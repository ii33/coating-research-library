# 自动膜系合成：统一混合路线与真实边界

日期：2026-10-23。已有实现依据 [17e0c4d核心契约](https://github.com/ii33/coating-sim/blob/17e0c4d8ecd38faf88f1793a4a935d683fa037fb/docs/film-auto-synthesis-contract.md)、[算法说明](https://github.com/ii33/coating-sim/blob/17e0c4d8ecd38faf88f1793a4a935d683fa037fb/docs/algorithms.html)、[多核验证](https://github.com/ii33/coating-sim/blob/17e0c4d8ecd38faf88f1793a4a935d683fa037fb/docs/film-synthesis-multicore-validation-20261023.md)。不把早期历史章节中的“后续实现”当当前状态。

## 1. 原问题不变，探索路径可以多样

输入为裸基片环境、允许的真实材料集合、原R/T规格及显式制造/资源/时间限制，也可提供真实seed。已有起点不称从零发现；不嵌入研究89层答案。材料在覆盖域内冻结，未知k不补零、不外推，已知教学k=0与真实数据身份分开。

hybrid已连接正式GUI、CLI、job/checkpoint和MCP，共用冻结问题及原验收。legacy只用于显式历史重放。默认最大层数不人为钉在70或104；有限预算耗尽表示尚未找到，不是物理不可行。

## 2. 已实现的探索循环

1. 多结构族广筛：均匀层、分窗HR、非QW匹配剖面、反射堆栈、AR/匹配簇、腔及双子栈等，结合材料对比、带宽和角度作需求尺度排序。尺度估计不是最少层数定理。
2. 保存真实设计与谱形多样性/Pareto档案，分别保护训练严格冠军和精确处方绑定的已审计冠军。
3. 局部/低维DE探索厚度，再对真实界面与层内位置计算解析零厚针方向。针锚定原宿主与位置；有限插入改变的真实层序必须完整前向重算。
4. 同轮多针实际插入后，联合优化全部真实层厚。SSE真实终点可续接下一轮，即使最坏违规暂时变差；不会因此覆盖更好的严格冠军。
5. 清除精确零层、相邻同material_id+optical_set_id合并、合法实际删层后重算；不同材料数据集不能仅因名称相似就合并。
6. 使用全部原约束的minimax/SLSQP及独立密网格、错位/极值审计；求解器的辅助t不直接作为目标通过证据。

探索默认按窗口归一，避免IR因点数多占据损失；这不删原采样点、不放宽最坏条件。各轮调度片不是隐性总预算。用户显式总评价/时间/轮数和资源护栏、取消与最终审计预留共同决定实际执行，未执行阶段须明确记录。

## 3. 数学零针不等于有限制造层

零厚针导数只给局部下降方向，有限层的相位、干涉与制造边界可能使方向失效。层内插入必须拆分宿主并保持原宿主总厚；多个探针的Jacobian列必须按实际构造层序绑定。只有有限厚度真实前向与联合精修后的结果才可比较，不能把多个负导数直接相加当最终性能。

裸界面的某些一阶导数可为零，因此还需合法正有限厚度出生与结构先验。局部不改进不是停止全部结构探索的物理理由。后续独审漏峰也不能用训练已通过掩盖。

## 4. 真实多进程做了什么

工程先验/全局独立候选与同轮零厚针探针已用持久进程执行。每进程准备一次材料上下文，源序采纳保证固定冻结逻辑批次的串并物理语义一致；联合厚度更新、后续轮次依赖和最终独审仍有串行部分。独立敏感性本阶段没有新增并行证据。

- 受控Windows专项：19个真实工作PID都有正CPU增量，31项任务完成，固定批次串并一致、退出清理完成；3GiB准入护栏下峰值估计约2.64GiB。17.90秒只是该有界任务耗时，不是加速比。
- 云端请求19、实际可用CPU为9时，得到9个真正工作的PID，不能报19个已使用进程。
- 12个独立48层/1001点Jacobian热池约1.63×只代表该评价片段，不含整个冷启动流程，也没有线程池A/B结论。
- 另一微任务原先部分PID的CPU增量为0；诊断发现15.625ms计时量化。提高测试物理网格不等于已完成该Windows用例复验，不伪造正数或改生产阈值。

请求进程数、ready进程数、真正派发并完成任务的PID数、峰值内存估计和进程RSS不是同一个指标。内存估计只控制工作准入，不是操作系统硬限；资源跳过不证明物理不可行。

## 5. 必须保留的负结果

四窗原目标为580–920nm和1044–1084nm非偏振R≥0.99、3000–5000nm和7000–12000nm严格R<0.03，39–51°。原1200秒正式冷启动仍未达标，末端108层的失败不能因后续多核专项通过而改标成功。

研究89层名义合格是已知起点工程精修结果，材料k=0假设、额外采样范围和处方来源都必须一起带出。它既不是软件冷自动合成的成功证明，也不是制造稳健或真实吸收证明。

发布快照存在定向验证证据，但完整CI仍有GUI冠军清理回归在后续修复验证中；此文不宣称全部tiers全绿。光谱独立审计仍共用物理内核，有限密网格不构成连续域证书。

## 6. 下一步判据，不新增长实验

优先保持真实探索终点、严格冠军和已审计冠军一致的处方身份，保证清理后重新评分/独审；再以相同材料、原网格与预算比较冷启动搜索路径。计入启动、通信、取消/回退、未知工作和清理，而非只报热池速度。没有完成的四窗冷测、Windows复验和完整CI明确标未完成，不靠降低规格补成功。
