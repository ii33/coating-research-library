# 双起点 mean-only 可行性修复与深谷诊断 · 2026-10-24

C67 与 A68v0 从各自冻结父设计独立出发，在固定材料、层数和层序下，通过了四窗逐角波段平均值的原网格训练及独立加密网格验收。两条主线均在首个 L-BFGS-B 阶段达到严格均值条件后提前停止。**这不是旧逐点规格通过，也不是制造或连续角域验证。**

第一高反窗的加密最小反射率分别只有 **67.971194819%（C67）和 40.894589577%（A68v0）**。平均值目标允许这类深谷与较高的带内其余响应同时存在；本轮结果展示了这种取舍，不能将它概括为零星坏点。当前没有增加任何逐点硬底线。

本报告接续 [breadth36 历史收尾](breadth36-mean-and-pointwise-closeout-20261023.md)，保留其原目标、失败结果和当时“下一计算尚未执行”的时间状态。[87 层原逐点通过历史](direct_flux_repair_validation_20261023.md)也不变。两份新代表、各自原父、全部物理层和完整诊断独立封存；本次仅公开摘要、复验合同和证据哈希。

## 1. 冻结物理与目标合同

- 空气 → 相干 ZnS/YbF3 膜 → 半无限 ZnS 基片；单面、各向同性，非偏振响应为 s/p 的算术平均。
- 保持原折射率数据，显式零 k；T 和厚度导数采用直接能流公式，不以 1−R 代替。
- 四窗为 R > 0.97 @ 580–920 nm、R > 0.99 @ 1039–1089 nm、T > 0.98 @ 3650–5000 nm、T > 0.98 @ 7650–10550 nm。
- 上述不等式用于**每个入射角各自的全波段加权平均**。波长积分采用完整有序网格上的梯形权重，再除以波段宽度；端点半权，不跨角度平均。
- 新 schema 的 mean-only 明确开启，pointwise 明确关闭；strict_lower=true、无上界，四窗 weight=normalization_scale=1。
- 无隐藏逐点底线、违规比例门、额外名义余量或敏感性 0.5 个百分点 guard。旧逐点阈值仅用于下文诊断。
- 有符号均值 gap = 目标 − 实际均值，全部条件 gap < 0 才通过；正值代表违规。

|---|---|---|---:|---:|

加密验收使用完整波段积分，没有把零散偏移点或极值点混入均值权重。该加密网格与历史其他 dense 网格身份不同。

冻结软件为 [coating-sim 8f0cd958](https://github.com/ii33/coating-sim/tree/8f0cd958b912477fc6d62b2a8769d98c835fe3d5)，版本 dev.20261024.02；本实验不追随后续改动。环境为 Python 3.13.16、NumPy 2.5.4、SciPy 1.18.1、psutil 7.2.2，BLAS 单线程。

前置资格已检查 mean 归约接线、直接 T、完整谱积分权重和块大小独立性：父目标响应逐点差为 0、均值差不超过 4.44×10⁻¹⁶；少量双步长厚度差分对 Jμ 的最大绝对差分别为 C67 7.9369×10⁻¹²、A68v0 2.81696×10⁻¹³ fraction/nm。资格收费 14.703125 CPU 秒，独立于下述双起点预算。

## 2. 求解与代表选择

使用冻结的 refine_multispectral_minimax 及解析均值 Jacobian。计划 BETAS=(100,400,1500)，平滑 L-BFGS-B 后接 SLSQP epigraph；**实际两线都在 beta=100 达到严格均值条件，后续 beta 与 epigraph 未执行**，不将早停写成求解器收敛。

两线不互相热启动。固定材料、层序和全部物理厚度槽，没有随机重启、针插、删层、合并或减厚目标。采用现有 coordinate_scale_nm=None，坐标尺度为 max(父厚度, 1 nm)；现有正厚下界为浮点 finfo.tiny，无层厚上限或总厚上限。这个数值域下界不是工艺下限；A68v0 的极小正厚槽保留，未按 epsilon 清除。

每线最多 600 CPU 秒、100 次未缓存完整训练 F/J 候选评估和 60 次全局优化迭代，计数跨所有延续阶段共享。研究包装器仅落实共享预算和归档，在 finally 恢复被包装入口。先完成评估并保存完整候选，再检查成功或额度；不把部分响应或探针写成可用代表。

完整候选按（全均值条件最大有符号 gap，既定加权 RMS）排序；每次严格改善保存可恢复设计与绑定摘要。C67 档案为原父加 8 次改善，A68v0 为原父加 9 次改善。事后只读复核全部档案的严格排序、设计身份与摘要绑定；光学独审仅使用封存 best，另开进程复算 original 和 dense。

## 9. 下一轮选择所需事实

C67 的加密第一窗谷较 A68v0 浅，但离散旧阈值违规比例更大；A68v0 的第一窗谷更深，第二高反窗仍逐点通过。不能仅由一个均值或一个最小值为两者作工程优劣总排序。
