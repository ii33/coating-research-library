# 多光谱直接通量修谷与冻结网格复核 · 2026-10-23

## 模型与门槛

单面 Air → coherent ZnS/YbF3 膜系 → 半无限 ZnS；各层显式处理零吸收系数 (k=0)，保持 (n) 不变，非偏振结果取 ((s+p)/2)。40–50°范围内要求：R>0.97（580–920nm）、R>0.99（1039–1089nm）；T>0.98（3650–5000nm、7650–10550nm）。T按直接通量/JacT计算，不以 (1-R) 替代。

## 修复与结果

89槽起点先经80次初试、再160次续试仍未满足目标。恢复的79-trial候选通过原1nm网格，但在密集检查的622.6–622.8、628.1–628.4、672.3–672.4nm（50°）三簇共9点失败。随后将原U、原网格和这些失败点邻点精确去重，形成105,725点修复集合；采用局部 max signed-gap 与 W 梯度，厚度参数步盒半径为0.0625nm（不是光谱分辨率），不加隐藏margin。修谷搜索仅有1个trial达到严格S可行。

冻结独立复核全部通过：original 97,524点、dense 334,314点、offset 326,000点、ultra 1,320,624点。原四窗最小R/T为0.970019574159、0.990019658689、0.980017981547、0.980018436530；ultra最紧点为628.25nm/50°、R=0.970015742289164。44个有界局部观测均通过；dense局部搜索有20项、ultra有11项达到maxeval，ultra记录13次success。该结果仅支持所列冻结网格和局部观测，不证明连续域合格或制造容差资格。

候选保持89槽、88个厚度严格非零；未删除零槽或合并，不称为“88层验收”或减厚。总厚度10882.484204614864nm，较原seed 10848.14676300214nm增加34.33744nm。修谷训练耗时7.53125 CPU s、审计62.328125 CPU s；已采样supervisor合计70.828125 CPU s。这不是从零开始的全流程总耗时，前序搜索/错误IO另计，监督尾部未采样。实际快照为0 IO retry/0 failure，不能据此确定先前 WinError 5 的根因。
