## 结论及历史边界

- **C67 不是整体达标解。** 相同阈值的逐角仅平均视图通过第一、第二、第四窗，第三窗未通过；原逐点严格视图四窗均失败。第三窗 50° 的违规点比例达 85.2702%，不能概括为“少量坏点”。
- A68 同样仅第三窗平均未过；B 与配对随机 D 的平均结果更差。四支原逐点整体门和四窗仅平均整体门均为 false。
- deep 后封存代表在 S1 训练网格上，C67 的最坏违规更小，但原网格暴露 743 nm/50° 的窄谷，原网格最大违规 2.901221 个百分点略大于 A68 的 2.848275 个百分点。不能把训练排序直接作为原网格排序。
- 本轮 D 初值扰动没有显示普遍收益。有限的模板、两 seed 配对与 CPU 预算不能证明随机机制无效，也不能证明 60–70 层不可行。
- [既有 87 层规范化与四网格通过历史](direct_flux_repair_validation_20261023.md)独立保留。该历史处方没有被此次紧凑探索替换；C 家族有继承来源，不宣称从零冷启动。
- A 的第 6 项结构尝试不再补跑。后续 mean-only 双起点优化等待新的共同归约实现验证与研究合同，本轮未执行。敏感性研究的 0.5 个百分点容许退化未借用于本轮。

后来追加的**仅平均视图**在每一个角度独立计算：

mean_b(theta) = sum_j [(lambda[j+1]−lambda[j]) × (y[j+1]+y[j])/2] / (lambda_max−lambda_min)。

全部 21 个角度的 mean_b 都严格超过本窗原阈值，该窗才通过；四窗都通过才是整体 mean-only pass。端点半权，不用跨角平均隐藏坏角度。此视图是从同一份原网格数组事后归约，未被用于本次训练或选 best，没有回写历史判定。

软件语义中的“绝对值指标”指逐点上下限，不是数学 abs。平均和逐点指标可独立选择；本报告只对比同阈值的两个单独视图，未配置新的点值下限或 combined 门。违规点比例、波长占比、缺口深度与连续失败采样段仅为诊断，不追加为 mean-only 的隐含门。

### 可复验的构造约定

以下公式按入射方向描述；存储处方明确转为 substrate_outward。H=ZnS，L=YbF3，q_m(lambda)=sqrt(n_m(lambda)^2−sin²45°)，不外推材料。

反射对：d_H=rho×lambda_B/(2q_H)，d_L=(1−rho)×lambda_B/(2q_L)。IR 初始匹配对：d_H=u×lambda_I/(4q_H)，d_L=(1−u)×lambda_I/(4q_L)，仅为初值，不宣称独立 AR 已达标；整栈按相干模型评分。

v0 含 4 个匹配层：入射端 9100 nm/u=.20，出射端 4325 nm/u=.20。v1 含 6 个匹配层：前端 4325 nm/u=.35、窄带/可见块之间 9100 nm/u=.20、末端 4325 nm/u=.35。匹配层计入 N，P=(N−M)/2。

1064 nm 在 40/45/50° 的 s 导纳 q 与 p 导纳 n²/q 上取 H/L 比的最小 gamma；m*=ceil(log((1+sqrt(.99))/(1−sqrt(.99)))/(2log(gamma))) 仅作 seed 经验，不是层数下界。窄带对数 clip 到 [2,P−3]。

A v0：可见中心 630/755/900 nm，剩余对数按 1:1:1 最大余数分配、每中心至少 1 对；顺序 630→755→900→1064，rho=.5，窄带 m*。A v1：中心 615/745/895 nm，分配 1.15:.85:1，顺序 1064→895→745→615，窄带 m*−1。分配 tie 固定靠前中心。

B v0：可见 t=i/(P_V−1)，lambda_B=620+300t，rho=.25+.25sin²(pi t/2)，窄带置后。B v1：1/lambda_B=(1−t)/920+t/620，rho=.35+.15cos²(pi t/2)，窄带置前。非法 P_V 构造停止，不能按光谱质量重抽。

C 保留入射首层，将余 86 层组成 43 个连续材料对，按 1064 nm/45° 的每对 qd 累积权重分为 30/32/33/34 个非空连续组；最近累计位置切分、tie 靠前且给余组留至少一对，同材料厚度用 fsum 合并。压缩改变干涉结构，不宣称相干等价，后续可优化全部层。

D 仅随机初始厚度：z0~N(0,1)，z_j=.85z_(j−1)+sqrt(1−.85²)xi_j，独立 epsilon_j~N(0,1)，delta_j=clip(.12z_j+.06epsilon_j,−.35,.35)，d'_j=d_j exp(delta_j)。匹配层也扰动，不归一总厚。实验 root seed=20261023；ASCII compact JSON [root_seed,candidate_id,"initial",attempt] 经 SHA256 取前 16 bytes、big-endian 为 128 bit seed，再用 PCG64（本轮 NumPy 2.5.4）。无效/非有限/hash 重复时最多三次尝试，含初始一次及最多两次重抽；谱差不重抽。关闭模板扰动不消费新增扰动 RNG；不改变产品原有 DE 等算法的 seed 行为。编辑顺序、tie、档案与 worker 返回不再随机化。同配置 seed 可重放提案，不承诺 CPU 截止下或跨平台的优化轨迹逐 bit 相同。

## 36 → 12 → 4：网格、晋级与局部预算

S0：四窗 lambda 步长 5/2/25/50 nm、含端点，角度 40/42.5/45/47.5/50°，共 1,045 条件。每支 6 CPU 秒，36 支总上限 216 CPU 秒。

S1：步长 2/1/10/20 nm、含端点，40–50° 每 1°，共 5,544 条件。晋级 12 支，每支 24 CPU 秒，总上限 288 CPU 秒。

36→12 名单按家族展示（不是性能排名）：

- A：A74v1、A68v0、A70v0、A56v1。
- B：B60v0、B64v0、B56v1、B70v1。

- D：D-B64v0-seed2、D-B70v1-seed2。

12 支都做 original F-only 诊断，总计 19.875 CPU 秒；这些结果参与后续选择，因此不是未见最终验证，没有据此另注入失败点改变 S1。12→4 为 A68v0、C67、B70v1、D-B70v1-seed2，晋级时 N 分别 68/67/70/70，满足 A/B/D 与 D/base 配对、多层数、C≤1。

deep 每支独立 129 CPU 秒（共 516）：保留未编辑完整 best；既有 minimax 的各 beta、L-BFGS-B 平滑阶段及 SLSQP epigraph 共用同一 CPU 预算，不把 max_iterations 当总预算。上限六种结构尝试：两次针插/分裂、两次内部删/成对删合、一次端层减半、一次内部层组重排。非法提案应局部拒绝，不应阻断已保存 best 的验收。

## 随机配对的有限结论

最终 D-B70v1-seed2 相对 B70v1：第三窗最小 T 与最差角平均 T 略好，但另外三窗、总体最坏 gap 及总厚度更差。最坏原网格违规为 D 的 17.916580 个百分点，对照 B 为 13.470442 个百分点。D8 的 S0 中只有 D-B70v1-seed2 的最坏 gap 略小于其 base；这不是随机机制总体获益的证据。

本轮实际比较的是不同初值在固定局部算法和有限 CPU 内的路径，没有随机改写严格优劣、编辑顺序或档案排序。不能从这一轮的小样本否定随机化，也不能把更多 seed 或更长预算假装成已执行结果。

## 失败经验与收尾修正

1. A68 的第 5 项端层减半把一个正厚数值推至约 1.112536929e−308 nm，低于现有 solver 的数值定义域。机器 finfo.tiny 不是工艺厚度下限；不能用 epsilon 偷删该层。原错误记录、已收费 92.90625 CPU 秒与完整 best 保留。该提案未重做，第 6 项也没有补跑。
2. 旧调度器把 A 分支错误传播到全局 finalizer，导致其他完整 best 的验收被阻断。此次将四个代表先逐字冻结，独立 F-only 验收；旧 failed/partial 状态保持原样，不冒称优化收敛。
3. 验收前发现 live 软件有五文件更新，不能静默切核。原 155 个 core 文件按原登记 SHA 精确隔离，五个变化文件由同提交原字节恢复至独立研究快照；另两个导入依赖单独绑定，不改正式软件仓库。
4. 首次隔离加载器错误移除了嵌套标准库，四支在 dataclasses 导入处失败，所有光学计数为 0；3.734375 CPU 秒启动成本照常记入验证。修正版仅保留运行时库路径，全部 coat_sim 导入仍经冻结路径与 SHA 门，不放宽数学或材料身份。5 个必要小 fixture 通过，四支 original 和统计完成，29 个自有进程身份均确认退出。
5. 窄谷漏采仍是关键：S1 成绩不是原网格资格。当前验收失败者不追加更密网格以改变结论，也没有借后期或其他支预算重搜。
