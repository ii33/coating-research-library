# 理想敏感度优化与固定初态受控退化研究摘要

更新日期：2026-10-23。实现依据为已发布的 [coating-sim 0165323](https://github.com/ii33/coating-sim/commit/0165323ddabc6579b9d4005b35e7572ff4e974a3)。本次只补充方法、一个真实物理计算小例与验证范围，不替换此前89层或制造误差探索数据，不提供完整冻结请求或执行日志。

## 两种工作分开

- **理想敏感度优化**：固定层序、原材料数据及吸收设置、原网格/角度/偏振，只优化显式厚度变量。理想假设不等于偷偷把材料吸收设为零；缺失的材料数据不能自动补零。
- **厚度参数表预期误差分析**：用户显式填写偏差、界限或标准差及必要相关性，单独输出局部预期影响。未填不是零，未声明相关性不假定独立。表格不自动给优化目标配权，也不提供退化预算或可应用候选。

当前方向不预置真实工艺误差模型或生产良率目标。历史独立、共模和漂移场景仍作为研究假设保留，不是产品默认。

## 优化的量不是达标率

设原条件为 i，所选厚度导数列为 j，物理厚度 d 的单位为 nm，Jᵢⱼ=∂yᵢ/∂dⱼ，y 为0–1的R/T功率比例。原条件权重 w 和归一化尺度 b 保持不变：

**F = Σᵢ wᵢ Σⱼ (Aᵢⱼ/bᵢ)² / Σᵢ wᵢ**。

绝对模式 A=J×1 nm；相对模式 A=J×当前探点厚度 d。F不取平方根；绝对的1 nm只是单位尺度，不是工艺精度。展示相对1%影响时，A乘0.01、平方目标乘0.0001。敏感度列与优化自由度分别冻结，固定层可保留在导数列中。

F是确定性的局部导数平方范数，不是制造良率、概率或有限厚度扰动保证。求解器仅用固定F₀作正比例条件化，报告和候选排序仍用原F。**允许光谱指标退化，不等于允许F恶化**：可用候选须完整护栏通过且F≤F₀；只有严格下降才称改善。

## 固定初始光谱的逐点护栏

schema 2的受控模式允许原名义指标未达标的合法初态开始。每个原目标行按稳定ID显式配置非负有限额度，空白不能当零；0.1个百分点（pp）=0.001功率比例，**不是相对0.1%**。

首个完整、计入预算的物理评价锁定初始光谱 y₀，整个运行只相对此同一基准比较。对每一个原波长、角度和偏振条件，额度 δ=δpp/100：

| 原目标类型 | 候选光谱护栏 |
|---|---|
| 仅下界 | y≥y₀−δ |
| 仅上界 | y≤y₀+δ |
| 双边或value | y₀−δ≤y≤y₀+δ |

重叠目标分别检查，不能平均补偿。护栏是精确闭合比较，不加求解器容差或额外余量；单向零额度仍允许向改善方向变化。基准不随接受的候选滚动，不允许逐轮累计放宽。

原规格阈值、严格不等号及value名义容差**不改写**。`nominal_targets_met`与`guard_pass`独立报告，所以可以前者false、后者true。应用还须重算原基准和候选、核对身份绑定，并明确确认未达标事实和退化幅度。schema 1保持原请求身份及重放路径；schema 2的显式`strict_nominal`保留原名义硬约束。旧记录不自动升级。

## 数值改良及边界

F依赖J，不能把一阶光学J误当作∇F。约束使用解析J；目标梯度采用物理厚度界内三点标量差分。schema 2比较中央、前向和后向模板，选择最大合法步长，平手优先中央；实际浮点坐标用三点Lagrange权重，不能假定等距。探点可跨名义或护栏，但不得成为可用候选。没有两个独立合法探点时明确失败，不伪造零梯度；schema 1数值路径不变。

同次运行锁定基准后，只缓存最近一次完整候选约束，按请求身份与精确浮点坐标位串匹配，结果不可写；不同位、不同请求或构造失败不能复用。schema 2两种政策均使用上述FD/缓存，不宣称其数值轨迹与schema 1相同。基准、缓存及构造峰值纳入资源估算，不通过缩网格/删列绕过限制。缓存减少重复构造的测试不等于端到端加速证据。

## 真实计算小例

以下是公开回归小例的运行摘要：单层、550 nm，绝对模式，显式厚度界130–230 nm；合成验证材料折射率为√1.5、基底1.5且k=0，并非实测材料。原目标R≤0.001，退化额度0.1 pp。

| 量 | 初始 | 返回的合法改善候选 |
|---|---:|---:|
| 厚度 nm | 180 | 181.93107728140123 |
| R功率比例 | 0.026741634837114073 | 0.02774163353350815 |
| T功率比例 | 0.9732583651628858 | 0.9722583664664919 |
| F | 2.739356756816342e−7 | 2.622058543346812e−7 |
| 原名义通过 | false | false |
| 固定初态护栏通过 | true | true |

F下降约**4.28196%**，R增加**0.0999998696394 pp**，小于0.1 pp额度。T是另一次同物理核验算的响应，不是新增约束，也不计入该优化运行工作数。此例允许改善敏感度而牺牲受控幅度的光谱表现，**不是原R指标达标**。

运行终态为`partial / solver_guard_rejected`：最后越界trial被拒，返回先前完整、护栏通过且F改善的incumbent，而非把求解器终点当合格结果。优化记录为12个原始forward/Jac条件块、8个probe、4个完整梯度、1次物理评价缓存命中和4次迭代；这些是小例计数，不是性能基准。

本次没有另附完整冻结result科学包。[公开小例测试](https://github.com/ii33/coating-sim/blob/0165323ddabc6579b9d4005b35e7572ff4e974a3/tests/test_film_ideal_sensitivity_v2.py#L71-L93)提供上述设定、合同及正式物理重放验证，但未锁定这些精确小数、终态或工作计数；后者均为执行者运行摘要，不保证跨求解器版本逐位一致，也不应称本目录单独提供完整重放材料。
