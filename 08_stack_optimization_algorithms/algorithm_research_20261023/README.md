# 优化、自动合成与敏感性研究增量 · 2026-10-23

本增量把常规厚度优化、结构自动合成、敏感性/制造稳健性放在同一张证据地图中。它是研究资料同步，不是软件仓库发布，也不替换本专题首轮、第二轮或第三轮冻结证据。

## 先读结论

- **常规优化**：固定材料和拓扑的名义厚度优化、经典起点局部/全局搜索已存在；梯度、RMS或求解器成功都不能代替原规格逐条件验收。
- **自动合成**：统一混合路线已实现结构广筛、真实多位置批针、全部厚度联合精修、删层/同源合并、全原约束精修及独立光谱审计。独立物理批次已使用真实多进程，不等于整个流程并行或线性加速。
- **研究成功与产品边界并列**：已知起点工程精修得到89层名义合格处方；四窗1200秒冷自动合成仍未达标，不能互相替代。
- **敏感性实效并非只有正例**：小AR独立留出167/256改善为253/256或256/256；89层训练worst下降77.88%，但留出通过6/16变为4/16，额外细网格名义失败。不推荐将该候选替换原设计。
- **后续稳健优化仍在开发/建议阶段**：场景云、解析Jacobian、显式原名义硬约束和更完整误差模型是下一步；本增量没有它们已交付或制造良率提升的证据。
