# 完整前向验证与区间决策

## 为什么完整forward不可省

事件导数只描述当前分支的一阶变化，不能替代新板形下的遮挡重建。每次候选都从新b、a重新求投影、活动面、事件、窗口裁剪、可见段及传递积分。参考浮点值用T02冻结闭式原函数得到；梯度由可见段光滑积分加事件边界项得到。

```
∂D/∂p = Σ可见段 ∫ ∂f/∂p dt − Σ内部事件 ΔV f(τ) ∂τ/∂p
```

本轮板的b、a不改变f，故光滑项为零；沉积响应来自移动遮挡边界。Li等通过可见性边界处理不连续导数，本轮采用结构性启发但自行推导一维Leibniz公式，未复现其渲染算法或继承无偏性声明。参见[作者项目与原文](https://people.csail.mit.edu/tzumao/diffrt/)及[勘误](https://people.csail.mit.edu/tzumao/diffrt/errata.html)。

## 有理Darboux前向包络

本轮新增包络不是“64阶和128阶结果接近”产生的经验误差条。每一可见段的端点由编码输入的有理投影精确计算，再等分N个有理面板。q和y在每面板内仿射，q非负，H固定。取qmin/qmax、y²min/y²max：若y过零，y²min=0；否则两端较小平方。上界平方为端点最大值。

```
fmin = A qmin H² / (H² + y²max)²
fmax = A qmax H² / (H² + y²min)²
fmin Δt ≤ ∫panel f dt ≤ fmax Δt
```

这些不等式逐面板以Fraction累加，并对非负源权重求和。最后才把有理上下界向外转换为浮点；转换时检查Fraction(float(q))与q的关系，必要时nextafter。因乘积相关性被放宽，界可能偏宽，但没有把相关性忽略成过窄区间。

本轮默认每可见段64面板，单源最多128面板。一阶导数的数值积分仍为32点Gauss-Legendre估计；有理包络认证的是forward积分值，不是梯度精度或Taylor余项。局部模型的梯度误差会影响提议质量，不能突破最终真实目标包络的下降门。

## 三层资格不能混用

- 编码几何拓扑：有理仿射guard证明，仅针对已编码输入与受限两参数路径
- 编码有限源forward：有理上下界包住有限节点物理核积分；不含连续源离散化误差
- 实机物理输出：尚无测量、材料和机器标定，不具备认证

输入的不确定性必须单列。本实现只接受shadow_boundary_uncertainty_m=0的条件合同；非零时输出unknown、空目标区间和空梯度，不把unknown当透明。未来若有严谨输入包络，可在相同目标语义下传播并进入比较；不得以普通浮点条件包络替代。

## 目标区间与可排名条件

D*须严格大于1e−8 s/m²，否则拒绝病态归一化。先将D区间平移并除以固定正D*，再平方：残差跨零则下界为0，否则取端点平方最小值；上界为端点平方最大值，乘1/2后向外舍入。

比较要求目标定义、源节点/权重、所有非设计输入、数值合同、单位和代码hash一致。两边还必须拓扑可微条件成立、输入不确定性有资格、目标有已知包络。若JA上界<JB下界才判A更好，反之亦然。区间重叠或相等返回unresolved；不能按中心值、较小区间宽度或字典序硬排。

unknown与不兼容合同不同：前者不能排名，后者直接拒绝比较。需要不同求积面板数比较时必须重新在同一数值合同下评价双方，本实现保守地不跨合同复用排名。

## actual与predicted分母

模型残差r+j·z给出pred=1/2[r²−(r+j·z)²]。实现将编码r、j、z转为有理数，保存pred的向外包络。它精确包围“这个已编码局部模型”的下降量，不保证真实Taylor下降。

actual=[JAlo−JBhi, JAhi−JBlo]。若pred未知、跨零或下界≤1e−12，则返回reject，不计算爆炸的ρ；漏事件零步就在这里停止。只有pred严格正且稳定，才计算ρ=actual/pred；ρ下界≥0.1且候选目标区间确定更小时接受。若ρ上界<0.1则拒绝，其余未决。浮点中心值显示改善而区间重叠，仍未决。

阈值均为本轮预声明数值护栏，不是制造公差。trust-region文献中的actual/predicted比值提供算法原型，本轮增加区间和事件门；本文没有验证经典收敛定理的全部前提，也不声称本算法已有收敛率。参见[Powell原文式1.4及第2节](https://optimization-online.org/wp-content/uploads/2010/01/2511.pdf)。
