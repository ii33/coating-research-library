# 材料响应接口来源边界

本轮10条来源只保存原创摘要、精确链接和少量条件化事实。没有版权原文、付费全文、原图或完整光谱表进入本目录。登记表为 `source_registry.json`，逐来源摘要位于 `summaries/`。

## 为什么选SiO2薄膜/熔融硅石基片

SiO2在原12种优先膜材中；熔融硅石不在原4种优先基片ZnS、Ge、K9、ZnSe内。该组合只作资料清楚、能区分bulk/film的接口方法示范，不替代用户的设备、工艺或基片选择。MR-S01/02是bulk证据，MR-S03/04/05是条件各异的IAD实验证据，MR-S08是计算旁证，不能拼成一个已测定的样品。MR-S10仅提供SI定义常数，不提供膜物性。

## 使用规则

- 有来源（cited）只说明资料可追溯；不等于样品、方法、温度、波段相配，更不等于量产合格
- 可计算（calculable）只适用于已定义公式与完整输入，不把公式完备当作输入已知
- 待校准（calibration_required）表示需本机、同材料/基片/层次和测量链建立响应关系
- 未知（unknown）保留null，不填0，不用典型值顶替
- SiO2薄膜ρ不能用Corning或Malitson块材数替代；膜n也不能由块材n与剂量推得
- 只有满足测量条件、量纲、粒种、能角谱、入射法线定义、温度、通量率、剂量历史、化学状态和误差的Y数据才能数值调用。本轮无可直接调用的生产Y(E,θ)
- 厂商剂量建议、MD模拟或ICP再溅射结果均不能补齐Kaufman辅助蒸发响应

## 继承资料
