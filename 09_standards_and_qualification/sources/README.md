# 来源与版权边界

来源查询日2026-10-02。主登记为../data/source_registry.json，标准角色和采用关系为../data/standards_map.json。逐来源原创摘要在summaries，MIL/GB按组合文件保留全部官方URL、状态、日期与缓存限制。

本轮没有保存标准或论文全文，也没有购买/登录受限目录。官方目录/公开摘要只用于身份、范围、状态和可得性核查；不能由其补写未知的操作程序、规范限值或采样表。目录“现行”与合同适用是不同问题。

原文redistribution_allowed=false，原创摘要summary_redistribution_allowed=true。发布必须排除sources/originals全部路径及qa_render、__pycache__。未来原文只有在确认合法保存依据后才能在本地另存；不因可下载而默认可再分发，不用历史合同版本的购买权限扩展对外传播。

DLA公开条目注明Distribution Statement A的事实已记录，但本轮仍仅保存元数据/摘要。部分DLA通知Transient链接可失效，优先从永久Document Details入口查找。GB采标文本存在版权提示；本轮尊重限制，不从第三方下载站绕过。
