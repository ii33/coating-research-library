# 观测数据合同

observation_packet.schema.json为严格JSON结构，evidence_contract.py追加物理/证据语义。一个packet代表同一时钟、坐标、真实表面面积及时间窗中的局部联合能角谱平均，不是全空间/全时间数据库。cells通量已经对能量和角cell积分；energy_ev_particle为每粒子总动能。

actual_unknown.json是缺项计划模板。synthetic_complete.json是纯数学fixture。完整实际记录需要外部证据，不能改origin标签造实测。证据引用应指向实际受控记录；本包不认证其真实或批准状态。

供上游/下游传递的边界：T05给到达元素通量，不给净库存；T04给独立净库存、状态/厚度合同；T10给观测过且经适用响应修正的暴露历史；T07/T08给带完整光学算子的条件预测；T09负责特定用途下的证据与决策规则。T03当前不接收净侵蚀。

观测时间窗只检查有效起止；完整层历史仍需time_integrate的有序、无间隙bin合同。几何位置和法向只描述采样对象，不自动证明它代表运动工件。单位由字段名称固定，不在同字段混用cm²与m²。

所有响应/密度/产额实际值保持unknown；未观察中性份额不能填0；标准不确定度未报道不能填0。结构通过是研究输入检查，不是量值溯源证书或工艺放行。
