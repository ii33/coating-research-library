## 交付物

- 目标函数、约束、参数化与数据协议
- 自动设计优化算法及对照基线
- 制造/装配约束检查、稳健性与敏感性结果
- 基于模拟与实测的校准迭代及失败案例

## 阶段验收标准

1. 目标、约束、输入数据和基线可复现且无信息泄漏
2. 在统一预算下比较解质量、耗时、约束违例和稳健性
3. 给出可制造的设计输出与不可行时的诊断
4. 仿真改善与实际验证分开报告，未实测不得声称生产改善

共同门槛：关键结论能回溯来源与条件；有可复用结果、未决问题、失效/适用边界及下一阶段接口；审查结论有记录。资料完成、仿真验证、实测验证分开标注。研究范围有限，文献不要求无限穷尽；关键缺口不得隐藏。
