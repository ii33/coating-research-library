# 第二轮误差感知双覆盖板优化算法规格

日期：2026-10-02 UTC  
状态：算法合同与候选比较规则；不是实现验收或设备结果

## 1. 问题边界

研究对象限定为两块有限厚、二进制 opaque 矩形分块/格栅修正板。当前geometry API将每个cell表示为独立的有限厚矩形实体，板框为实验室水平固定；open cell不产生实体。尺寸、格点、位姿和制造判据均是研究合同的一部分，不等于已测实机公差或供应商认可值。当前制造器检查两个命名板槽、xmin支承连通性、最小feature、厚度、workspace、边界长度、材料占比及两块完整包络的保守分离；其初始默认数值只供有限合成研究，不应称为真实工艺能力。无板、首轮已有参数板和一个有限厚度扰动板是T02移交建议的首批对照。邻域提案须通过当前制造合同后才能评价。

每个候选分别追迹蒸气与离子射线；两通道使用各自的源、权重、能量和率历程。两块板均进入相应通道的遮挡并集。不得跨通道复用遮挡矩阵、核或缓存。正向接口应继续按T02移交返回逐点 `N_net, h, D, U, R, ε, τ`，有效面积/无定义点、源/时间/空间工作量、见证极值、误差状态、几何适用域及依赖哈希。

本规格只定义如何在给定的有限候选与明确场景集合上提出、评估、比较和保留设计。T02 当前正向 oracle 仍为 partial；结果只能用于有界算法研究，不能生成实机加工尺寸、设备设定或生产资格。

## 2. 冻结量与优化目标

在运行前冻结候选几何和哈希、制造可行集合、有限加权RayBundle、面积/时间权重、两通道输入、误差来源、目标、有限不确定场景集、数值策略和预算。不得在比较中途改阈值或隐藏场景。当前RayOracle不是从连续物理输入生成ray的通用前向接口，而是消费调用方提供的有限、非负、已乘源/时间权重贡献；ray bundle只涵盖给定的点—时刻组。

沿用T02定义：净原子注量 `N_net`，厚度 `h=N_net/n_atom`，离子注量 `D`，入射动能面密度 `U`，`R=D/N_net`，`ε=(U/e)/N_net`，`τ=∫1(Γ_i>0 且 Γ_net=0)dt`。当前实现的具体多目标向量为 `h_target_max_deviation` 与离子目标偏差：候选者逐点评估相对 `h_target` 的最大样本/见证偏差，以及在 `D` 或 `ε` 中二选一的目标相对偏差；两者均不是连续片最大值证明。当前接口以面积平均 `h/无板平均h` 形成 throughput，并用其下限作约束。可选硬约束包括 `max_h_relative_deviation` 及 `ion_allowed_interval=(lo,hi)`；后者对所选的 `D` 或 `ε` 逐点生成上下界约束。这里D/ε二选一，不自动代表R区间，R仍有单独定义及分母资格规则。T02 handoff指出 h 相同而 D×2 的情形必须是回归；不以更大的离子指标自动奖励候选。吞吐下限是硬约束。无板候选是必要基线。

若目标区间、吞吐下限或 `R/ε` 所需的定义/误差预算未提供，则相关资格为 `unresolved_missing_contract`；不临时填入首轮合成例的示例阈值。若继续使用 `Γ>0` 定义 τ，应将其单独标为未达/待定，除非连续源支集与事件已经由可接受的 oracle 处理；不得改成未说明的工艺剂量阈值。

## 3. 候选评价与不确定性类型

每个候选在固定的训练/比较集与独立验证集上求值，候选缓存键至少覆盖：两板各自完整掩模与位姿/厚度包络，工件点与面积权重，蒸气/离子源各自位置、尺寸、法向、角分布/指数、率与能量历程，gate/运动时钟与初相位，材料净留存/密度假设，数值网格、积分配置、代码与数据哈希。任何改变即失效；某一通道/板改变不能借用另一通道/候选的遮挡缓存。

对每个待比较量分别保留API状态，不合并为一个模糊的“误差条”：

1. `bounded_conditional`：区间端点覆盖已经声明的有限bundle、外给误差半径/conditional假设和冻结数值合同下的量，可在相同 `oracle_signature` 下按区间规则比较并报告“条件有限候选前沿”。它不是连续T02真实物理真值或生产证明。
2. `estimated`：至少一个误差轴只有估计值，如T02源/时间求积的网格差、异族差或留出误差。可用于提案优先级/诊断，但当前搜索器不会据此判可行或Pareto支配，而返回 `inconclusive`。
3. `unknown` / `partial`：端点未知或某误差源未覆盖。包含三态可见性unknown传播、全点τ事件缺少连续支集合同、分母跨零、或输入合同缺失。不得当零或默认透明。

可把 `estimated` 结果显示为“筛查区间”，但字段和排序必须带证据标签；不得把经验网格差改称数值上界。T02 v0.3报告的点2事件带是 conditional 数值包络，binary64三角函数、凸包和 `1e-11 m` guard 尚未经严格舍入验证；点12更紧离子参考未运行。RayOracle只把误差半径加到已有有限和上，不能自动补出缺失的 source/time/space、kernel、input 或 model 误差；整个高精度前向 oracle仍 partial。

## 4. unknown 与可行性传播

有限厚几何采用 `blocked / clear / unknown` 三态。`unknown` 不实现布尔转换，不默认为透明，也不在积分中静默丢弃。对非负离散贡献 `w_k`，三态透射因子分别为 `[0,0] / [1,1] / [0,1]`，求和得到该有限节点集合上的透射包络；该包络只描述该项可见性不确定性，不能替代总源/时间/核误差预算。多板联合遮挡仅在至少一板确定阻挡时为 blocked；所有板都确定 clear 才为 clear；其余保留 unknown。

把每个约束写成统一方向 `g_k(θ)≤0` 并报告 `[g^L_k,g^U_k]`：

- `feasible`：所有约束状态均为 `bounded_conditional`，区间已知且每个 `g^U_k≤0`
- `infeasible`：至少一项可用的条件区间 `g^L_k>0`
- `unknown`：其余情况，包括 estimated/unknown、几何或指标区间跨阈值、未提供阈值或所需前向量尚未闭合

只有feasible候选参加当前同一有限合同下的区间目标比较，结果命名为“条件有限候选前沿”，不是一般化证书。unknown候选留在 unresolved 队列，不进入feasible archive。任何基于保守遮挡下界的 throughput/比值/τ 都需单独证明方向性；几何层面的“把 unknown 当挡板”并不保证比值或时长保守。

## 5. 区间支配与 inconclusive

目标一律先规范为最小化。对两候选 A、B 的 `bounded_conditional` 目标区间 `[L_{Aj},U_{Aj}]`、`[L_{Bj},U_{Bj}]`，仅当双方均feasible，且对每个目标 `U_{Aj}≤L_{Bj}`、至少一项严格小于时，才称A在该有限条件合同下 **interval-dominates** B。这个端点条件是保守的充分判据；不满足不等于相等。任何目标为 `estimated` 或 `unknown` 时，当前API直接返回 `inconclusive`，不凭点估计、代理或更细网格差删去候选。

区间交叠且允许排序改变时，返回 `inconclusive`，保留两者并登记局部信息加密请求；若部分目标有相反方向且各自已分离，则当前实现返回 `tradeoff`，不以标量化隐藏。估计中心差 `|m_A−m_B|≤u_A+u_B`（两侧半宽/误差估计）时，对该标量排序必须 `inconclusive`。如果 `u` 来自经验估计，应写成“按现有估计无法分辨”，而非宣称数学上不可分辨。不得以中心值更优、低网格、代理置信带或候选枚举先后打破平局。

有限场景稳健性只对冻结的集合 `S` 作出：最小化目标的场景最坏端点为 `[max_{s∈S}L_{js}, max_{s∈S}U_{js}]`。当前API以一个bundle/oracle签名评价同一冻结输入，并不自动构建多场景稳健目标；主调用须逐场景单独运行并保持输入可比性，再按预先冻结规则汇总。这不代表 `S` 外或所有真实设备不确定性。若需要概率置信区间、均值/方差效用或机会约束，须有已说明的数据模型，不能把 deterministic enclosure 和 statistical CI 混同。

比值只有在分母全区间严格正时才定义。例如 `N_net=[N_L,N_U]` 且 `N_L>0` 时，才可用向外舍入求 `D/N_net` 或 `(U/e)/N_net` 的诊断外包络，并记录依赖关系；若 `N_L≤0`，资格标为 `undefined_or_unbounded_denominator`、优化状态unknown。若 `N_L>0` 但区间宽度 `N_U−N_L≥N_L`，当前API标记 `ill_conditioned`：诊断 bounds 保留，但 `R/ε` 的资格状态降为unknown，不得为病态分母提供优化奖励。该病态判据并不把比值转换成产品通过结论。

## 6. 比较驱动的局部加密

只有加密能收窄影响候选可行性/支配结论的误差源时才继续；在日志中将每次动作映射到候选、场景、通道、源子域、时间段、工件点、几何分量和预算消耗。优先处理对待判排序区间宽度贡献最大的项，不整体盲目加密。

- **source**：沿各自通道分开细化源面积节点/面板；优先 source-space 中候选两板可见性变化、狭窄掠射、或通量贡献显著的子域。遇已知不连续显式分段。低成本多一倍网格或求积族差只能作诊断；若没有解析/经验证余项或区间积分，仍是估计。
- **time**：在 gate、rate 结点、已知周期/频率、遮挡进入/退出事件处切段；用不整倍时间级与相位错开的留出对照降低 alias 风险。T02已展示同错alias可让相邻网格高度一致但误差很大。未知带宽、未知窄脉冲不能靠有限抽样排除；缺率历史/频带合同就停止并报 unresolved。
- **space**：提升面积求积分辨率，并另留未参与搜索的边缘、环带、扇区、板边投影附近与残差见证点。离散 PV/见证点极值不是连续面严格最大值；连续最大值若要认证须独立上界/几何分析。
- **geometry**：对 unknown 的局部不确定管/近平行侧壁/板边投影单独加密精确有限求交或区间几何。未知不能通过采样稀有度估计为零。面、边、端点接触须沿冻结 v0.2 开线段/有限厚/零厚例外约定处理。
- **mask search**：候选可由有上限的二进制翻转/板厚/位移邻域生成，也可由 `discrete_space()` 惰性枚举有限的二进制掩模×位置目录×厚度目录组合，再经制造合同筛查。`max_candidates`截断只限制搜索预算，不能宣称global optimum；只有未截断遍历目录内完整有限笛卡尔空间并完成评价时，才可讨论“该离散目录内”的穷举结果。当前搜索已记录15候选fixture中13次评价、2项制造拒绝的有限结果；决策仍inconclusive，不能作为算法质量或物理真值。代理模型（如有）只能改变候选评价顺序或提出候选，实际结论只由相同冻结oracle评价决定。当前 `refinement_requests()` 只返回含轴/点/时窗的诊断请求，不会自动生成新RayBundle或默默提高fidelity；任何source/time/space加密须作为新的、有哈希和预算的bundle/job。

以下任一条件停止对应判断并标 unresolved：预算耗尽；输入/率支集不满足合同；unknown 比例/量区间仍跨目标界；分母跨零；已知源/时间积分告警；目标区间仍交叠；有限点 PV 的连续极值未证明。停止后保留 Pareto 候选与 undecided 队列，不强行输出单一获胜板。

## 7. 交付字段与验收边界

每个候选应保存掩模/几何及制造约束的哈希、候选生成来源、缓存键、两通道分别的 ray/source/time/point/component 工作量、逐点通量与单位、面积权重、当前 `h_target_max_deviation`/`ion_target_max_deviation`/throughput 与区间类型、`ion_allowed_interval` / `max_h_relative_deviation`约束区间状态、`ratio_conditioning`、`N_net`分母跨零无定义点、有限scenario解释、source/time/space单轴和交叉复核、网格/相位/留出对照、停止原因与代码/依赖哈希。逐点样本/见证偏差不等于连续极值证明。

回归必须包含：两块板对两通道分别生效；同一两块板的 opaque union 仍保持三态；无板对照；同样厚度 `h` 但离子总率加倍时 `D` 与 `U` 加倍的 T02 反例；几何 unknown 不能变透明；`N_net` 区间跨零时 `R/ε` 不得返回可排序有限值；目标差小于数值不确定带时不应删掉任一候选；空或失败的设备任务保留 `not_run/partial`。

## 8. 有界材料输入衔接建议

后续可做一个**单一材料对的响应/输入映射契约**，复用T04已完成材料卡及其证据记录，不重开全材料文献综述，也不虚构未测的实机配方。范围仅选一个清楚标牌号/工艺条件的薄膜材料与基片组合，写版本化字段映射：材料身份与批次/工艺证据、有效膜密度及不确定度、净留存/再溅射输入状态、角向响应状态、密度到 `N_net→h` 的单位转换、`D/U/R/ε`的可计算条件、未定义量策略、source/input/model误差轴及RayBundle provenance。字段没有一手记录时保存 `unknown`，不填0，不用块材密度代替薄膜有效密度，不从T04公开卡推断本机角向留存。

验收只需一个示例schema、单对材料的映射/缺项表和小型非物理fixture检查，目标是明确哪些参数可输入、哪些仍未知；不跑沉积试验、不做全材料比较、不修改T02/T03误差界、不声称完成校准。这样为将来接入完整正向模型提供可审阅接口，同时不延迟原计划中的T05蒸发源专题。
