# 拓扑距离与局部信任域

## 有限厚板事件

从源s射向靶点，在板近/远表面z处的左右边缘投影到靶平面为：

```
B±,z = s + (b ± a − s) H/z
L = min(B−,near, B−,far)
U = max(B+,near, B+,far)
τL = (L − x0 − u)/v − c
τU = (U − x0 − u)/v − c
```

对v<0按时间重排两个事件。它们包围遮挡区间；与过程窗口求交后得到可见段。厚板使用near/far候选面，不能用中面薄板替代。active_z和lower/upper是事件身份的一部分。

若当前胜出面固定，τ对(b,a)仿射。所有面的B差也仿射。这给出本轮的零余项条件：H、z、v、源位置和运动时钟均固定，仅b、a变动。若同时变H或旋转板，H·b、H·a等交叉项或几何非线性出现，下面的零余项证据不能沿用。

## 一般一阶启发式

把一个拓扑安全条件写作h(p)>0。沿候选方向d：

```
h(p+αd) ≈ h(p) + α ∇h(p)·d
若 ∇h·d<0，αheur = γ h(p)/[-∇h·d]，0<γ<1
```

h包括事件到t0/t1的有向距离、相邻事件的间距、胜出面与候选面的差、横截速度及角度截断。取最小α只是启发式。如果没有余项界，即使γ=0.8也不能声称绝不跨分支。最小反例为h(α)=1−α−4α²：一阶规则取0.8，而真实h(0.8)=−2.36；第一次零点约0.390388。

若有可追溯的Hessian/方向二阶界M，使|余项|≤Mα²/2，则充分条件为h0+αh1−Mα²/2>0。多个条件均须满足，M必须覆盖整段与输入包络。也可直接以区间扩展证明每个h在路径或参数盒上严格正。未提供M或区间证据时只能保留heuristic标签。

## 本轮可核算的零余项证据

本实现不用浮点Jacobian冒充精确系数。先将已编码二进制浮点输入转换为Fraction，再由投影代数重建每个h0和两维系数。这里“精确”仅指该编码模型，不是输入参数恰好等于真实机器。

1. 活动面：lower使用另一面减胜出面；upper使用胜出面减另一面；均减face_guard_m。两类必须严格正
2. 端点：记录每个事件当前位于t0/t1的哪一侧，沿该符号分支用有向距离减event_guard_s。包括窗口外的事件，防止从外部进入时漏掉
3. 事件序：将所有有限节点事件排序，对相邻对要求τj+1−τj−2 event_guard_s>0。同节点必检，跨节点共同事件也保守拒绝；后者可能无需拒绝，但本轮没有放宽
4. 板半宽：a>0。它同时避免退化板边界合并
5. 横截：v固定且|v|>transverse_floor，零/近零速度返回未决
6. 角度：源、靶法向固定，H>zfar>0保证两余弦均严格正；b、a不会改变射线方向。因此本轮角度截断由不变量排除。该论证不覆盖变法向或零高度

路径p(β)=p0+βΔp，β∈[0,1]。每项h(β)=h0+βdh，其最小值严格等于min(h0,h0+dh)。代码为每项保存有理数最小值及向下舍入显示值。所有最小值>0才返回encoded_affine_segment_certified。这保证同一活动面及事件序，余项恰为零。

提议时先用γ=4/5裁剪到最近guard；随后实际candidate被浮点编码，代码重新对“原编码点到实际新编码点”整段认证，避免把理想实数步的结论错套到浮点落点。认证失败便不求奖励或继续外推。

## 信任域并不只看拓扑

设计量缩放S=diag(0.002m,0.002m)，δp=Sz，||z||2≤Δ，默认Δ=1。缩放把两轴的步量变成无量纲。拓扑安全只保证导数的分支有意义，不保证残差线性模型足够好。候选仍必须重算完整forward和目标区间，并通过actual/predicted检查。

缩小/扩大Δ只产生下一步建议；下一次必须重新计算事件表、完整forward及Jacobian。跨过事件的步不能拿旧方向的一阶Jacobian继续线性外推。非光滑拓扑切换处可能仍有可用的单侧或广义导数，本轮统一未决，未实现那些扩展。

事件时序对线性化的重要性与混合系统文献一致，但本轮累积沉积量没有机械冲击reset，不移植其saltation矩阵公式。参见[Kong等原文III节](https://arxiv.org/html/2306.06862v3)。
