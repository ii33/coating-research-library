# Bounded validation protocol

Timestamp qualification: numeric gates and tiny-check scope were fixed in implementation before the necessary run; this document consolidates that record after execution. It is not a separately timestamped prospective registration.

Protocol scope: one frozen two-parameter slab family. One event-aware local trial and one matched omitted-event trial; necessary tiny adverse cases. No global search, no old continuous-source rerun, no production modification.

Acceptance for the new encoded-model result requires all of: exact affine segment guard success; new full forward; qualified input/error status; nonoverlapping objective intervals; predicted reduction lower bound >1e−12; ratio lower bound >=0.1. Equality/overlap/unknown are not wins. No count of successful tests grants physical certification.

Planned tiny checks: reference value and derivative decomposition; sign reversal at target translation; pure event half-width; active face/endpoint crossings; exact clipping; unknown geometry; overlapping objective; pathological ratio and target denominators; nonplate parameter refusal; reverse velocity; nested finite-source Darboux enclosure; complete cache binding. These were exercised at small scale. No repeated parameter tuning was used to force acceptance.

One narrow independent check is permitted, with fixed scope covering topology, rational forward and refusal semantics. A repair, if needed, receives only necessary author replay; the formal requested model chain remains pending. Independent review scope and content hashes are retained.

High-work default remains plan_only. Any later explicit run needs restored authorization and device quota/permission, a copied plan and fresh external output. At most 18 trial calls and 10752 rational panel upper budget in the default plan. Stop at declared resource limit, cancellation, unresolved result or completion; no automatic densification. Current high-work execution count is zero.

Preserved inherited limitations: historical point12 partial, point2 non-strict conditional evidence, continuous-source validation absent. This new tiny family cannot fill those gaps.
