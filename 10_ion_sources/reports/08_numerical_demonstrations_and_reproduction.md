# 8 · 可运行算例与数据质量验证

所有输入为合成假设，仅演示量纲、分母、空间映射、计量缺项和数值收敛；没有真实机台数据、材料拟合或生产最优值。电压/电流例数不是操作建议。模型不调用任何设备控制接口。

## 8.1 基线算例及手算核对

设基片平面已校正正离子电流0.48 A/m²，粒子数分数85%单电荷90 eV和15%双电荷180 eV；这是虚构Ar混合束。平均电荷1.15，平均粒子能103.5 eV。假想化学计量SiO2-like膜净增长0.35 nm/s、实际膜密度假设2.1 g/cm³、式量60.0843 g/mol、每式单元3原子。

| 派生量 | 结果 | 检查 |
|---|---:|---|
| 正离子粒子通量 | 2.60515×10¹⁸ m⁻²s⁻¹ | j/(1.15e)，不是j/e |
| 净总原子通量 | 2.21003×10¹⁹ m⁻²s⁻¹ | ρrN_Aν/M |
| 离/净原子比 | 0.117878 | 同一基片平面、同一时间基准 |
| 入射动能流 | 43.2 W/m² | 本特殊同电位降设定下也等于j×90V |
| 每净总原子能量 | 12.2004 eV/atom | 每式单元则36.6013 eV，不能混名 |
| 600s离子注量 | 1.56309×10²¹ m⁻² | 1.56309×10¹⁷ cm⁻² |
| 同期入射动能面密度 | 25920 J/m² | 不等于工件已吸收全部热 |
| 净厚度 | 210 nm | 不证明入射蒸气所代表厚度相同 |

若错误假设100%单电荷，粒子通量和离/原子比高估15%。本例因E与z同比例，j×电位差可保持动能流不变，这说明“能流算对了”不证明粒子数/化学剂量也算对。

## 8.2 荷交换算例

采用完全合成的σ=10⁻¹⁹ m²、P=0.01 Pa、T=300K、L=0.5m，仅作一个无散射、前向能量保留的单次荷交换模型。程序把原始能量粒子数拆成快离子和快中性，检查二者总和守恒。慢离子产生后如何被杯收集不在模型内，不能由结果预测实际电流读数或材料效应。

它反驳的仅是“电荷减少必然等比例减少全部动能处理”。本轮没有给Ar/O2真实截面、碰撞输运或电子能量分布，因此不生成某机可接受压力/距离组合。[物理背景IS-04]

## 8.3 再溅射分母与零生长边界

设入射成膜原子10¹⁹、辅助粒子2×10¹⁸ m⁻²s⁻¹，常数有效溅射产额假设0.7 atom/particle，净流为8.6×10¹⁸；离/入射原子比0.2而离/净原子比0.232558。若产额假设变6，净值−2×10¹⁸表示侵蚀，程序不会把负净流做成成膜归一化比。

恒定Y与全留存只是代数示例，未包含反应气体、复合材料元素选择性、角度/能谱、表面状态和演化。因此不能用本图找真实溅射阈值。

## 8.4 空间非均匀与运动

301×301方格上的半径12cm圆形区域，采用移心高斯j和较平缓沉积率。70,679个等面积网格点显示：净速率RMS相对不均匀约6.09%，离/净原子比却约26.43%；每原子能量在约5.63–18.13eV变化。两者都只是合成场；不是实机均匀性指标。

面积平均的局部比为0.120018，而两面积均值之比为0.121874，二者不同。具体应选哪一个取决于问题：局部性能需要局部R；总通量预算可用积分比。任何单平均都不应掩盖极值/盲区。

运动算例用两个数学周期和连续遮挡函数构成180s轨迹，对j和净原子通量同步积分。100至3200时间区间的中点求积，对12800区间参考的R相对差由8.03×10⁻⁵减至7.41×10⁻⁸；这是数值收敛，不是物理模型误差。真实硬挡板有不连续边界，应采用事件切分或额外加密，此平滑算例未证明所有遮挡几何都收敛。

简单两等时段反例：Γ_i=(1,1)、Γ_net=(1,9)，整层比=0.2，局部比算术平均≈0.5556。若某段只有离子无沉积，仍可累计整层注量，但不定义该时刻有限离/原子比。

## 8.5 不确定度与热负载

取j、r、ρ、平均电荷的对数标准差6%、4%、3%、2%，r和ρ相关系数−0.5，其余互不相关。60000次、固定seed1042对数正态抽样得到R的变异系数约7.308%，解析对数正态值7.290%，一阶近似7.280%；95%相对分位约0.867–1.153。它验证实现与给定统计假设一致，不含中性粒子、杯偏差、几何或模型误差，不能当真实总不确定度。

独立给吸收热功率3W、热容24J/K、热导0.15W/K，则180s集中参数温升13.507K；绝热假设22.5K。没有从离子束总电流推导这3W。模型忽略辐射、空间梯度、温变物性、界面接触和蒸发/反应热，只作热预算边界演示。

## 8.6 复现

在本专题目录执行：

    python -m unittest discover -s tests -v
    python benchmarks/run_benchmarks.py
    python benchmarks/plot_figures.py
    python models/check_package.py

分享阅读包不含local-only原文，最后一条应改为：

    python models/check_package.py --reader

reader模式只跳过原文存在/哈希检查，其余结构、来源引用、冻结依赖与数值一致性检查保持不变；本地研究库默认模式仍核原文。

核心models/ion_assist_reference.py仅用Python标准库；benchmarks需NumPy/Matplotlib，schema测试需jsonschema。记录实际版本于data/runtime_versions.json。环境缺依赖时不自动安装或改变用户系统。

图为本库原创：source_functional_blocks.svg是概念功能图；synthetic_spatial_fields.svg为四类二维图；synthetic_diagnostics.svg为荷交换、再溅射、求积、热负载。PNG已逐张视觉检查，可读且无裁切。图中英文用于避免字体缺失，物理解释见本章。

## 8.7 能声称通过什么

数值测试覆盖单/多电荷、分子原子数、负数/非有限输入、能量差、零束/零沉积、快中性贡献、再溅射负净流、积分比与平均比、误差协方差、热模型极限、投影、schema和来源/材料完整性。最初一个大通量测试误用绝对小数位比较造成浮点失败，改为相对容差后重新运行；没有修改物理结果来通过测试。

通过测试只证明这些明确假设内的实现和结构检查，不表示已验证Kaufman真实能谱、材料性质、工艺窗口、设备安全、量产重复性或任何标准资格。
