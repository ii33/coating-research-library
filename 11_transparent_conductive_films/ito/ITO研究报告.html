ITO 透明导电膜 从蒸镀工艺到仿真模型

阶段一有界研究版 · 2026-10-03 · 未经本机台实测校准

结论：先把“源与输运 → 膜材料状态 → 电学/光学观测”拆成可验证的模块。ITO蒸镀能够形成透明导电膜，但源料配比不能代替膜组成，氧流/温度不能唯一决定载流子与迁移率。最短可靠路径是以实际膜厚、方阻、Hall与T/R/椭偏数据闭合电光模型，再标定工艺到膜状态。

1. 可以采取的结论

  1. ITO蒸镀不存在可脱离设备搬用的单一氧流量/温度配方。 本版得到6篇可用原始实验全文、1篇有内部矛盾的全文和1份成套机构工程报告，另有1份辅助机构年报；已将设备、氧化方式、厚度、测试口径分开。它们支持建立设备内的局部响应模型，尚不足以建立跨设备的通用定量预测。
  2. 把源料、蒸气、到片通量、最终膜组分分开。 “90/10 ITO”必须注明金属合金还是In₂O₃/SnO₂质量配比，不能直接替换成膜中Sn阳离子原子分数。当前核心全文没有足够的源料耗尽—蒸气分馏—膜组成随时间数据，分馏系数不可凭经验填写。[ITO-C04, C09]
  3. 先保留完整样品配对再比较性能。 厚膜低方阻、薄膜高透射、另一片高载流子浓度不能拼成“最优样品”。光学数值还要区分T₅₅₀、400–700 nm均值、谱峰Tmax、相对裸玻璃T。[ITO-C08, C10]
  4. “离子辅助”不是一个可互换的设备状态。 Ebert低能活化氧、End-Hall、带栅离子束、70 V/数百A的HDPE弧源，其电源设置、能谱、通量和热负载含义不同。电源电压不能直接写成到片单能离子eV，放电电流不能直接换成到片离子剂量。[ITO-C05]
  5. 退火和增氧都可能存在拐点。 Pokaipisit的500 nm膜空气300°C×1 h改善，但350°C回升；Rao的80 nm低温膜经200°C×4 h空气退火后Rs从65增至1100 Ω/□。两者并不矛盾，起始膜和热历史不同。[ITO-C02]

本报告中的“窗口”均是来源的实测扫描范围或离散样品，不是保证达标的通用工艺建议。未做本项目实测。

5. 源组分、氧与轰击：进入模型前的变量定义

5.1 质量分数换成阳离子原子分数，只做计量换算

对氧化物混合源，w为SnO₂质量分数：

x_Sn,cation = (w/M_SnO2) / [(w/M_SnO2) + 2(1−w)/M_In2O3]

按M_In₂O₃=277.633、M_SnO₂=150.708 g/mol：95/5、90/10、80/20氧化物质量配比分别约4.624%、9.284%、18.717% Sn阳离子原子分数。金属In/Sn=90/10 wt%则约9.704%。这里均为源料计量值，非成膜值；“全原子at%”还包含O，分母不同。推导采用标准原子量近似、保留有效位数，不表示源料分析精度。[ITO-C04, derived]

Yamaguchi公开片段以95/5 wt%氧化物源做实验，报告气氛与离子照射影响XPS的Sn⁴⁺组分。它说明需要测膜，但不提供本版可用的源→总Sn/In传递系数。Jan1987机构摘要的Sn:In金属质量比3:1更不能读成“膜中75% Sn”；蒸发分馏和投料口径必须读全文才能判断。[P13, abstract/conclusion snippet；P09, institutional abstract]

5.2 氧流量与氧到达通量分开

平衡中性气体的表面碰撞通量可作为低阶参照：Γ_O2 = p_O2 / √(2πm_O2k_BT_g)。p必须为分压、T_g为气体温度；sccm是标准状态体积流量，缺有效抽速、温度、气体分布、离解/反应消耗时不能唯一换成分压或活性氧通量。原子氧、分子离子、快中性粒子需额外物种项。

建议模型把氧供给拆为：中性分子供给、活性物种份额、表面反应/再蒸发及氧消耗。用实测pO₂/残余气分析加表面组成来校准，不直接以“某篇12 sccm”作为物理边界条件。此处为物理量定义和待验证建模建议，不是对当前论文的拟合结果。

5.3 离子参数至少保留四层

  • 控制量：放电电压、电流、气流、离子源型式和角度
  • 到片量：能量分布f(E)、电流密度j_i(x,t)、离子/中性物种比例
  • 积分量：离子剂量D_i=∫Γ_i dt；能量剂量D_E=∫Γ_i〈E〉dt
  • 生长竞争量：离子/沉积原子通量比Γ_i/Γ_dep、每沉积原子能量Γ_i〈E〉/Γ_dep

P02的体等离子体密度10¹³ ions/cm³不是流量；P01的阴极kV不是其低能氧到片eV；P03放电V/A缺到片能谱；P06甚至没有提供离子源电压/电流。因此本版本不拟合统一“离子能量—ρ”曲线。[P01 §2；P02 §3.1/3.4；P03 Methods；P06 §2]

通量到 ITO 材料状态的可追溯链

版本 0.1，2026-10-03。本文是条件模型设计与原创守恒推导，不是机台配方，也未接入产品运行时。

1 先把四个组成分开

源料氧化物质量分数、源表面剩余组成、气相粒子组成、薄膜元素/占位组成是四个不同对象。材料标签 In₂O₃/SnO₂ 90/10 wt% 不能写成 Sn 10 at%。定义 w 为 SnO₂ 在两种氧化物中的质量分数，摩尔质量 M_In2O3 与 M_SnO2 均用 kg/mol，则理想配料的阳离子比例为

x_Sn,cation = (w/M_SnO2) / [2(1−w)/M_In2O3 + w/M_SnO2]。

取常用原子量 In=114.818、Sn=118.710、O=15.999 g/mol，90/10 wt% 对应约9.28%的 Sn/(In+Sn)；这是配料算术，不是薄膜成分或电活性 Sn 比例。氧也在分母中的“总原子at%”另算。XPS表面、RBS体平均、EDS相互作用体积及供应商氧化物质量配比不能不加口径直接比较。原子量示例只用于工程单位核查，不作为同位素精密计量。

蒸气不能被默认为完整 ITO 或 In₂O₃ 分子。Bischof等的纯In₂O₃ KEMS实测识别In₂O、In、InO，In₂O为主要组分；其铱坩埚小孔平衡逸出装置与开放式反应电子束蒸发不同[INT-S01，Abstract、§4.3.1；装置见§2、Table 3]。NIST独立登记In₂O气相物种及相关质谱出处[INT-S02]。这些证据支持“物种应显式建模”，不直接给出本机Sn物种比例。

还要区分“解离蒸发”与“混合料分馏”。纯In₂O₃可解离成含铟亚氧化物与氧，整体元素收支仍可能相容；ITO源中In/Sn相对蒸发与源耗尽漂移是另一问题。不能仅见亚氧化物就证明所有条件下In/Sn不共格。KJLC官方明确提醒两氧化物不同蒸发行为造成成分控制困难[INT-S03]，具体分馏大小须时序成分测量。

2 三种平等的源模型

已标定通量模型

从独立膜厚/组分见证片、QCM原始频率、固定位置、源寿命阶段拟合物种或元素通量随时间的分布。输出局部到达 F_e(t,x)，单位 atoms m⁻² s⁻¹；保留协方差、来源和插值有效域。若只知道总质量流且Sn/In未知，输出partial，不伪造各元素通量。这是最适合近期工程校准的选项。

有界物理参考模型

物种s的Hertz–Knudsen边界示意为 Φ_s = α_s p_eq,s(T_src,a_source,p_O2)/sqrt(2πm_s k_B T_src) − α_back,s p_back,s/sqrt(2πm_s k_B T_gas)。温度K、压力Pa、单粒子质量kg，输出particles m⁻² s⁻¹。p_eq必须来自适用相态的活度和反应平衡，蒸发系数与反凝结系数不能未经依据取1。混合源需联立各元素库存、反应及热平衡，不能把纯组分蒸气压按质量分数线性插值称为热力学结果。

源能量账可写 C_eff dT_src/dt = P_abs − Q_radiation − Q_conduction − Σ_s L_s Ndot_s − Q_other；L_s与Ndot口径分别J/particle、particles/s，或统一mol。束流设定功率不是已知吸收功率，电子束扫描、孔洞、熔池位置、坩埚反应均影响场。没有源温、活度、系数和热边界时，此模型只解释敏感性，不输出可信绝对速率。参考实现本轮不求解未知热力学常数。

直接实测输入模型

把每时间bin的工件入射或净留存元素通量作为输入，直接推进库存；适合独立检查下游材料与光学算法。不要求每次都反演源模型，但不得把输入为实测净量的成功计算叫“由源功率预测膜”。三个选项并列保留，没有新模型替代旧模型的暗示。

3 几何输运与氧气

若 Ndot_s 是遮挡前向半球总粒子发射率，归一角函数 f_s(Ω) 的半球积分为1，则点源局部通量为 Φ_s(x)=Ndot_s f_s(Ω) cos⁺θ_inc V/r²。f单位sr⁻¹，接收通量按真实面积计；cos接收投影只乘一次。有限源应对源面和工件运动积分，各物种可有不同角分布。不能把被挡通量重新归一而消灭遮挡损失。

碰撞可先用λ与源基距离L对比诊断。等温同种硬球气体的λ=k_B T/(sqrt(2)πd²p)只是筛查近似；不同蒸气/背景气的输运平均自由程应使用碰撞截面和相对速度。对无碰撞直达份额 exp(−∫ds/λ_s) 的估计，不包含散射回来的粒子，更不含反应或等离子体电场。Kn不足时升级碰撞输运，不靠重新拟合cos指数把组成与角散射混为一谈。

平衡中性O₂撞击率 Φ_O2=p_O2/sqrt(2πm_O2 k_B T_gas)。源区、基片附近、压力计位置可不同；sccm流量不可直接换成工件分压。2Φ_O2为氧核撞击率，不是留存率。活性氧、O⁺、O₂⁺各自建账，远离热平衡时不能把所有物种塞回一个气温。分子解离需核数守恒，电荷态只影响电流转换，不改变核数。

建议保存Ψ_O = 氧核入射率/(In+Sn核入射率)作为暴露坐标，但它不是膜O/(In+Sn)，更不是“氧空位浓度”。即使Ψ_O很大，黏附、解离、表面交换和再溅射仍可限制摄氧。

4 状态推进

对元素e的面库存 A_e，

dA_e/dt = Σ_s ν_es S_s Φ_s + R_e − D_e − Σ_i Γ_i Y_e,i + J_interface,e。

A为atoms/m²，ν是每粒子的核数，所有右端为atoms m⁻² s⁻¹。S∈[0,1]为定义清楚的入射留存，不用S>1吸收氧反应增重；R为外部气体/反应补入，D为脱附，Y是每入射离子移走的该元素核数。元素通量相同不代表相态相同。若某步库存小于零，停止并转换到膜耗尽/基片暴露模型，不能裁成0后继续。

有效膜厚通过质量账得到 h=m_A/ρ_eff，m_A=Σ_e A_e M_e/N_A。状态密度改变时 dh/dt=(dm_A/dt)/ρ_eff − h(dρ_eff/dt)/ρ_eff；退火致密化可在质量不变时减薄。QCM软件预设密度、源料压片密度和晶体理论密度不能替代ρ_eff。多层不同ρ需分别计算。未知污染/氢/氩贡献使质量账partial，不要把只追踪In/Sn/O的模型叫全元素闭合。

状态向量建议包括组成、密度、相分数、晶粒/晶界指标、孔隙、缺陷/补偿、应力、温度与时效。每个量具有测量算子；没有独立辨识的变量不必全部自由拟合。电学闭合由下游n_e、μ_dc或实测σ提供。Sn替位激活、补偿、间隙氧和晶界俘获使源Sn比例与自由载流子不一一对应，氧空位也不保证两个可迁移电子。

3. 载流子、缺陷和电学模型

3.1 不把化学计量直接当 N

一般电中性条件写为：

N + Σₐ |Zₐ| Cₐ⁻ = p + Σ𝒹 Z𝒹 C𝒹⁺

这里 C 是指定电荷态的缺陷浓度，不是总 Sn 或总氧缺陷量；中性复合体不直接出现在净电荷一侧，却可能影响散射。电荷态依赖费米能、温度和局部结构；还需区别自由载流子与局域态。Sn 激活比例可以作为待校准隐变量，但不能用总 Sn 原子分数直接代替激活比例。

Furubayashi 等针对 RPD 生长、随后负氧离子处理的 ITO，观测到 N 降低时 μH 先升后降，并将后段与 Sn–O 中性复合体联系。Klein 等的原位研究摘要报告了氧空位中性化和 Sn 施主转为陷阱的限制机制。它们说明“氧越少电导必然越高”的单变量外推不可靠；均不是本蒸镀设备的标定曲线。[EO-S01, §3–4/Fig.2；EO-S02, Abstract]

最低可用实现不必强行求所有缺陷：以实际测得的 σ∥ 或 N_H、μ_H 为主，缺陷研究用于约束可能方向和设计辨别实验。

3.2 面内电导与方阻

在连续膜、欧姆响应、相同面内电场、层间能充分交换电荷且不受接触限制时：

σ∥(z) = q N(z) μtransport(z) [S/m]

G□ = ∫₀ᵈ σ∥(z) dz = q ∫₀ᵈ N(z) μtransport(z) dz [S]

Rs = 1/G□ [Ω/□]

离散成 j 层：Rs = 1 / Σⱼ σ∥,j dⱼ。先积分电导，再取倒数；不能先平均电阻率再除总厚度。 对均匀膜才有 ρ = Rs d；对梯度膜，Rs d 是等效面内电阻率，不能称局域 ρ(z)。[EO-C02, derived；EO-S07, Eq.4]

适用限制：

  • 岛状、裂纹、孔隙贯通、横向非均匀或临界渗流：上述标量积分不能代表实际电流网络
  • 跨膜输运是不同边界问题；无接触阻的标量串联极限为电阻面积积 R⊥·A = ∫ρ⊥ dz，不是 1/∫σ∥dz
  • 各向异性必须积分合适的面内电导张量后求逆；存在 σxz/σyz、霍尔耦合或不同层电位时需要完整张量与边界条件，不能逐元素套标量方阻公式
  • 接触、探针压痕、非欧姆、基底并联、边界修正和温升应独立建模/排除

3.3 Hall 不等于深度剖面仪

均匀、单电子载流子模型中，RH = −rH/(qN)，所以 NH = N/rH，μH = rH μtransport。只有 rH≈1 才可把 NH≈N、μH≈μtransport；虽然同一模型下 q NH μH = σ 仍成立，两个拆分参数不能自动解释成微观真值。

在各层同号载流子、低场、rH=1、共享面内电场的理想并联例子中，令 S₁=ΣNⱼμⱼdⱼ、S₂=ΣNⱼμⱼ²dⱼ，则：

Nsheet,Hall = S₁²/S₂，μHall = S₂/S₁

这说明多层 Hall 给的是迁移率加权组合，而不是简单的 N 深度平均；高场、多带或不同 Hall 因子需要更完整处理。[EO-C03, 本项目低场张量展开推导]

测量须保存原始磁场/电流反转、欧姆接触验证、样品几何、厚度和温度。van der Pauw 条件包括薄、均匀、单连通样品和边缘小接触；厚度不确定度直接影响体浓度与电阻率。[EO-S07, The van der Pauw Technique]

4. 光学介电函数与电学连接

4.1 符号、因果性和有限适用域

本目录固定时间因子 exp(−iωt)，沿 +z 传播为 exp(+i k₀ ñ z)，ñ=n+ik；被动吸收要求 k≥0、Im ε≥0。ε=ñ²，α=4πk/λ 是强度吸收系数。[EO-S06, §2–2.1]

采用：

ε(ω) = ε∞ − ωp²/[ω(ω+iγ)] + Σⱼ Sⱼ ω₀ⱼ²/[ω₀ⱼ²−ω²−iΓⱼω]

ωp² = N q²/(ε₀m)，γ = q/(m μopt)，σDrude(ω)=ε₀ωp²/(γ−iω)

故 σDrude(0)=Nq μopt。这是同一 Drude 参数模型的 DC 外推，不是证明测量的 DC 电导一定等于光学外推值。晶界、连通性和不同测量频率可能造成显著偏差。[EO-S03；EO-S05]

正的 Γ、γ 和非负振子强度保证这一参数模型的被动性与相应解析因果结构。代码采用一个普通 Lorentz 项作为带间贡献的演示；没有实现完整 Tauc–Lorentz 带边、Burstein–Moss/多体重整化或非抛物性能带求解。ε∞ 是所选频段内未显式纳入的高能贡献；有限拟合区间不授权任意 UV/远 IR 外推。演示区间为 400–2500 nm，只是代码适用域标签，不是经实验建立的 ITO 有效域。

文献对自由载流子与带边吸收采用不同组合：Fujiwara/Kondo 使用 Drude 与 Tauc–Lorentz；Gui 等在 200–1680 nm 的 RF 溅射样品中使用多步/梯度拟合并交叉比较 Hall、四探针和椭偏。[EO-S03, Abstract；EO-S08, p.2、p.8]

4.2 m* 与 μ：必须解耦记录

  • 有效质量会受到非抛物性与载流子占据影响，不能默认全浓度、全工艺固定为 0.35mₑ。该数在演示中仅是显式假设。[EO-S03；EO-S04]
  • μopt描述光谱拟合所见的有效阻尼；μtransport描述 DC 路径；μH还含 Hall 因子和测量模型。代码要求 μtransport 单独提供，避免自动复制 μopt
  • 光谱优先约束 ωp²∝N/m* 和 γ，而不直接唯一约束 N、m、μopt 三者。固定 m 的反演应报告“在假设 m* 下得到的 Nopt”，不要把它标成直接实测 N
  • 对多孔/纳米晶膜，局部光学载流子响应与宏观 Hall 响应的区别可能更大；Gondorf 等即给出这类反例，不能把其参数搬到致密蒸镀 ITO。[EO-S05, Abstract]

4.3 经验 ε(λ) 也是完整模型输入

EmpiricalEpsilon 对有限域内复介电函数线性插值；可以来自经校准的实测 n/k 或拟合，代码禁止外推。这样无需把测量无法识别的 N 和 m*硬拆开。插值保持本表的被动虚部，但不保证全谱 Kramers–Kronig 一致性；若跨宽谱拟合，应选因果振子、合适的 KK 约束样条或其他有物理约束的表达，并单独验证未参与拟合的光谱。

4.4 粗糙度与雾度不能伪装成 k

本实现是平面镜面模型。积分球总 T/R 与小接收角镜面 T/R不是同一观测。若散射光没有被探测器收集，1−Tspec−Rspec包含未收集散射，不能全部解释为热吸收。粗糙表面需有 AFM/PSD 或独立雾度/角分布证据；亚波长细结构可在条件成立时引入有效介质粗糙层，但不等价于雾度模型。直接加大 k来吃掉散射会污染 N、μopt和热吸收推断。[EO-C06, 测量能量收支推导；待实测辨别]

5. 膜/基底光谱：相干与非相干分开

给每个薄层 ñj(λ)、dj，从入射侧排序。相位厚度 δj=2π ñj dj/λ；法向界面振幅 rij=(ni−nj)/(ni+nj)、tij=2ni/(ni+nj)。可乘 2×2 矩阵，也可用等价的稳定反射/透射递推。参考代码用后者，避免厚吸收层的指数增长。[EO-S06, §3–4]

三种几何不能混报

  1. coherent_rt(..., n_out=glass)：薄膜后接半无限玻璃，T 是进入玻璃的功率，不含玻璃背面
  2. coherent_rt(..., layers=[薄膜..., (glass, dglass)], n_out=air)：包含有限玻璃厚度，保留全部相位，适用于实际保持相干且仪器可分辨相位的条件
  3. incoherent_substrate_rt(...)：薄膜相干，厚玻璃相位完全平均，玻璃本身无吸收，背面裸露；适用于仪器带宽、厚度/角度分布等确实平均掉基底干涉的情况。不能仅凭“超过多少 μm”一刀切判断

法向、入射/出射外介质无吸收时 R=|r|²，T=(nout/nin)|t|²，A=1−R−T。代码限制入射、出射介质为实正折射率；不吸收玻璃的非相干公式为：

D = 1−Rfront,reverse Rback

Ttotal = Tfront Tback/D

Rtotal = Rfront + Tfront Rback Tfront,reverse/D

其中反向前膜计算须倒转薄层顺序并交换边界介质。当前非相干实现没有吸收玻璃、背镀膜、多厚层或部分相干。有吸收基底时应接入完整强度传输与吸收传播（并正确处理吸收介质中的边界功率），不可简单把这个限制忽略。[EO-S06, §4.4、§6；EO-C05, 几何级数推导]

代码输出的是理想镜面模型的 T/R/A；不含积分球口径、仪器线形、测量偏振/角度展宽、非均匀膜空间平均。真实光谱比较前需按测量分辨率进行卷积或平均。

7. 参数识别与不确定度

7.1 明确的不可辨识反例

在固定其他振子的 Drude 模型中，同时作变换：

N→cN，m→cm，μopt→μopt/c

则 ωp²与 γ完全不变，所以全部 ε(λ)、n/k、T/R也完全相同。代码中有此单元测试。增加波长点或更换优化器不能解除这种结构性不唯一；需要外部质量信息、可信 Hall约束或有证据的先验。若 μtransport也除以c，DC电导亦不变。[EO-C04, derived]

额外常见相关性：d与n干涉相位；粗糙层与低密度层；Drude长波尾与带间背景；两层厚度与介电函数；接触/基底并联与“低体电阻率”。增加自由层数总能改善训练残差，不能据此确认真实深度梯度。

7.2 拟合与校准顺序

  1. 先拟合裸基底；独立测厚，检查绝对/相对光谱口径
  2. 均匀层 + 最少必要振子，施加厚度、非负阻尼/强度和适用域约束
  3. 同时拟合T/R，必要时多角度椭偏；多起点检查局部最小值与参数相关矩阵
  4. 检查残差随波长/角度是否有系统结构；仅有新增证据时增加界面层或梯度
  5. 留出整批或整工艺条件验证，而不是随机分散同一条光谱的波长点
  6. 工艺回归仅在训练条件包络内使用，跨设备、基底、源料或热史标为域外

Mendelsberg等摘要强调初值敏感性及联合T/R可降低参数不确定性；本报告未取得其全文，故不提取具体拟合约束或精度。[EO-S09, Abstract only]

7.3 不确定度输出

  • 区分测量误差、同片空间差异、重复样/批间差异、参数识别误差和模型偏差
  • 每次计算应携带参数联合协方差/后验样本，不把相关参数误作独立抽样
  • 可对正参数用对数尺度抽样；传播到 Rs、T/R/A 和目标带平均量，报告区间而非只报一个“最佳值”
  • 单层独立小误差近似有 δRs/Rs≈−δN/N−δμ/μ−δd/d；方差必须加协方差项，不能机械平方和
  • 多层应传播 Σσjdj 的联合不确定性；域外、缺测或不可辨识不应用窄区间掩盖

当前代码没有拟合器、误差传播器或真实后验；这些是下一阶段接口要求。

9. 透明导电膜的真正权衡

目标要同时指定 Rs、目标谱带、基底和应用约束：

  • 加厚在均匀σ假设下按1/d降低Rs，但干涉会移动、吸收路径变长，透过率并不对厚度单调；真实厚度还可能改变微结构
  • 增N可能降低Rs，但取决于μ是否随之下降；自由载流子红外损耗、反射和ENZ位置也会改变
  • 提升μ而不过度提高N常是值得研究的方向，但受缺陷、晶界、温度预算和结构约束，不是保证可实现的调参按钮
  • 可见平均T良好不代表近IR透过良好；低透过可能来自反射也可能来自吸收，二者对热负荷不同
  • 应力、附着力、弯折、湿热稳定性、光学色差和厚度均匀性可能使“最低Rs样品”不适合应用
  • 任何 Tᵃ/Rs 类综合指标都应声明谱带、权重和指数；不要把文献中一个FOM称为全用途最优

目标带加权定义为 T̄ = ∫T(λ)W(λ)dλ / ∫W(λ)dλ。明视觉需要明示光源谱与V(λ)，太阳能用途需指定太阳谱/器件响应。代码 weighted_mean 接受外部权重；演示仅按波长等权平均，绝不是标准“可见光透过率”。

校准实验与模型选择

本章为待验证的实验设计建议，不是已执行的设备操作。先依据基片、下层器件和设备安全条件确定可行域，再由实測闭合模型。文献窗口用于构造候选域，不能跨装置当最优配方。

1 先定义产品指标

至少明确：基片材料/尺寸/厚度/表面；透明要求是400–700 nm、指定可见光加权、近红外还是中红外；透过率是带基片总透过、扣基片相对透过还是镜面透过；入射角与偏振；Rs上限、均匀性、接触结构；散射、颜色、应力/附着、热预算；后续退火气氛及服役条件。未给定时研究可继续，但不能排序出单一“最佳ITO”。

若目的是红外窗口上的透明导电层，须先核查自由载流子导致的IR吸收/反射与基片本身的窗口。可见透明不等于3–5 μm或8–12 μm透明；ITO在所需波段是否可行应先用实测n,k与薄膜厚度预算筛选，不直接移植可见电极配方。导电加热还要分离膜面电阻与电极接触、边缘电流集中和电热边界。

2 工艺决策树

  1. 基片/下层能否承受文献沉积温度及后处理？若不能，优先研究低温反应蒸镀或离子/等离子体辅助，但同时设定充电、粒子损伤和辐照热预算。低温不自动等于低损伤。
  2. 已有电子枪且有可控氧气与基片温度？先以reactive e-beam作为证据较容易迁移的候选，稳定源状态和见证片组成；没有氧控时不要只靠后退火掩盖整层金属富集。
  3. 只有阻蒸？明确金属In/Sn或氧化物混源、加热器与坩埚相容性；分别测随源耗尽变化的组分。能蒸出可见膜不证明批内/批间Sn稳定。
  4. 要降低热预算而具备活化装置？区分activated reactive evaporation对反应气/蒸气的激活，与独立ion-assisted对工件的能量/剂量。仅记录“辅助电流”不足以迁移，必须量测工件能角谱及受照面积。
  5. 已满足电阻但透过差？先分清反射、自由载流子/带间吸收、金属团簇、粗糙散射、基片吸收，再改变变量。增氧、退火、减厚的效应可能反向，不作单调保证。
  6. 已满足光谱但Rs高？从厚度、N与μ、接触/测量几何、连续性逐项排查；不得只增加Sn或减少氧。先确认是否处于不连续膜/强空间不均匀区，再决定连续介质模型是否有效。

C. 厚度解耦：在可行的中心工况增设三个厚度，并对极薄样片做连续性检查。以G_sheet对h的趋势检查死层/界面和均匀σ假设；仅2点不宜同时拟合厚度偏置与σ再宣布唯一解。

D. 退火配对：同批相邻片分成原态与不同气氛/温度时程，遵守基片热预算；记录质量/密度/膜厚与电学光学变化。把退火历史作为状态，不与沉积温度合并成一个“热量”。

E. IAD增量：基础工况确定后，独立改变到工件离子通量及能量，在近似等厚度/等热历史下比较；必须留无离子对照。固定束流与蒸发速率比例时二者不可辨识，不能由相关性拟合独立影响。离子剂量改变时同步观察净侵蚀与成分选择性损失。

F. 验证：整批保留，不把同一片重复测量随机拆成训练与验证。至少一组新源料批次/新一天/新位置验证；以预测区间覆盖、偏差和重复性给结论，报告训练范围外样本，不只报R²。

5 参数与不确定度

先使用低维经验模型，例如logσ、logN、logμ或介电参数的有界响应面。温度、log p_O2、净生长速率、源寿命、离子观测量和退火状态要带单位标准化。不要同时拟合互为恒等式的logσ=logq+logN+logμ而不说明观测误差关系。

可对测量向量 y=(h,Rs,R_H,T(λ),R(λ),Ψ,Δ,composition)定义 y=H(θ,u)+ε。H包括测量几何和基片；源参数u与材料θ分层，不能让n,k把漏建的背面反射和散射全吞掉。J=∂H/∂θ的秩与奇异值是局部辨识诊断，平坦方向宜报告组合量或区间，不硬报唯一常数。

少量可见透过率往往难以辨识Drude阻尼与等离子频率；单个Rs只约束q∫Nμdz；Sn、缺氧、晶界散射又可能彼此补偿。增加Hall、IR及独立厚度可打破部分相关，不保证所有深度函数唯一。光学μ与Hall μ分开核验，允许晶界导致差异。

小误差可用Σ_y≈JΣ_xJᵀ；共享厚度、压力校准和密度误差必须在Σ_x保留协方差。ρ=Rs h若按独立误差传播只是额外假设。接近零净生长、缺陷饱和或非线性阈值采用有界采样/剖面似然，不能对病态商机械高斯近似。未知不确定度填null，不能填0。

def solve(a,b):
    a=[list(row)+[y] for row,y in zip(a,b)]
    N=len(b)
    for i in range(N):
        k=max(range(i,N),key=lambda j:abs(a[j][i]));a[i],a[k]=a[k],a[i]
        p=a[i][i]; assert abs(p)>1e-20
        a[i]=[x/p for x in a[i]]
        for j in range(N):
            if j!=i:
                p=a[j][i];a[j]=[x-p*y for x,y in zip(a[j],a[i])]
    return [row[-1] for row in a]

def boundary_rt(wl,layers,n0,ns):
    # Independent direct E,H boundary solve; unknowns [r,A1,B1,...,t].
    n=[n0]+[x[0] for x in layers]+[ns];d=[0]+[x[1] for x in layers]+[0]
    L=len(layers);N=2*L+2;a=[];b=[]
    for j in range(L+1):
        # E and H at boundary: known incident + each medium's wave terms
        for h in (False,True):
            row=[0j]*N;rhs=0j
            if j==0:
                row[0]=(-n0 if h else 1);rhs=-(n0 if h else 1)
            else:
                p=cmath.exp(2j*math.pi*n[j]*d[j]/wl)
                row[2*j-1]=(n[j] if h else 1)*p
                row[2*j]=(-n[j] if h else 1)/p
            if j==L:
                row[-1]-=(ns if h else 1)
            else:
                row[2*j+1]-=(n[j+1] if h else 1)
                row[2*j+2]-=(-n[j+1] if h else 1)
            a.append(row);b.append(rhs)
    sol=solve(a,b)
    return abs(sol[0])**2,ns/n0*abs(sol[-1])**2
