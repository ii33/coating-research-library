# T06 近红外 中红外与多光谱薄膜研究移交

T05已完成电阻蒸发与电子束优先研究的有界理论/公开证据/合成模型包：7章、27条来源、12材料源耦合记录、3原创图、51项检查、角向/方位留出与不确定度反例。没有用户设备实测，未发布工艺设定。

## T06应继承的接口

1. 物理厚度d、面质量m_A和光学响应分开。源输出j_in是kg m⁻² s⁻¹，留存/反应/ρ_f才给d；QCM等效厚度不是所有工件位置的真值
2. 材料卡的n/k须与源料、沉积法、基片温度/离子条件、膜密度/组成、实际谱域绑定；不能把T04块材常数赋给全部蒸发膜
3. 同材料不同源状态可能有不同二维厚度算子。源形/角律漂移会改变T03板结果，固定tooling不能自动修复
4. 化合物源蒸气、到达组分和最终膜不是同一对象；氧化物、ZnS、氟化物、H4的真实k与化学计量须在目标波段验证
5. 多层不同层的误差可能相关：同一料位漂移、温度历史、QCM密度误设会跨层累积；设计优化不能默认各层独立同分布误差

## T06首轮范围建议

按原文研究近红外、中红外、多光谱常见薄膜类型与应用边界：增透、高反、带通/长短通、多波段窗口、金属/介质混合、保护层。搜集原始光谱/热机械/环境证据，并区分谱域、AOI、偏振、温度、基片与用途。不要提前替代T07完整膜系设计理论或T08优化算法专题。

材料/基片仍以T04十二种膜材与ZnS、Ge、K9、ZnSe的条件化卡为起点。H4厂家/货号未知、Ge掺杂与K9牌号等缺口继续显示，但不等待它们才开展资料研究。波段名称须在具体项目中用明确波长区间表达，避免NIR/MWIR词汇定义差异影响比较。
