# INFICON SQC-310 手册交叉核对

来源：[SQC-310 Operating Manual 074-550-P1-H](https://www.inficon.com/media/11922/download/SQC-310-Operating-Manual-.pdf?inline=true&language=en&v=1)，§10、§11、附录A；核对日期：2026-10-02。

§10同样把密度、tooling和Z-ratio分开。Density校准先设Z=1、tooling=100%，再拿与晶振位置相邻的遮罩样片独立测厚；Tooling按实测基片厚度/晶振读数的比值乘初始因子得到，并建议至少三次独立沉积取平均。§11的Z-match为`Tf=(Nat dq/(π df Fc z)) atan[z tan(π(Fq−Fc)/Fq)]`；`z=√(dq μq/(df μf))`是AT切石英与膜的剪切声阻抗比。附录注明其Z值按AT-cut晶体归一化。

附录A Al行列ρ=2.700 g/cm³、z=1.080。这是QCM材料表的建模起始值，不是实际蒸发膜密度；手册另外要求独立膜厚校准。§11指出AT切在室温可做成小温度系数，但温度梯度、质量加载与膜应力引起的频率变动不能分离，须减小温度诱发偏移；没有可套用的固定温漂上限。手册说明旧式厚度方程频差限约0.02Fq，Z-match测试到约0.4Fq，不能把这两个模型适用范围混为QCM所有误差的保证。
