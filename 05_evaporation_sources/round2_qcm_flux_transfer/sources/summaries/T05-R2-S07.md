# 铝气相物种入口

[NIST Chemistry WebBook，Al气相条目](https://webbook.nist.gov/cgi/cbook.cgi?ID=C7429905&Mask=1&Units=SI)，2026-10-02读取官方页面。条目标识Al和aluminum atom，并给气相热化学资料；这支持把原子Al作为明确示范物种，不能证明任意蒸发源没有Al₂、氧化物、离子或团簇。

本包不复制数据库表、不由其温区推出用户源温。页面分子量26.9815386的末位与当前CIAAW数据不同，实现选择T05-R2-S06的26.9815384 g/mol，保留来源版本。Al/Al₂混合和O₂摄入均为显式合成质量账，不声称是实测蒸气组分。
