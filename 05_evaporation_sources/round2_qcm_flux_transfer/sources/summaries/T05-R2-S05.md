# 刚性与粘弹负载：开放原始研究例

来源：[PMC收录全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6415026/)，Gonzalez-Martinez et al., Polymers 10(3), 284 (2018), DOI 10.3390/polym10030284；该文CC BY 4.0；核对日期：2026-10-02。

这项湿度控制的QCM-D原始实验研究了胶乳涂层及其中表面活性剂。文中报道在较低湿度下，部分膜的归一化谐波频移近似不随谐波数变，耗散变化较小；越过材料相关湿度转变后，频移和耗散显著变化，膜变得更水合、更软。它说明有粘弹耗散或频率谐波依赖时，单一频移不再能无条件解释为Sauerbrey质量/厚度。

应用边界很重要：样品为有水蒸气/水合的聚合物与表面活性剂层，不是真空沉积的Al金属膜；不能把文中的湿度阈值或QCM-D判据移作Al的数值门槛。它只支持先验证刚性耦合与工况，再决定频率到质量/厚度转换模型。
