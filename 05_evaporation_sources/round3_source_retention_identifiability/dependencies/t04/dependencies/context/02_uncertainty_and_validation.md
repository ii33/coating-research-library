# 单位和不确定度传播

本轮的区间计算与标准不确定度计算是两种证据，不合并成一个“误差百分比”。quantity同时区分数值状态、interval_kind与standard_u。hard_bound、expanded_uncertainty、synthetic_bound不能互相改名；输入扩展不确定度区间经过区间算术仍不成为严格包络，也不自动保有联合95%覆盖率。所有本轮数值样本的边界均为合成确定性边界。

## 量纲核对

| 量 | 推荐单位 | 不能互换的口径 |
|---|---|---|
| 元素净通量 g_a | atoms/m²/s | 式单元/分子/源料粒子/QCM厚度速率 |
| 离子局部通量 Γ_s | particles/m²/s | 电荷A/m²、源出口总A |
| E_s | eV/particle | eV/charge、束电源V |
| N_net | atoms/m² | 无面积的总数、厚度 |
| D | charged_particles/m² | C/m²、包含中性的总粒子剂量 |
| U | J/m² | 吸收热、W/m²、剂量归一经验单位 |
| rho_film | kg/m³ | 原子数密度、源料bulk/packing密度 |
| M_a | kg/mol of atoms | g/mol、每化学式的摩尔质量 |
| n_atom | atoms/m³ | formula_units/m³ |
| h_increment | m | 最终h、QCM软件显示h |
| R | charged_particles/net_atom | 离子核/原子或离子/式单元 |
| epsilon | eV/net_atom | eV/离子、eV/式单元 |

1 g/cm³=1000 kg/m³；1 nm=10^-9 m；1 mA/cm²=10 A/m²；1 Å/s=0.1 nm/s。reader只接受上表规范单位，外部导入必须显式转换，不能猜字符串或静默改值。

## 区间路线

每个cell的Γ、E、每个bin的净元素通量及膜密度/摩尔质量都需给有限区间。先对时间和物种求积/求和，再计算比值；浮点结果用nextafter向外舍入，确切零乘法和零加法保留零。实现给出输入区间的保守算术包络，忽略已知依赖会变宽而不是擅自收窄。存储和浮点运算不声称满足全连续空间或复杂化学模型的数学严格证书。

温度未知不一定阻断已测g、Γ、E的守恒积分，但必须阻断任何依赖温度的材料响应模型。代码没有该预测器，因此不会借温度未知产生确定n/k或应力。未测的表面电位也不能借名义源电压补能谱；直接输入的到达能谱才可计算U。

三类必要缺失字段的结果不同：结构/单位错误是invalid；合法unknown记录是valid但相关输出blocked；数值可算但材料、上游误差或适用域未资格化则conditional_calculation。文献参考数据在计算入口默认不可用，需一个显式测量或衍生记录将样品、条件、来源和转移误差说明清楚。

## 协方差路线

对独立原始观测x及其协方差C，局部线性传播是 C_y=J C J^T。models/contract.py 的 propagate_covariance 对一个标量输出执行该式，并检查维数、有限性、对称性和归一化后的半正定性。奇异协方差可合法表示同源完全相关误差；负方差或不相容相关结构被拒绝。1e-12只是无量纲PSD数值检查容差，不可用于裁掉真实负库存或掩盖分母过零。

单一输出的一阶对数微分为：

- d ln h = d ln N_net − d ln rho_film + d ln M_formula − d ln nu
- d ln R = d ln D − d ln N_net
- d ln epsilon = d ln U − d ln N_net

已知相关项必须带正确正负号。例如R的方差包含 −2 Cov(D,N)/(D N)；如果把N由rho×h计算，那么rho与h的共同标定不能再当独立误差相加。若h本由同一个面质量m_A/rho求得，rho h=m_A，密度项可代数抵消。回归测试包含完全相关[1,-1]雅可比抵消例。不能把法定SI常数e和N_A再加成实验误差；元素摩尔质量仍与组成/同位素假设有关。

一阶法在净N近零、强非线性、非高斯或偏态状态失效。此时优先保留原始观测与区间/分布、使用后续适当非线性传播；不得输出对称±误差伪装有限稳定epsilon。联合相关蒙特卡罗还需要完整观测模型，本轮未运行，也未把独立高斯玩具bootstrap包装为实际误差闭合。

## 七轴不能相互覆盖

source为实际源通量/谱模型；time为采样与时间积分；space为点/单元与空间插值；geometry为遮挡/位姿；kernel为数值核；input为材料与计量输入；model为状态/响应模型缺口。同一原始测量的误差只传播一次，证据引用保留相关性，不把七个条目直接RSS。未知axis不因其他axis有窄区间而变成0。

最小回归覆盖：原子/式单元倍率；电荷数与粒子数；eV到J；两段历史的积分比与比值平均不相等；零/负/跨零/病态净量；块材密度与致密化误用；组分不符/漏氧；能角及表面积单位；快中性缺失；H4与YbF3身份；库存耗尽；协方差病态；可辨识与秩亏辨识。一次独立窄量纲核查的实际发现和复验范围另存reviews，不能扩大为完整算法审查或生产签字。
