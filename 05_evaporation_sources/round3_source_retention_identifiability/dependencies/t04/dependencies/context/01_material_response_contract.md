# 材料与基片响应输入合同

本轮把几何与剂量算法的输出接到可审查的材料数据，完成的是输入结构、有效域和失败语义。代表组合为 SiO2 薄膜与熔融石英见证基片：SiO2属于原优先膜料，公开块材色散、厂商块材资料与薄膜离子辅助研究能相互校核，适合暴露“来源有值但目标膜未测”的边界。熔融石英不是原四种基片之一，本例是方法示范，不暗示用户设备、库存或最佳材料选择，也不声称遍历所有组合后获得绝对最完整证据。

核心结论是：N_net、h、D、U、R、epsilon 可以在单位、粒子口径和局部历史完整时条件计算；它们本身不能唯一预测 n/k、应力、附着或量产工艺窗口。实际代表组合保留未测值 null；单独的合成样本只演示接口与辨识，不能与文献数据混成校准集。

## 与上游的边界

T04第一轮207条条件化参数与76条来源不重写。T10的电流、离子/原子、动能及历史定义沿用。T03的非负贡献优化器不接收本轮的净侵蚀记录。本轮不会把T02完整oracle的partial、点12离子参考not_run、tau非严格条件包络或T03未运行设备验证变成通过；七个误差轴 source/time/space/geometry/kernel/input/model 分开保留。

本合同在一个明确局部点或有限单元面积上工作，所有粒子通量已按实际基片表面积归一；不再乘一次cos(theta)。角度theta相对于局部外法线，phi为绕法线的方位角。每个能角cell存已经对该cell积分的粒子通量，不是每立体角强度，不省略或补乘sin(theta)。真实二维角谱缺phi时可计算已测总通量矩，但不能据此校准方向相关响应。

## 一条可审查记录包含什么

1. 身份：源料和膜分别标名；厂商、牌号、批次、相态、基片等级、表面处理、下层结构、后处理和环境历史。H4必须提供品牌/货号/版本或批次，不能给通用化学式。YbF3只表示氟化镱，不是YF3。K9实际牌号未知时不替换成H-K9L或N-BK7
2. 膜库存：每一种留存元素的初始面库存与有符号净通量，声明是否完整。反应氧、植入Ar、氢、水或污染元素未被计入时，不得把部分元素之和叫总原子数
3. 膜状态：目标样品实际有效膜密度、实测组成、匹配摩尔质量及各自不确定度。源料装填密度、晶体密度、块材密度、QCM软件密度不直接替代有效膜密度
4. 暴露历史：时间bin边界及bin平均净通量、温度、局部电位、反应气体分压；物种/电荷态/每粒子核数；局部联合能角谱及快中性覆盖情况。固定总剂量不能替代通量率，平均能量不能替代谱尾，累计比值不能替代沉积与轰击次序
5. 证据：来源/测量标识、条件标识、依赖哈希、RayBundle标识；每个量保留数值或null、单位、区间性质、标准不确定度或未知原因。未报道的不确定度不能填0
6. 响应：样品、方法、波长、几何、失效模式、测量或已验证物理模型、适用域；没有这些证据就不发出材料响应数值。记录响应不等于预测另一样品，更不等于资格通过

机器接口在 data/material_response.schema.json；models/contract.py执行结构检查及物理语义检查。additionalProperties=false防止拼错字段悄悄被忽略。接口v1明确选择“逐元素净库存已测”作为数值入口，既不从IAD电源读数造局部谱，也不调用未测黏附/产额完成看似闭合的余额。

## 守恒量与单位

对元素a定义膜库存 N_a(t)，单位atoms/m²。它只属于当前被追踪的膜层，不把基片被打出的原子继续算作同一膜。用局部bin平均净通量g_a：

N_net,a = sum_j g_a,j Δt_j；N_net = sum_a N_net,a

净通量可写成物理记账式 g_a = 留存入射_a + 反应摄入_a − 脱附_a − 再溅出_a + 已定义的界面交换_a。各项都未测时仅有净通量无法拆出每项，不能把负差全归为Y。主实现直接读净库存变化，Y记录作为证据接口保存而不自动执行再溅射预测。

D = sum_j,s(z_s>0),c Γ_s,c,j Δt_j，单位charged_particles/m²

U = e sum_j,s,c Γ_s,c,j E_s,c,j Δt_j，单位J/m²，包含已声明的带电和快中性分量。E必须是每入射粒子的动能eV，不是E/q；若从电流推粒子数，先用 T10 的 j=e sum z_s Γ_s，电荷态、物种比例和二次电子校正缺项则停止。分子离子D数的是粒子，不是核数。e和N_A是SI定义常数[MR-S10]。

U是入射动能面密度，不是吸收热，更不等于基片温升。中性份额unknown时U与epsilon阻断，仍给U_observed_components为部分观测能量，D可在其余输入齐全时保留。

组成固定为式单元sum_a nu_a A_a时，nu=sum_a nu_a，M_formula=sum_a nu_a M_a；n_formula=rho_film N_A/M_formula，n_atom=nu n_formula。于是 N_formula,net=N_net/nu、h_increment=N_net/n_atom。SiO2的每式单元含3原子，Ta2O5含7原子；同样U下每式单元能量是每原子能量的nu倍。非整数占位量必须解释其归一化，不能当一个可计数的独立分子。

h_increment只在组成与有效密度不随区间变化、元素净变化与所声明组成相容时返回，是有符号厚度变化，不是最终膜厚。成分漂移、致密化、含水/孔隙变化时，应量测端点库存、密度和厚度，并用 m_A(t)=rho(t)h(t)做状态关系；不能把dh/dt=r_net/n_atom用到n_atom正在变的膜。多相混合/分层/不确定H4在v1保留N_net及剂量，h被阻断，未来要扩展显式状态模型。

## 零净沉积与侵蚀

逐bin检查每元素初始库存加累积净变化的整个下界。只要可能耗尽某元素，就不能继续沿用相同膜材：N_net与h/R/epsilon阻断，要求转到膜耗尽/基片暴露模型。绝不按一个相对于巨大上界的容差吞掉真实小库存缺口，也不将负库存裁成0。

当N区间全为负时，N_net和在恒定状态下的负h_increment可记录；R和epsilon不作为成膜变量。当N下界≤0时，二者无定义或无界，数值为null。当N下界>0但区间宽度≥下界时，状态ill_conditioned，只给诊断比值区间，正常value为null，不参与稳定响应坐标或优化奖励。其他严格正且条件良好的情况，R=D/N_net、epsilon=(U/e)/N_net。

全层比值必须先分别积分再相除。瞬间无蒸气但有离子的bin应保留离子单独暴露、先清洗/后轰击标识；正负bin相抵后累计净沉积为正，也不能直接送入T03现有非负贡献oracle。本轮不新增tau的严格证书。

## 公开数值能用在哪里

Malitson色散与Corning密度用于明确品种和温度的块材参考，不填入实际沉积膜rho或n；Corning文档也不是用户来料COA[MR-S01,MR-S02]。SiO2 IAD研究显示需要同时记录基片温度、速率、物种、到靶通量、氧环境和源污染；本次可读资料并没有构成本机全能角谱和历史的联合响应数据库[MR-S03,MR-S04]。Niederwald的组分/密度/光学关联限于其SiO2膜、测量与工艺状态，不能降格为“加同样剂量就得到同样n”[MR-S05]。

KRI归一化剂量是带定义与条件的工艺度量，不是通用硬门槛[MR-S06]。公开再溅射实验、模拟分别带等离子体/测量和模拟势函数/靶态范围；ICP结果和MD结果不自动变成本机Kaufman源的Y(E,theta)[MR-S07,MR-S08]。本轮没有可直接迁移的实际Y网格，所有优先材料均unknown/null。含水与时效也改变膜状态，需保存测量时点和环境，不能只存刚沉积完的一行剂量[MR-S09]。

## 输出意义

conditional_calculation只表示在给定区间、口径和状态假设下计算成功，不代表上游误差闭合、材料模型已辨识或工艺可生产。所有记录production_qualified=false。代表组合的真实模板6项请求均阻断，是正确的未测状态；数值齐全的合成正沉积示例得到N_net=2.0×10^19 atoms/m²、D=6.0×10^18 particles/m²、U=128.17413072 J/m²、R=0.3、epsilon=40 eV/net atom、h_increment约0.309365 nm，全部是人为选定输入的算术结果。
