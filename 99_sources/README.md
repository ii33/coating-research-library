# 来源登记

每个真实来源使用`source_record.schema.json`登记，记录汇入`source_registry.json`。来源摘要与合法原文放在相关专题的`sources/`中；跨专题复用用同一来源ID及相对路径，不复制后忘记同步。

- 来源ID格式为`SRC-000001`起；`SRC-000000`仅供模板，占位记录不得进入真实登记
- 先核对身份、可读取内容、版次和存档权利，再做可追溯摘要
- 对原文设`original_path`前必须确认`rights.archive_allowed=true`并记录许可依据与SHA-256
- 打包或分享前检查`redistribution_allowed`，不是允许存档就一定允许再分发
- 来源等级不等于每个结论已验证；`claims[].verification_status`逐条填写
- 来源变更保留旧版本与具体引用定位，禁止无声覆盖
- 表中空值表示未知，不代表不存在或为零
- 标准记录须含发布机构、完整编号、版本/修订核验、状态、替代/修改单、适用性与有关条款

全局`records`初始化为空；当前T01研究在专题本地登记中维护，根登记的`topic_registries`链接该登记。若专题已有S01等来源ID，保留原ID并使用`T01:S01`命名空间跨专题引用；不要为了形式统一改写原始研究引用。后续统一登记时需提供显式ID映射，不能重复计数或丢失版权/版本字段。
